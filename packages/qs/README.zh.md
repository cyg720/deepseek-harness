# 奇术工作台

[English](README.md) | 中文

## 概述

七个奇术插件提供外壳、静态登录、会话导航、输入、转写、审批和提问。它们遵循[客户端模块子系统](../../docs/subsystems/client-modules.zh.md)，并保留可配置的官方界面。
