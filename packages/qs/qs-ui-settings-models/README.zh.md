## 概述

在奇术设置布局中显示供应商注册、配置及已确认的凭据状态，并支持 DeepSeek 与 pi-ai 供应商的连接编辑。

<a id="understand-the-implementation"></a>
## 理解实现

官方 `modelsSettings.face` 提供已有控制器，供应商与页尾子槽对应官方扩展。读取失败保留旧行并显示通用重试提示。本呈现不拥有独立权威状态，因此无需 invariant 伴随插件。

供应商保存器先确认配置版本，再保存凭据。凭据失败保留已提交配置；调用方须基于已确认视图重新计算字段操作后再重试。卸载阻止后续写入及 UI 回执，但不能撤销已发送的 RPC。连接编辑器只提交端点覆盖及显式凭据引用；空密钥保留已存储凭据。原生认证路线首次配置时显式创建空配置。

供应商删除先确认路线，再按已读取版本移除其用户配置。默认保留密钥；只有可写的约定引用且没有其他目录行引用时才提供显式密钥删除，该步骤先于配置删除。部分成功后的重试不重复已确认的凭据删除。

模型列表可编辑标识、名称与 token 容量，并保留其他模型字段。K/M 容量简写按十进制换算，非法或重复条目阻止保存。恢复继承移除用户数组并显示部署或 schema 默认值。配置确认成功后清除已提交的模型修改标记，凭据重试不会因为 Host 对象字段顺序变化而重放模型配置。

pi-ai 供应商的模型发现使用当前草稿端点、协议和可选只写密钥查询，不存储这些字段。筛选与选择只将明确采用且尚不存在的候选加入草稿。请求字段变化或卸载会失效旧回执；失败可重试且不暴露诊断原文。

自定义供应商卡从官方 schema 获取协议选项。创建要求未占用的小写路线标识、HTTP(S) 端点及至少一个有效模型，使用打开表单时的版本写入配置，再存储明确输入的凭据。配置提交后锁定路线字段，重试仅处理密钥。检查凭据引用时，已观察到的更高版本命名空间优先于迟到的创建确认。

已声明的 pi-ai 供应商可以编辑显示名称和 schema 支持的协议，不改变路线标识。清空名称只移除用户覆盖。模型发现使用草稿协议；不支持或缺失的协议需要明确选择有效选项后才能保存或查询。内置供应商路线不暴露路线级协议覆盖。

<a id="model-experience"></a>
## 模型体验

### 供应商目录

#### 模型看到什么

目录读取不改变模型请求。保存的供应商端点与凭据通过 `modelsSettings.face.operations` 影响后续供应商请求。

#### Token 影响

不增加提示词 token。

#### KV Cache 影响

目录读取不改变缓存。供应商配置变动沿用官方适配器重载行为。

## 已知限制与未完成项

<a id="known-limitations-and-deferred-work"></a>

- 欢迎说明步骤复用官方版本化文案与确认控制器，失败可重试，卸载后的迟到响应不影响新步骤。独立 DeepSeek 步骤在任意供应商可用时跳过，只写目录指定的凭据，并重载共享目录后再判断完成。正式 Web bundle 已装配该插件。真实 Host 浏览器用例覆盖首次确认、凭据持久化且不回显、端点编辑与刷新恢复。真实 Host 用例还验证自定义供应商新增、编辑、刷新与删除、传输失败保留草稿、默认保留密钥及明确删除密钥且不影响其他凭据。已确认用户刷新时，查询事实期间不会打开任一引导弹窗。390px 真实浏览器用例覆盖官方适配器的端点模型发现、端点拒绝后重试、长名称候选无对话框溢出、采用、持久化和防重复添加。两轮官方/QS 根界面切换验证已保存配置双向同步；官方页面并发写入后，旧 QS 草稿被版本校验拒绝且保留，不覆盖持久化新值，重新加载采纳最新版本。其余 W10 功能及整体验收仍待完成。

设置版本和凭据操作复用官方能力，不从脱敏描述符重建整个命名空间。
