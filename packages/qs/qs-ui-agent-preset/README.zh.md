<a id="understand-the-implementation"></a>
## 理解实现

重置后的准备中断状态跨目录刷新保留，旧 RPC 回执不能清除。卸载预设贡献者会在输入注册表保留失败状态；需重新启用并明确重试选择，或刷新页面确认会话预设。重试成功恢复可用性，但不会重放已取消的首次消息。

读取使用官方 agentPresets 与 settings Remote。后发刷新使旧回执失效，重连重置和释放废弃在途读取。目录打开能力缺失不隐藏有效目录；未提供预设服务或空目录显示不可用，拒绝或传输失败显示读取错误。呈现没有独立 Host 状态需要对账，因此不发布 invariant 伴随入口。

设置控件通过 settings.mutate 提交 default 或 modeSelectionEnabled 单字段及呈现时的版本。没有可写设置描述时写入器拒绝写入，重连和释放隔离在途回执，并保留较新的推送版本。损坏预设不可选，选择器关闭时不能选择默认值。保存成功刷新 Host 生效目录，不改变既有会话。

选择控制器在尚无会话时暂存健康预设，只向空白会话应用选择；目录变化会废弃不可用选择。会话切换、重置或释放后的回执不能发布另一会话的选择结果。欢迎区选择器订阅官方会话列表，标题标识读取各会话已记录投影。QS 欢迎区槽移除时清除暂存选择。

目录刷新后，即使会话尚未创建，选择器也恢复显示仍然有效的暂存选择，不会静默替换为生效默认值。

进行中的选择向 qsSendPreparation 发布绑定实际 RPC 目标的准备状态。QS 提交等待成功；选择失败持续可见，阻止在未确认预设下发送。指向另一会话的请求不会阻塞当前会话。

策略保存前捕获当前空白会话和连接代次，持久化成功后重新读取 Host 生效默认值，仅同步仍为空白且当前选中的同一会话。同步失败与设置保存成功分别呈现。目录刷新保留已挂载控件，避免部分失败提示随刷新丢失。

<a id="model-experience"></a>
## 模型体验

### 浏览器目录

#### 模型看到什么

本呈现不增加模型消息或工具。`agentPresets.list` 读取目录，不改变任何会话组成。

#### Token 影响

不增加提示词 token。

#### KV 缓存影响

目录不构造模型请求。

## 已知限制与未完成项

<a id="known-limitations-and-deferred-work"></a>

- 首次发送等待及失败有 DOM 回归，真实浏览器已验证延迟预设请求阻止提交；暂存预设首次发送的浏览器回归暂停真实预设 RPC，并核对持久预设选择先于唯一用户主动消息。真实浏览器回归在选择请求在途时卸载 Host 预设提供者，恢复同一 Loader 条目后核对输入保留、零提示词发送及成功重试的持久事件。注册表、插件生命周期和 DOM 回归也覆盖中断、重装及明确重试。复制/删除、组成查看、目录打开及对话创建须先核对批准的范围再实现。

### 开发备注

运行中的会话保留开始时的组成。默认值和选择器策略作用后续会话，目录可见不能证明这些操作已实现。
