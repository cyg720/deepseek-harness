# @deepseek-ai/dsh-qs-transcript

[English](README.md) | 中文

## 概述

本插件对应官方 ui-chat，包括视口和阅读位置归属；不拥有会话输入框，也不执行工具。

在工作台阅读用户消息、助手输出和待处理交互卡。助手正文复用官方 Markdown 渲染器，支持代码块与安全链接；无法识别的记录仍可查看。

## 使用本包

在 [Web 组合](../../bundle/web-app/cordis.patch.yml) 中与其他奇术插件行一起挂载 `@deepseek-ai/dsh-qs-transcript`。本包没有部署配置字段。

系统提示、参考上下文、思考过程与未知扩展负载默认折叠，展开后使用限制高度、自动换行的文本面板。已关闭轮次的过程行显示已记录的活动数量；尾部显示完成状态及可用的精确 Token 总量，不重复回复正文。这些折叠只影响呈现，不会从模型请求中删除上下文。未知负载只在展开时序列化，收起时释放格式化展示文本。

阅读区消费官方共享的转写偏好。普通模式保持过程成员可见，并隐藏紧凑过程控制行；切回紧凑模式保留各轮手动展开状态。通用设置中的转写视图行读写同一官方偏好，紧凑模式下，最终答案的内联推理随已完成轮的过程展开状态显隐，正文保持可见。普通模式、运行中或历史不完整时，推理仍可独立展开。

过程控制行只在轮次结束、答案锚点确定、投影轮次匹配、历史加载完整且存在过程活动时显示。其他情况下过程成员保持可见，不提供无效控制行。

主动发送消息或追加说明会恢复跟随。被动输出与历史前插保留用户上滚后的阅读位置。程序滚动立即生效，其延迟事件不会因内容增长而取消跟随。

历史加载与失败具有可见状态；重试会重新连接官方传输。每个 Session 绑定在内存中保留跨界面切换的阅读位置。加载更早历史会保持可见行锚点。整条复制包含用户文本或助手正文，不包含思考内容。

用户正文和追加说明随官方正文字号偏好变化并保留原型字号差值。助手 Markdown 使用官方排版令牌；代码块保持固定代码字号。

<a id="understand-the-implementation"></a>
## 理解实现

折叠过程成员与最终推理通过 chatPresentation 提供的官方隐藏 Hook 保持挂载。beforematch 事件展开所属轮次，持有焦点的内容不被隐藏。浏览器原生查找栏的验收与程序化事件测试分开。

<details>
<summary>实现细节</summary>

每行订阅按键索引的聊天节点源，历史分页读取会话快照。尺寸观察覆盖正文和交互卡。持久化记录由官方对话投影持有，因此本视图包不发布运行时 invariant 伴随入口。

行组件表在编译期覆盖全部本地 RowKey。浏览器因内容高度不足限制 scrollTop 时，阅读位置恢复会在内容增高后重试。

</details>

官方服务持有会话权威数据，本包仅呈现这些数据，因此不发布运行时 invariant 伴随入口。

<a id="model-experience"></a>
## 模型体验

### 浏览器呈现

#### 模型可见内容

`@deepseek-ai/dsh-qs-transcript`：无；浏览器视图将用户动作委托给官方服务，不构造模型请求。

#### Token 影响

本包不添加自有提示词或工具 schema；用户提交内容由官方服务处理。

#### KV 缓存影响

无；两个入口均不组装或发送提供方请求。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 消息图片委托 qs-ui-attachment 呈现；普通文件卡按照官方 Chat 展示名称、类型和大小，不提供打开或下载动作。未知非文本块保留可见限制提示。Markdown 支持 HTTP(S) 图片和通过官方鉴权文件 API 读取 POSIX/Windows 绝对路径图片；相对路径仍不支持。

行分派采用当前未退位的槽位键。后装贡献无需修改内置白名单即可呈现，卸载后恢复未知行兜底。分页失败读取 `historyLoad`，交互卡片归输入包的固定主区座位。

过程折叠要求轮次已结束且匹配、答案锚点已确定并存在可展开活动。外部过程与内联推理即使活动计数为零仍可展开；历史未完整加载时，已加载的成员保持可见。

收尾诊断按不可变节点数组快照共享弱引用索引。节点数组变化时重建索引，新增、删除和切换会话不会复用过期结论；同一快照中的其他收尾行查询不再扫描转写历史。

轮次运行时的步骤坐标来自该轮官方节点位置中的最新步骤，结束后采用最终答案步骤；位置缺失或轮次不匹配时不补造坐标。

历史分页在后续布局变化中持续保持所选行，直到用户滚动或发送。转写暂时禁用浏览器原生滚动锚定以避免重复补偿，卸载时恢复原样。

顶部哨兵进入转写滚动容器时自动加载历史。官方会话控制器负责请求串行和分页状态；断线、加载中、取消、失败及无进展分页暂停自动触发，连接恢复后仍可手动重试。已卸载的观察器不能继续请求分页。

压缩行消费官方自动 checkpoint 与手动命令关联投影。摘要仅在展开时挂载，缺失估算保持不可用，失败或缺 checkpoint 的命令结算保留完整文本。标记不呈现模型 checkpoint 指令信封，也不移除原始对话历史。

命令行从官方命令投影读取运行与结算状态，名称缺窗时使用通用标签，不回显参数，完整结果仅在展开时作为普通文本挂载。呈现结果不重新执行命令。

### 开发备注

<summary>维护者工作上下文</summary>

验证状态见[复核修复记录](../../../qishu/PRD/1-AI工作台/复核测试/02-复核修复与全量验证.md)。

收尾行声明 qs.chat.assistant-actions，仅在官方收尾消息具有 messageId 时传入动作槽。没有持久身份的中断残片不提供消息动作入口。

收尾行还声明 qs.chat.turn-tail，传递官方轮次位置及收尾序号。独立文件呈现消费此链，不重新解析会话事件。

最终回答中的行内代码文件引用使用可选的官方 chatFileMentions 提供者。各行只订阅自己的 turn-tail 数据，轮次关闭且最终助手序号一致时才启用链接。未知路径和歧义文件名保持普通代码。文件导航使用正在查看的会话及官方右栏资源路由。

更早历史分页成功但未新增记录、且仍有历史时，显示本地化状态说明并保留手动重试。该判断由官方 historyLoad 状态提供，呈现层不推断历史结束，也不发起下一次自动请求。
