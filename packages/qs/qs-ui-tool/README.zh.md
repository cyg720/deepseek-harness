# @deepseek-ai/dsh-qs-ui-tool

[English](README.md) | 中文

## 概述

本插件对应官方 ui-tool：转写里的工具调用树与逐工具视图注册表。复用官方持久调用/结果载荷、共享呈现原语以及官方命令与权限服务；不执行工具，也不读取本机文件。

工具调用呈现为可展开的行，状态取自已记录的调用：运行中、已完成、失败或已中断。每个调用按 Wire 工具名分派到自己的视图；未认领的名称——包括调用头不在已加载窗口内的结果——保留兜底卡，而不是静默消失。

<a id="use-this-package"></a>
## 使用本包

与其它奇术插件行一起挂载 `@deepseek-ai/dsh-qs-ui-tool`，装配位置见 [Web bundle](../../bundle/web-app/cordis.patch.yml)。本包没有部署配置字段。

展开写入、编辑、命令、搜索、Web、待办、图片或提问类工具调用，可以看到已记录的摘要、参数与结果。命令是否失败，按官方 shell 渲染器写在结果文本尾部的退出标记判定，绝不用“轮次结束”推断成功；输出已转存、或结果没有退出标记时，卡片说明状态不可得，而不声称成功。

子调用（程序化工具分发）按 `callId` 挂在根调用之下；未知或非文本结果保留其转义源码文本，作为可选中、有高度上限的面板展示。

<a id="understand-the-implementation"></a>
## 实现说明

<details>
<summary>实现内部</summary>

行在转写行槽上注册 `tool-call` 键，并声明 `qs.tool.call.toolview` 子槽；八个子插件各自注册自己负责的 wire 键（`bash` 与 `pwsh` 共用命令视图，`write`/`edit`、`grep`/`glob`、`web_search`/`web_fetch` 分别共用同族视图）。分派使用框架既有的 keyed entry 机制，因此卸载某个子插件后，它的键立即回到兜底卡。

视图模型是对持久载荷的纯函数；载荷不符合既定结构时返回 `undefined`，组件随即渲染兜底卡——即契约不符会退化成可检查的文本，而不是空行。每个视图只渲染自己这一层，递归与深度上限归工具树。

</details>

本包不发布运行时不变式伴随入口：持久调用与结果记录归官方会话投影所有，本包只做呈现。

<a id="model-experience"></a>
## 模型体验

### 浏览器呈现

#### 模型看到什么

`@deepseek-ai/dsh-qs-ui-tool`：本浏览器呈现把工具执行委派给官方服务，不构造模型请求；这里展示的工具结果就是模型已经收到的同一批持久记录。

#### Token 影响

本包不新增提示词或工具 schema token；工具 schema 归官方工具包。

#### KV 缓存影响

无；浏览器呈现不组装供应商请求。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与未完成项

- 文件打开与 `~` 家目录缩写尚不可用，路径按会话工作区根相对显示。独立 QS 轨迹插件通过 `qs.tool.call.actions` 贡献工具定位操作；轨迹视图不可用时隐藏入口。
- 图片结果通过宿主下发给行的会话授权装载器呈现；没有该能力时卡片说明限制并保留文字摘要；URL 装载或浏览器图片加载失败会显示错误提示。待办写入失败保留错误结果，不把请求清单呈现为已生效状态。
- 已记录参数不符合该工具既定结构时回落到兜底卡；逐工具视图不会部分解释未知载荷。
- 历史回答可解析但无法与问题配对时，已答数和总数均来自实际结果条目；无法解析的结果由兜底卡保留原文，不报告为零回答。
- 调用头落在已加载窗口之外的结果会说明参数不可得，并指向转写自身的分页入口；本行不另造历史动作。

折叠摘要不展示命令原文；明显的凭据头、环境赋值，以及带用户信息、查询串或片段的 URL 不自动进入摘要，原始详情仍可主动展开查看。此筛选不能识别任意自由文本中的所有秘密。

通用卡的参数和非文本 JSON 结果只在各自详情展开后解析或序列化，收起后移除正文；错误文本保持直接可见。原始参数按字符断行而不改变文字，减少 JSON 长字符串的布局工作。大型完整文本结果仍会产生浏览器长任务；宽子调用树仍需独立性能验证。
