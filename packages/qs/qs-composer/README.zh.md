# @deepseek-ai/dsh-qs-composer

[English](README.md) | 中文

## 概述

本插件对应官方 ui-conversation，拥有 Stage、欢迎区、输入和队列呈现；qs-transcript 独立拥有 Chat 视口和滚动。欢迎区通过 qs.workspace.hero.agentPreset 向独立预设插件提供入口。

在当前会话编辑并发送消息，也可在首次发送时创建会话。运行中的会话遵循共享忙碌 Enter 偏好；支持引导时，Ctrl/Cmd+Enter 请求相反的投递方式。队列项可编辑、移除或引导当前轮。当前队列操作结束前，队列控件保持锁定。创建失败保留草稿及预分配的会话标识。长按 Enter 不会重复提交同一草稿。

## 使用本包

在 [Web 组合](../../bundle/web-app/cordis.patch.yml) 中与其他奇术插件行一起挂载 `@deepseek-ai/dsh-qs-composer`。本包没有部署配置字段。其 composer-enter 通用设置行共享官方忙碌 Enter 偏好与设置动作。空草稿 Ctrl/Cmd+Enter 通过官方整队操作引导待发消息；命令菜单先仲裁带修饰键的 Enter，再决定是否提交。 忙碌时发送按钮显示解析后的投递方式，并随共享偏好和会话状态更新。

首条消息交接过程中出现阻塞时，草稿保持可编辑。恢复后需要再次明确发送；重新连接不会自动提交保留的草稿。

输入字号随官方正文字号偏好变化并保留小 1px 的差值；视口宽度不超过 700px 时至少为 16px，避免移动端聚焦自动放大。

<a id="understand-the-implementation"></a>
## 理解实现

贡献者在准备未确认时卸载，注册表保留绑定会话的失败状态与恢复指引。空闲替代实例不能清除它，替代实例必须发布新的准备尝试并完成。输入区取消首次自动发送交接并保留草稿，后续恢复仍需明确发送。

独立 QS 插件通过 qsSendPreparation 发布绑定会话的发送准备状态。准备期间禁用提交并保留首次发送交接，准备成功后仅继续该交接一次；报告失败则保留草稿，恢复后需要用户重新发送。注册贡献和订阅随其拥有者释放。

会话标题声明 qs.stage.header.actions，供独立功能插件贡献。只有当前会话存在时才渲染；作业数据及控制恢复由作业呈现插件和官方 Session 服务负责。

欢迎区仅在未选会话或官方列表摘要确认空白时显示；未知或非空历史保留转写顶部位置。欢迎区声明 `qs.workspace.hero`，选择及导航由独立工作区呈现负责，Conversation 插件只渲染槽位。

<details>
<summary>实现细节</summary>

客户端将发送委托给官方输入机。取消或卸载会使尚未完成的创建失效，阻止迟到导航；请求失败不代表创建成功。错误提示与阻塞原因由官方会话状态提供。本适配层没有可独立比较的持久化投影，因此不发布运行时 invariant 伴随入口。

首次发送交接同时等待预分配会话及其输入动作就绪，其他当前会话不会接收待提交草稿。

</details>

<a id="model-experience"></a>
## 模型体验

### 浏览器呈现

#### 模型可见内容

`@deepseek-ai/dsh-qs-composer`：无；浏览器视图将用户动作委托给官方服务，不构造模型请求。

#### Token 影响

本包不添加自有提示词或工具 schema；用户提交内容由官方服务处理。

#### KV 缓存影响

无；两个入口均不组装或发送提供方请求。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 本阶段不支持附件或模型选择，模型名称只读显示。首次发送失败后重试复用同一标识；取消不会删除 Host 已创建的会话。

会话级 `qs.stage.pending` 座位在滚动转写之外拥有 `qs.stage.interaction` 链。阅读内容变化不替换权威待回答请求源。含引用或附件的结构化草稿在 QS 中保持可见但只读，应在官方界面继续编辑。 纯文本命令 claim 保持可编辑，通过官方输入机提交；QS 不直接调用 claim。

上下文面板读取官方会话压力与组成投影，优先使用 projectedTokens；采样或容量缺失时显示不可用提示。面板明示组成属于启发式估算，并说明模型切换可能暂用较早采样。该面板不阻止发送、不判定计费，也不发起压缩。

输入区汇总命令、确认弹层独立持有的冻结原因与创建会话交接状态。每次释放仅移除自身持有者，卸载后迟到的取得与释放不再更新状态。展开的上下文面板和队列在输入区域内滚动，不能占满整个转写视口。

输入宿主通过 `qs.composer.takeover` 选举独立业务替换呈现，使用官方会话和待回答快照。业务呈现接管时卸载普通编辑器并释放其输入触发器租约；全部拒绝接管时恢复绑定同一官方输入机的编辑器。未选中会话时只渲染回退输入，不解析严格会话链。

可续聊子会话只有父级明确可用时才能编辑或提交。可用性未知时禁用输入，但不宣称父级离线。运行中的子会话保留独立停止动作，父级恢复可用后保留已有草稿。

会话阅读座位使用官方 conversationPresentation store 保存视图选择与定位请求，仅列出已注册 QS 阅读视图。选中呈现卸载时回落聊天，保留偏好供重装恢复。待回答交互和输入区保持在可替换阅读内容之外。待回答卡消失并丢失焦点时，座位恢复仍可聚焦的原控件或当前输入/标题。用户主动移焦以及会话替换均不触发恢复。当前待回答请求撤销后，在所属会话保留本地化状态更新提示；提示不推断回答者或宣称回答成功，新请求到来时隐藏。待回答卡在限高区域内滚动；审批或提问可见时为阅读区保留空间并限制输入区高度，长表单不能覆盖视图标签；共享呈现服务缺席时仍回落聊天。QS 轨迹呈现由独立插件提供，不属于本包。阅读标签采用手动激活：方向键和 Home/End 移动焦点，Enter 或空格选择视图。标签关联共享阅读面板，焦点所属视图移除后保留可进入的标签。

阅读视图标签固定在滚动容器顶部，切换视图无需先丢弃当前阅读位置。
