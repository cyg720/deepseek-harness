# Qishu workbench

English | [中文](README.zh.md)

## Summary

The seven Qishu plugins provide the workbench shell, static sign-in, session navigation, composer, transcript, approvals, and questions. They use the [client modules subsystem](../../docs/subsystems/client-modules.md) and preserve the official interface as a configurable alternative.
