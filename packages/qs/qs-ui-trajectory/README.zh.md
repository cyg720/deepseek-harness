<a id="use-this-package"></a>
## 使用本包

本插件独立对应 ui-trajectory，在官方 trajectory target 存在时注册 qs.stage.view。Web 配置独立装配。

<a id="understand-the-implementation"></a>
## 实现说明

视图读取官方请求快照和会话分页。target 移除时撤销呈现。上下文只在展开后挂载，并作为文本渲染。本插件不重复事件 Definition 或 target builder。投影所有权仍在官方注册表，因此不发布 invariant 伴随插件。

<a id="model-experience"></a>
## 模型体验

### 浏览器呈现

#### 模型可见内容

`trajectory` target 提供已记录请求。此视图不添加模型消息或工具定义。

#### Token 影响

不额外添加提示词 token。

#### KV 缓存影响

视图不构造供应商请求。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 已实现请求卡、已记录系统/工具上下文、逐请求 token 用量、已记录首字延迟及历史加载。缺失或非法用量显示为未记录，零用量保留为零。首字延迟按结果序号关联助手时间，失败重试不能借用后续结果；缺失时间仍显示未记录。用户、追问、上下文、助手和工具结果文本及压缩摘要已接入按需展开的历史台账；台账不代表某次请求的完整模型输入。图片通过当前会话授权加载器委托给可选 QS 附件插件，仅在记录展开时挂载；图片呈现缺席时显示限制提示。普通文件显示名称与字节数，不提供未支持的打开或下载动作。请求结果定位按记录序号展开并聚焦已加载的助手结果或压缩摘要；结果缺失时禁用。已加载轮次导航聚焦每轮第一条实际请求，无所属轮次的手动压缩不生成轮次。阅读位置及展开记录在官方会话绑定生命周期内保存，与聊天阅读位置分离。文件附件访问、完整指标、虚拟化和完整跨视图交互验收仍未完成。展开的请求详情还展示已记录的压缩摘要、原始输出与失败信息；认证失败使用本地化提示，不展示供应商原始认证响应。实时助手块和运行中工具层级消费同一官方轨迹快照，结束后移除瞬时呈现。官方跨视图工具焦点请求会展开已加载的祖先链、聚焦目标后确认；缺窗时保留请求并显示提示。这不代表 W9 全量验收通过。

工具卡的定位操作由本插件独立贡献。操作激活官方轨迹目标，并通过共享会话 store 传递调用标识；视图不可用时隐藏入口。操作槽由工具插件持有，卸载任一插件都不会留下另一份草稿或重复目标。

### 开发备注

官方注册表负责请求投影与分页，QS 插件只负责呈现。

更早历史分页成功但未新增记录、且仍有历史时，显示本地化状态说明并保留手动重试。该判断由官方 historyLoad 状态提供，呈现层不推断历史结束，也不发起下一次自动请求。
