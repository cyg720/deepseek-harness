# Agent Note: 奇术工作台客户端插件家族

Status: implemented

[English](2026-09-17-qishu-workbench-client-plugins.md) | 中文

## Problem

奇术工作台以官方插件的界面职责为拆分依据；自有登录独立例外。官方服务继续拥有会话与执行状态，官方界面保留供开发者切换。

## Decision

九个官方对应插件与一个自有登录包组成工作台。qs-shell 以 -1000 注册 root；官方 AppFrame 保持加载，界面切换不替换服务实例。

qs-shell 声明顶层布局槽；qs-ui-sidebar 声明 qs.nav；qs-composer 声明 qs.stage.body、qs.stage.transcript 和 qs.composer；qs-transcript 声明转写行槽；qs-composer 拥有固定待回答座位与交互链。每个插件通过 slots.inject 等待父声明，卸载时释放自有注册。

只有两条通道承载跨包事项，没有第三条。外观走全局样式表 `packages/qs/qs-shell/src/client/styles/tokens.css` 与 `.../contract.css`：外壳注入它们、把作用域限定在 `.qs-root`，其它包使用 `--qs-*` 令牌与 `.qs-*` 类名而不 import 任何东西。行为走槽或 Cordis 服务。bundle 纯净度门禁拒绝 `@deepseek-ai/dsh-qs-*` 之间的运行值导入，所以 `qs-transcript` 即使与 `qs-shell` 同属一个产品也不能 import 它的组件；类型导入会被擦除，是唯一保留的跨包类型通道。

槽的 inject face 归**声明方**所有，不归贡献方。`packages/client/ui-slots/src/index.ts` 里的 `SlotSpec` 要求 `children` 声明带上 inject 对象，而注册方自己的 `inject` 工厂是另一份业务面。这就是 `qs.stage.transcript.row` 与 `qs.stage.interaction` 由 `qs-transcript` 在自己的契约里声明、而不是由外壳声明的原因：会话插件声明转写槽，但只有 qs-transcript 能提供填充它的 chat 节点 keyed hooks。

`qs.stage.transcript` 是工作台里唯一的严格 `session` 洞，因此 `Stage` 渲染它之前先读当前会话 id——严格 session 槽在无绑定时抛 `SlotAssemblyError`。`qs.stage.body` 与 `qs.composer` 是 `session-maybe`，欢迎区与输入框在未选会话时仍然存在；此时输入区的 `inputActions` 是 `undefined`，这正是"无会话发送"必须先建会话的原因。

开发者切换是外壳持有的控制器，其生命周期独立于工作台 root 注册。`defaultUi: official` 保持QS 行加载但不注册工作台 root，官方画面无需重启即胜出；停用全部QS 行是另一条路径，会释放全部工作台注册。两者不可互换：改优先级只是把渲染交还出去，什么都不会清理。部署级开关 `showOfficialUiEntry` 拒绝的是切换动作本身，不只是按钮。行配置经 `webserver/index-inject` 的全局 `__QS_UI_CONFIG__` 到达浏览器，因为 `dsh.client` 行的浏览器半边由客户端模块系统装载，读不到 Loader 行配置。

登录门是界面选择器，不是安全边界：`/api` 没有用户级鉴权，Agent Note 在声明服务处就写明这一点。`qs-shell` 把 `useQsAuth` 当可选座席读取而不是写进 `inject`，因为必需服务缺失会让 fiber 永久等待，而一个永久等待的外壳永远画不出"登录组件未加载"故障页。同理，工作台组件抛错时外壳渲染故障页，而不是回落官方界面。

首次发送使用预分配的会话标识和组件持有的取消信号。创建失败不允许触发导航，即使错误携带该标识也不例外。取消、中途导航和插件卸载都会阻止迟到结果打开会话；组件卸载时释放外壳冻结。重试复用预分配标识，成功交接后清除。队列操作保留发起时的会话归属并检查 RemoteResult。失焦与点击可能早于 React 渲染禁用状态，因此同步在途锁串行化队列写入，操作结束后解除控件锁定。输入区读取官方输入门面的通知与阻塞注册表，不维护重复的错误或发送准入状态。

会话列表创建采用相同的取消归属；请求失败留在导航中可见，不产生未处理的 Promise。审批重试保留原决定，因此批准失败后通过重试控件不会变成拒绝。

转写将系统提示、过程控制和轮次尾部识别为官方 Chat 节点类型。指令上下文与思考内容通过默认折叠的详情保留；过程摘要与精确 Token 总量读取具名投影字段，未知扩展负载使用有界详情。模型可见记录保持完整，内部元数据和重复的收尾消息不进入默认对话正文。

单选答案清除已被替代的自由文本。菜单生命周期阻止迟到结果操作界面，但不取消服务器已接受的操作。转写跟随区分主动提交、被动更新与历史前插。折叠的未知负载延迟序列化；非文本历史显示可见限制提示，本地 Markdown 媒体沿用官方文件 API 策略。

插件测试装载真实 SlotRegistry 并调用条目的 inject 工厂；仅统计注册数量无法验证服务接线。创建、答复和卸载的异步结果由可控 Promise 驱动，DOM 测试验证用户可见结果及真实答案载荷。这些测试验证独立插件包，不引入跨插件共享运行时组件导入。

审批、提问和菜单提交持有同步实例锁，因为仅靠 React 状态更新无法排除渲染提交前的重复事件。失败操作释放锁以便重试。转写行按有效槽位键分派，并保留未知行兜底，滚动恢复则保留目标位置，直到浏览器几何尺寸允许抵达。

## Alternatives considered

- **以优先级 0 注册工作台（或直接替换官方行）**：向 `single` 槽注册同优先级的第二个条目会抛错，而删掉官方 `ui-layout` 行会让开发者切换所要抵达的官方界面消失。负优先级两者都保留，由配置决定。
- **按产品清单将多个官方插件合入一个包**会混合卸载和槽声明归属；按官方插件职责保持独立，登录作为自有扩展。
- **设一个 `qs-ui` 包放令牌与共享控件**：这是避免重复标记的最直接做法，也正是纯净度门禁所禁止的——`@deepseek-ai/dsh-qs-*` 不在默认 client externals 里，而 `dsh.client.external` 不是功能插件之间的依赖机制。外观改由全局类名与令牌承载，行为走槽。
- **十一个 `qs.*` 槽全由外壳声明，包括转写拥有的两个**：能通过类型检查但不可能工作——槽声明的 inject face 必须由声明方提供，而外壳没有 chat 节点读取器可提供。
- **只注册工作台画面并停用官方行**：被否决，因为开发者切换必须能抵达到已安装的官方界面，包括工作台尚未实现的功能。

## Consequences

布局偏好和用户选择的演示登录标记使用浏览器本地存储；转写阅读位置由内存中的 Session 绑定持有。提问草稿跟随官方请求结果清理，不以当前是否可见为依据，因为更高优先级的交互可以遮住仍待处理的请求。界面切换既不能回答请求，也不能丢弃其有效草稿。

外观在类名层面重复而非在代码层面重复：改 `.qs-btn` 会波及每个包，但每个包仍自己写标记、键盘处理、焦点恢复与可访问名。这份重复是纯净度门禁的代价，且是有意为之。

家族是顺序无关且可部分降级的。贡献包中任意子集缺席都不会导致启动失败；工作台把那个洞渲染为空，缺少 `qs-login` 则产生显式故障页而不是静默直通。`packages/qs/qs-shell/tests/composition.client.spec.tsx` 里的组合测试把全部包装到真实 `SlotRegistry` 上，断言每个 `single` 槽只有一个贡献者——因为"每个包单独能编译"并不构成槽树成立的证据。

工作台占据整幅画面，因此它渲染的任何组件都必须在缺少完整浏览器 API 的环境里存活。一次未做能力检查的 `matchMedia` 调用让 root 占位者抛错，框架的条目级边界随即**让 root 条目退位**——官方 `AppFrame` 悄悄回来了，而所有官方浏览器用例照旧通过。root 占位者崩溃不是可见故障，而是静默的产品替换，所以工作台自身的能力假设属于它的契约。

同一车道还抓到一个会打断启动的问题：`qs-composer` 直接向 `qs.composer` 注册而没有走 `ctx.slots.inject`。在 `defaultUi: official` 下没有任何条目声明该槽，注册于是抛错、整个 loader 条目失败——被打断的正是开发者切换所要提供的那种模式。现在贡献包全部等待声明，这才让"不注册工作台 root"成为一种受支持的模式而不是崩溃。

官方浏览器车道固定 `defaultUi: official`，理由与出厂装配固定 `workbench` 相同：那些用例验证的是官方 Web 产品，而要测工作台的用例必须自己声明。

`qs.status` 与 `qs.overlay` 现在有占位者：连接状态条（含手动重连）与 `qsToast` 服务背后的 toast 宿主。弹窗刻意不走该宿主，因为原生 `<dialog>.showModal()` 自己进顶层图层。开发者切换两个入口齐备：部署未开启时顶栏按钮完全不出现，官方侧栏底部槽承载返回入口。

[官方源码改动记录清单](../../../../../qishu/官方源码改动记录清单/00-登记规则与索引.md)是"本家族触碰了哪些官方文件、实际跑过哪些验证"的权威来源。

独立日程目录读取官方投影，默认 bundle 保持关闭。显式补丁启用两套呈现并复用一个 Schedule 所有者。目录门户挂到所属 `.qs-root`，继承主题变量而不向 body 复制色板；切换会话销毁展开目录及其展示时钟。呈现插件不取得提醒执行或修改权限。本地时间同时显示 UTC 偏移和 UTC 原值，因为夏令时回拨会使两个不同时间点具有相同的本地钟表读数。

目标视图共享官方 `goalPresentation` 提供者。调用方可随修改动作携带已观察 GoalRef，使 Host CAS 拒绝针对旧版本的编辑；省略 ref 时保持官方读取当前投影的行为。连接重置先使旧进程激活状态失效，再重新查询。该接口不增加 Goal 执行器或另一份 command-input Definition；独立奇术目标消费者捕获编辑版本，冲突后要求显式刷新。创建使用 goals.create 提交原样目标正文，不将正文解释为斜杠命令。清除确认同时捕获所显示的正文和 GoalRef，提交时不替换成投影中的较新版本。取消和 Escape 不修改目标；会话或目标替换会丢弃确认。

GoalError 在保留 HarnessError 基类的同时实现共享 Remote 错误字段。Gateway 使用结构化错误身份，工具结果元数据与命令消费者则依赖现有领域构造器；替换基类会丢失工具错误代码。纯 Goal 类型出口将错误映射合并带入两侧程序。真实 Web Host 调用断言旧版本的 edit、pause、resume、complete、clear 请求返回 GOAL_STALE_REVISION，且不追加 goal/change 或覆盖较新目标。

奇术输入区在普通编辑器外提供严格会话接管链。业务呈现根据官方会话和待回答快照选举，不另设只读状态。接管释放编辑器的触发器消费者，草稿仍由共享输入机持有；无会话路径只渲染回退内容，不解析严格会话作用域。

独立奇术子代理呈现使用官方目录观察与完整子地址。展开分支在收起、切换和卸载时释放观察，诊断记录不生成导航链接。浏览祖先目录只改变观察根，不选中祖先会话；选择兄弟会话使用目录返回的完整子地址。方向键只作用于健康记录的导航按钮，保留表单控件原生操作。输入接管遵循官方的单次和父级不可用条件，为运行中的可续聊子会话保留普通停止操作。

奇术工作区选择器使用现有 uiWorkspace 导航所有者，不重建空白会话复用或导航取代逻辑。本地在途锁阻止重复选择，只有仍挂载的呈现更新完成或失败状态。目录接纳仍由单独装配的选择流程负责。

奇术显式新建会话在发送前捕获当前会话的已登记工作区成员关系，将其标识传入官方创建操作；后续选择变化只阻止导航，不改写已接受请求的工作目录。

奇术 Conversation 呈现声明欢迎区工作区槽，由工作区呈现贡献选择器。两个入口均委托既有服务导航，从会话快照取得当前选择；父槽释放撤销欢迎区贡献，不移除侧栏导航。

目录入口共用一个请求控制器，并各自暴露子槽。回调捕获请求身份，取消、其他会话选择、流程贡献撤销和入口释放均使其失效。Host 工作区登记可能在撤销后完成，但共享导航的 beforeOpen 回调在选择会话前拒绝已撤销请求。选择器组件在官方 open/busy/结果参数之外接收请求身份，必须丢弃过期的原生或浏览结果。

独立奇术原生选择器贡献两个目录流程，OS 操作委托 uiWorkspace。每个请求身份保留一个 promise，effect 重放不打开两个对话框；在采纳阶段挂载不会重新打开选择器。撤销和卸载丢弃回调；现有 Client 方法没有逐请求取消接口，因此取消 QS 入口不终止 Host 原生对话框。Web 测试只替换 OS 能力结果，保留真实工作区持久化及导航。

独立奇术浏览式选择器使用 Host 返回的目录地址，不拼接平台相关路径。每次打开请求拥有可中止的扫描，并忽略迟到结果。关闭视图不能撤销目录创建，但迟到创建结果失去导航权。扫描失败禁用旧列表的采纳，本地化提示不包含 Host 诊断详情。

奇术外壳布局持久化使用版本化白名单，仅包含面板尺寸和显隐。运行时视口状态、请求身份和恢复提示不进入记录。无版本几何记录可迁移，不支持的版本和无效字段可见回退。浏览器存储失败保留可用的内存状态，不显示原始浏览器诊断。

面板 layout-record 编解码器保存地址与几何，不保存活跃 TabDomain 实例、资源正文、导航参数或撤销历史。解析器重建白名单字段并限制输入规模。合法 JSON 不能证明资源归属或呈现插件已安装；存储和恢复必须在发布标签前通过官方 owner 完成这些检查。浏览器存储通过 QS 会话座位接入。

官方右栏 store 拥有 restore 动作，通过现有订阅一次性发布缺席的会话停靠面。Docking 操作分配全新身份；TabDomain 只观察最终记录，原有关闭和所有者释放流程负责释放 pin。已存在的停靠面拒绝恢复，避免持久化偏好覆盖活跃导航。QS 负责存储访问与地址授权。

QS 会话座位保存版本化布局元数据，只在停靠面缺席时通过官方所有者恢复。官方文件地址解析器和当前标签及正文注册在任何资源 pin 前过滤恢复条目。失效条目和几何收敛产生可见恢复提示，存储失败保留活跃布局。写入跟随共享官方 store，在 QS 座位缺席时仍执行；已删除会话清理仍是明确缺口。

面板布局退出清理通过可释放的 Cordis 注入观察可选 QS 登录服务。只有已登录变为未登录才清理自有键前缀，初始未登录状态为刷新恢复保留记录。每次持久化读写检查当前登录状态，防止正在退出的座位重新创建已清理记录。存储拒绝只能尽力处理，不能阻断退出；这一浏览器偏好机制不是鉴权。

视口收敛由官方 store 一次处理，因为独立 resizeFloat 手势会抬高并聚焦浮窗。所有者在同次提交中恢复调整前焦点和层叠。QS 合并窗口通知，并在会话座位卸载时取消待执行帧。

官方呈现服务提供只读的 observeLayouts 已提交布局通知，回放已有停靠面，忽略未变化的布局引用，隔离消费者异常，并随所有者释放 store 监听。QS 将保存责任交给已挂载座位，缺席座位的提交由根级观察者保存；两条路径均检查当前登录状态，后台保存不能撤销退出清理。

QS 布局控件遵循原型，状态变更使用官方意图。“向前移动”按钮调整活动停靠标签的位置，不重建资源实例；首位、空栏和浮窗禁用该动作。其他拖拽手势的键盘等价操作仍需独立验收。

Conversation 所有者通过 conversationPresentation 公开既有 store 句柄和 target 激活入口。共享视图选择必须复用该句柄，不能另建持久化草稿或定位请求。QS 视图名录必须排除仅有官方呈现的条目；取得 target 数据源不等于完成 QS 轨迹视图。

QS 阅读宿主通过可释放注入消费 conversationPresentation，替代视图名录来自 QS 注册，不能因为官方数据源存在就显示官方呈现。选中呈现移除后显示聊天而不擦除保存的偏好。待回答交互和输入保持兄弟座位，只替换阅读正文。

独立 QS 轨迹插件读取官方 trajectory target，并在 target 移除时撤销注册。请求上下文只在展开时挂载，以 React 文本呈现。界面依据是 qishu/prototype；官方组件用于核对行为与生命周期，不作为工作台外观标准。请求卡不表示已支持消息、工具结果或媒体记录。

QS 阅读标签将键盘焦点与视图激活分开；移动焦点不能激活 target 或替换正文，原生按钮激活才提交视图选择。请求 token 用量来自已记录 usage，缺失值与零值分开，非有限数及负数不作为有效用量显示。

待回答卡片使用独立限高滚动区。审批或提问可见时保留阅读区高度并限制输入区，长表单存在期间仍能操作视图标签。阅读 target 切换时表单仍属于唯一会话座位。

待回答座位只在表单拥有焦点时负责恢复。请求结束后回原 DOM 控件，必要时回当前主区输入或可聚焦标题；会话切换清理焦点所有权，用户已主动移到其他位置的焦点不能被夺回。

待回答请求消失后显示会话级状态提示，不附加回答者或成功结论。远端撤销也可能源于传输或所有者生命周期结束，视图不能把每次移除都解释成其他客户端已回答。新请求隐藏旧提示。

QS 轨迹历史台账与请求提示词快照分开展示官方已加载 eventNodes。台账不是重建后的有效模型上下文，尤其不能跨压缩或历史缺窗做此推断。记录正文只在展开后挂载，未支持内容展示限制提示而不是原始内部对象。 成功空页且仍有历史时，两种阅读视图均显示本地化手动重试说明。是否无进展由共享历史状态决定；自动重试保持暂停，避免反复请求同一窗口。 物理流恢复可能在不重新打开 Session 对象时替换历史窗口。因此在途向前分页捕获窗口版本，Session 每次窗口替换均更新分页身份并释放等待状态；整体流取消信号不能代替窗口归属。

轨迹图片子槽由 QS 轨迹插件声明，附件插件导入声明并独立贡献呈现。图片授权加载和 URL 缓存仍由官方会话服务持有。

QS 轨迹阅读状态以官方 SessionBinding 为 WeakMap 键，只保存偏移和展开记录标识，不保存消息正文或图片字节；视图卸载时移除滚动监听，避免其他视图接管后写回旧位置。

工具定位由轨迹插件可选贡献到工具所属操作槽，复用 conversationPresentation 的目标激活和共享 store 定位请求。工具插件不依赖轨迹实现；目标未注册时不显示操作入口。

QS 设置壳独立对应 ui-settings-general，分区、操作、通用行与引导槽由 QS 呈现持有，settingsScope 仍是唯一配置权威。根级原生对话框提供模态焦点；仅回环连接的本机文件操作消费 hasDocument，不暴露路径，异步结果仅属于当前挂载实例。

独立 qs-locale 呈现订阅官方 LocaleRuntime 并委派选择命令，不持有语言注册表或偏好 store。Host 只读镜像禁用持久选择，memory 连接明确显示临时范围；即时应用不等于持久化确认。

独立 qs-ui-theme 呈现向同一官方 ThemeRuntime 注册外观与字号行。主题事件与设置写入仍由官方持有；卸载呈现不会重建或释放服务。

qs-ui-settings-plugins 导航保留已访问标签的挂载，使页面草稿在切换时保留；移除贡献会释放对应页面。父子槽注册与 DOM 导航已完成本地测试，Web 装配已接入只读清单标签，Shell 与 AgentLoop 数值卡已接入，WebSearch 与 SubagentModelSelection 卡片已接入。

独立 qs-ui-settings-plugin-inventory 向 qs-ui-settings-plugins 贡献延迟加载的只读标签，委派官方清单 RPC 及预设 display 解析器。读取 effect 在释放后忽略迟到结果，元数据和条件仅按文本显示。全局启用、预设组合与已观察到的运行状态分别保留。

插件配置目录仅在官方 describe 镜像存在命名空间且对应 keyed 卡已挂载时分发。初始状态缺失、读取失败、连接不可用和已读取的空目录保持区分。数值卡使用最初编辑版本，冲突保留草稿，按当前版本重试前必须显式采用该版本。重置移除覆盖，不写入基础值的副本。

QS 配置写入必须保留编辑版本并消费明确 Remote 结果。本地卡提交器阻止迟到完成覆盖共享镜像的新版本，不以 void mutation 的完成推断保存成功。释放呈现可阻止迟到 UI 接受，但不能撤销已经发出的 Host 写入。

QS WebSearch 卡独立呈现配置和凭据回执，只清理已确认成功的草稿，重试保留原凭据引用。凭据字面量只保存在当前编辑器，卡片卸载、放弃、连接重置和释放均清除；可写性和配置状态仍由官方凭据服务决定。

独立 qs-ui-permission-presets 装饰器读取当前权限投影，将机器值命令委派给官方会话，不把菜单选择当作已提交的权限状态。本地化内置标签前须精确匹配 Host 产品名称，保留运维自定义名称。新会话默认值属于另一项设置操作，不能据此推断现有会话权限已改变。

默认权限确认同时绑定设置版本和当前连接代次。重连可能保留相同设置版本，仅比较版本不能接受旧连接的确认。默认值写入回执与当前会话命令结果分别处理。

根呈现覆盖不会撤销全部官方子槽声明。独立 QS 命令装饰器使用显式优先级覆盖，同优先级重复注册仍报错。QS 权限覆盖贡献跟随其设置槽生命周期，移除 QS 根后恢复官方装饰器，不重建共享命令服务。

QS 预设目录保留损坏条目供管理，Host 生效默认值与选择器可见策略分别保留。目录打开能力独立读取，能力缺失不清空可用预设；只有当前生命周期的最新读取可以发布目录。

预设策略控件携带呈现时版本，逐字段更新设置。重置废弃在途回执不代表取消 Host 持久化，重连必须重新读取权威设置。部署策略隐藏选择器时，已保存默认值与目录生效默认值仍须区分。

暂存预设在提交给空白会话前必须重新核对当前目录。异步选择回执同时归属连接代次和捕获的会话标识，不能由切换后的会话或重装控制器继承。

预设策略保存与现有空白会话同步是两个 Host 操作。设置写入前捕获空白会话，之后采用刷新后的生效默认值；选择器策略关闭时生效值可能不同于保存值。同步被拒绝不得把已持久化的设置误报为保存失败。

预设选择和消息提交是独立 RPC。QS 输入区消费绑定会话的准备源，不假定列表变化订阅一定先于消息提交完成。准备期间保留交接，失败则取消自动提交并保留草稿。准备目标在选择开始时捕获，不按后续当前导航推断。

准备贡献者卸载不能确认预设操作成功。输入区保留中断贡献，直到替代实例明确重试；空闲注册及旧 RPC 回执不能恢复已取消的首次发送交接。

QS 模型选择复用官方 modelDirectories 解析器，通过独立输入槽呈现。/model 装饰器也作用于既有客户端命令，但先检查原贡献可用性。菜单与回车采用同一有效 UI 及附件规则，卸载后恢复原贡献。

命令处理器可能同步打开弹层。输入壳在进入锁定阶段后、执行提交副作用前清理旧临时界面，避免清理动作关闭刚打开的弹层。

模型选择失败包含传输拒绝和 RPC 错误信封。共享目录仅在请求仍属于当前代次时释放选择中状态；已卸载作用域或旧连接的响应不能改写当前状态。

替代模型设置呈现消费官方 modelsSettings 访问服务。该服务公开已有供应商目录、设置和凭据操作及欢迎控制器，独立视图不创建相互竞争的模型配置或确认状态。

奇术模型设置注册自己的设置分区及供应商卡/页尾扩展，读取 modelsSettings.face。供应商凭据区分已确认、缺失和未知；没有显式凭据引用的活动供应商保留其原生认证状态。

供应商配置与凭据存储分别提交。QS 供应商保存器先采纳新的设置视图，再写入密钥；保留部分成功状态，并要求重试差异基于已确认版本计算。编辑器卸载阻止后续凭据写入，但不宣称回滚已发送的 Host 请求。

连接编辑器只修改所显示的端点与凭据引用字段，保留隐藏配置。空密钥输入保留已存储凭据。原生认证路线允许持久化为空配置；不支持的适配器类型保留可见的部署配置说明。

供应商删除默认保留凭据，因为配置条目不能证明密钥的独占归属。只有可写的约定引用且当前目录中无其他引用时，用户才可选择删除。已确认的凭据删除先于带版本检查的配置 unset；部分失败后不重复删除凭据，避免移除重试前新写入的密钥。

模型数组编辑保留未知的逐模型字段，仅在显式编辑后形成覆盖。恢复继承使用部署或 schema 默认值，不能读取仍包含用户覆盖的有效值。配置确认在凭据操作前清除已提交的模型修改标记，不能根据序列化对象键顺序判断是否重发已提交数组。

模型发现是基于草稿字段的只读操作。用于查询的凭据不持久化，候选须明确采用，采用时保留查询期间编辑的模型。每一代请求字段拥有自己的回执；端点、协议、路线或密钥变化会失效旧结果，不能让其覆盖新候选列表。

自定义供应商创建使用适配器 schema 的协议枚举及草稿打开时的版本；路线尚未创建时不用于模型发现。配置提交后，仅重试凭据不能重新创建路线。检查密钥写入目标前，迟到的创建确认不得覆盖已观察到的更高设置版本。

只有手工声明的 pi-ai 路线暴露路线级协议编辑；内置目录的不同模型可能使用不同协议。编辑器通过精确字段操作修改名称和协议，保持路线标识不变。端点查询使用草稿协议，设置确认在凭据重试前清除已提交的协议修改标记。

奇术 welcome-notice 引导注册项与官方界面复用同一版本化文案及确认控制器。确认失败可重试；已卸载视图忽略迟到的加载与确认响应。独立 DeepSeek 凭据步骤遵循共享目录就绪状态，保留失败草稿并忽略卸载后的迟到回执。正式 Web bundle 已装配奇术模型设置插件，官方状态所有者保持唯一。无密钥真实 Host 浏览器用例验证说明确认、凭据只写与端点刷新持久化；自定义供应商增删改验证失败草稿和独立凭据保留。引导先查询权威事实再打开弹窗，避免已配置用户刷新时被抢焦点。

会话呈现入口同时公开既有发送策略：官方设置行和替代消费者共用一个忙碌 Enter 可观察状态、设置动作和手势解析器。奇术输入框在归属会话发送时读取当前 Session 并使用共享策略解析投递模式；首次创建交接仍按排队提交。奇术 composer-enter 行在通用设置中呈现同一偏好，卸载仅移除呈现。

Chat 所有者通过 chatPresentation 公开既有转写偏好源与设置动作。替代转写必须消费同一策略，不另建设置控制器；仅公开入口不代表替代呈现和设置行已完成。

奇术阅读区订阅共享模式：普通模式显示过程成员并隐藏紧凑控制行，切回紧凑模式保留各轮展开状态。最终答案的内联推理仅在紧凑模式且过程就绪条件成立时使用同一轮的展开状态；正文与独立推理折叠状态保留。

奇术 transcript-view 设置行对应官方 ui-chat 注册，以顺序 12 贡献到通用设置。设置行直接使用共享可观察源与更新动作；卸载移除设置行，不重置偏好。

奇术过程控制行与成员显隐共用一个就绪判定：同一已结束轮次、已知答案锚点、完整历史和已有过程活动。当这些保护要求成员保持可见时，不显示无法控制成员的过程行。

共享 Chat 呈现通过服务传递 useSearchableHidden，保持客户端模块隔离。奇术过程成员保持挂载，将 beforematch 与焦点保护委托给官方 Hook；最终推理使用同一轮次的揭示动作。
