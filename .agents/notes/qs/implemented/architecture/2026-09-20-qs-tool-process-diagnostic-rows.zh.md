# 代理笔记：奇术工具、过程与诊断行

状态：已实现

[English](2026-09-20-qs-tool-process-diagnostic-rows.md) | 中文

## 问题

工作台转写需要工具调用树、轮次过程与收尾，以及第二优先计划归到 C1–C3 的重试/错误/截断诊断。这些行的官方呈现位于 `packages/client/ui-tool` 与 `packages/client/ui-chat`，工作台都不能直接作为视图复用。

三个事实约束这次重写。命令退出状态不是结构化字段：shell 工具把 `[exit code: N]` 或 `[killed by signal: S]` 追加到结果文本尾部，输出转存时这段尾部会被替换。过程折叠属于轮次投影而不是某一行：官方 Chat 在轮次结束后隐藏 `[processStartSeq, answerAnchorSeq)` 窗口内的过程成员。行组件只拿到冻结的 props，从不持有上下文，因此工具视图无法自行取得按会话授权的图片装载器或折叠状态。

## 决策

`@deepseek-ai/dsh-qs-ui-tool` 在转写行槽注册 `tool-call` 行并声明 `qs.tool.call.toolview` 子槽；八个子插件注册各自负责的 wire 键。每个视图模型都是对持久载荷的纯函数；载荷不符合既定结构时返回 `undefined`，该调用随即走共享兜底卡——视图不部分解释未知载荷，也不渲染空行。

退出状态只从官方尾部标记读取，「没有标记」如实报告为不可得而不是成功；输出已转存时报告状态不在已加载文本中。

已记录的失败优先于合法请求参数：待办写入失败使用通用结果卡。授权图片 URL 不代表浏览器加载或解码成功；装载器拒绝与图片错误事件都会给出可见失败提示，同时保留结果正文。

问题配对与回答计数相互独立：有效结果条目即使无法按 ID 与请求配对，仍能支持数量统计。无效结果文本两者都不能支持，通过兜底卡保持可见，区分未知结果与零回答。

会话级能力通过行 owner 输入传递：转写宿主按 binding 用 `uiConversation.imageUrl` 签发图片装载器，并按 binding 建立一个折叠存储，于是行无需持有上下文即可读写折叠状态。过程折叠使用官方窗口边界与独立 kind 列表，并在行座席处应用，因此展开折叠会通过同一个存储订阅让座席重渲。

折叠与展开按钮共享活动判定，包括未计数的外部过程与内联推理。历史窗口未完整加载时不隐藏过程成员，因为控制展开的过程行可能尚未加载。

诊断是三个独立注册。重试行陈述官方 `retryState` 与尝试计数，不提供计时器也不提供动作；重试耗尽由本轮自己的错误行陈述，持久失败就在那里。

折叠摘要不展示命令原文；明显的凭据头、环境赋值，以及带用户信息、查询串或片段的 URL 不自动进入摘要，原始详情仍可主动展开查看。此筛选不能识别任意自由文本中的所有秘密。

收尾诊断按不可变节点数组快照共享弱引用索引。节点数组变化时重建索引，新增、删除和切换会话不会复用过期结论；同一快照中的其他收尾行查询不再扫描转写历史。

轮次运行时的步骤坐标来自该轮官方节点位置中的最新步骤，结束后采用最终答案步骤；位置缺失或轮次不匹配时不补造坐标。

通用卡的参数和非文本 JSON 结果只在各自详情展开后解析或序列化，收起后移除正文；错误文本保持直接可见。原始参数按字符断行而不改变文字，减少 JSON 长字符串的布局工作。大型完整文本结果仍会产生浏览器长任务；宽子调用树仍需独立性能验证。

历史分页在后续布局变化中持续保持所选行，直到用户滚动或发送。转写暂时禁用浏览器原生滚动锚定以避免重复补偿，卸载时恢复原样。

顶部哨兵进入转写滚动容器时自动加载历史。官方会话控制器负责请求串行和分页状态；断线、加载中、取消、失败及无进展分页暂停自动触发，连接恢复后仍可手动重试。已卸载的观察器不能继续请求分页。

压缩行消费官方自动 checkpoint 与手动命令关联投影。摘要仅在展开时挂载，缺失估算保持不可用，失败或缺 checkpoint 的命令结算保留完整文本。标记不呈现模型 checkpoint 指令信封，也不移除原始对话历史。

输入区上下文面板使用官方会话投影座席及 token-meter 类型，不创建第二个计量服务。容量或采样未知时与零值区分；展开后明示组成估算和模型切换采样时点限制，估算不参与请求授权、阻止或计价。

命令行从官方命令投影读取运行与结算状态，名称缺窗时使用通用标签，不回显参数，完整结果仅在展开时作为普通文本挂载。呈现结果不重新执行命令。

输入区汇总命令、确认弹层独立持有的冻结原因与创建会话交接状态。每次释放仅移除自身持有者，卸载后迟到的取得与释放不再更新状态。展开的上下文面板和队列在输入区域内滚动，不能占满整个转写视口。

独立 qs-ui-input-trigger 插件通过官方会话控制器呈现命令候选。输入桥读取官方草稿修订号并同步可见光标，IME 期间暂停匹配，普通发送之前先仲裁菜单按键。输入区持有消费者租约，菜单仅拥有自身绑定与订阅。

独立 qs-ui-commands 呈现复用官方选项控制器，在奇术主题根内使用原生对话框呈现风险确认；浏览器约束焦点，控制器负责确认状态与执行。打开视图持有输入冻结；卸载关闭控制器且不恢复焦点，避免迟到结算消费其他草稿。关闭不承诺撤销已经发送的业务操作。

qs-ui-message-feedback 通过官方共享反馈呈现贡献持久消息动作与会话表单。转写拥有收尾消息动作槽，仅传入持久消息身份；流式残片不可评价。反馈确认提示不替代任务通知。

奇术右栏共享官方 store 句柄与 TabDomain。外壳开合请求使用独立序号，面板实际状态回报不制造新请求，避免旧外壳偏好覆盖导航打开内容的状态。正文和标题 keyed 槽保持标签身份与生命周期信号；会话切换及 QS 卸载不销毁官方资源所有权。公共 docking 组件负责布局手势，缺失业务视图保留可见限制。

文件树呈现公开同一 store 句柄，并按 store 实例的 actions 身份缓存 Remote 注入对象。替代正文共用状态和请求代次；界面切换后的旧目录响应不能覆盖新刷新结果。标签 abort 仍决定请求与状态的生命周期。

文档预览呈现同样共享官方 store，每个 store 实例只绑定一份注入操作。分页和字节读取由同一代次所有者淘汰旧响应；换渲染类型或在另一界面刷新后，旧响应不能重新发布。渲染类型订阅共享，不重复注册类型元数据。

## 考虑过的替代方案

- 用重建出的地址渲染 `openFile`、`inspectCall` 与家目录缩写，会伪造其 owner 分别是右栏检查器（C9）、轨迹视图（C17）与 Host 账户事实的能力。
- 在过程行内部隐藏过程成员，会让成员行仍然挂载并可见，因为该行并不拥有转写的节点顺序。
- 在重试行上加实时倒计时，会把本地时钟当作排期权威，而原型明确禁止这一点。

## 后果

转写包现在拥有两项会话级行能力；任何需要其中一项的新行都必须加入同一 owner 输入，而不是自行取服务。只要已记录载荷不再符合契约，工具视图就退化为兜底卡，因此 Host 侧对工具参数或 `meta` 的改动会表现为限制说明，而不是空白行。

跨包行键保持可发现：客户端槽位生成目录现在记录 `qs.tool.call.toolview` 与 `tool-call` 行键。打开文件、轨迹定位、家目录缩写以及桌面/窄屏视觉复核仍未实现，记录在 [M1 验收报告](../../../../../qishu/PRD/1-AI工作台/复核测试/32-第二优先M1工具过程诊断验收.md)。

文档预览所有者通过 `documentPdfPresentation` 发布唯一 PDF 页码状态以及既有 worker 和画布操作。替代 PDF 正文拥有挂载文档和取消信号；界面切换保留标签偏好，但不共享正在运行的画布任务。页面重试创建新画布，防止已取消的任务写入后继画布。

可交付物插件仍是成功文件变更事实、显式交付声明及本机打开请求的唯一所有者。奇术通过独立槽及共享 deliverablesPresentation 服务替换轮次收尾和 present 工具呈现。预览使用会话范围文件地址，本机动作要求显式手势并保留持久事件与索引坐标。

奇术助手行通过槽 hookContext 订阅官方轮次位置数据。只有已关闭轮次的最终助手序号使用可选官方文件词表，收尾迟到时更新链接而不扫描整张转写。未知路径及歧义文件名仍由原提供者拒绝，打开动作在正在查看的会话范围内解析路径。

已有图片附件由独立奇术附件插件呈现。转写宿主唯一声明消息图片槽，用户、追加说明和上下文行通过宿主委托渲染；工具图片结果使用独立贡献。会话授权加载器持有字节读取和 URL 生命周期，视图忽略换图或卸载后的异步结果。新增上传仍不属于第二优先范围。 原图使用 body portal，聚焦关闭按钮，支持 Escape 或按下遮罩关闭，卸载后恢复打开前的焦点。普通文件元数据归转写呈现，并保留其与图片的原始顺序；不将附件存储标识解释为导航 URL。
