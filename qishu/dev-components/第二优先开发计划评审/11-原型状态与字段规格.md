# 原型状态与字段规格

本文为现有[原型](../../prototype/index.html)的增补设计输入。对应页面已在原工作台内通过 [readiness.js](../../prototype/readiness.js)补稿，沿用现有色彩、字号、间距、卡片和窄屏规则；仍是隔离的本地演示，不接真实业务。九组规格分别对应复核 V-B01–V-B09。实测范围及剩余限制见[本轮验收](../../PRD/1-AI工作台/复核测试/30-M0与原型补全验收.md)，不能直接沿用原 39/61 状态的通过数或将模拟状态视为生产验收。

## V-B01：跨视图审批与提问

桌面主区顺序：会话标题 → Chat/轨迹切换 → 可滚动视图 → 当前会话待回答区 → 输入区。待回答区不属于 Chat/轨迹可卸载内容，窄屏可在主区内展开并限制自身高度，不遮住提交按钮。只呈现一个可回答实例；状态条可显示摘要与定位入口，但不得再复制表单。

| 状态 | 呈现与动作 |
|---|---|
| 无 pending | 不占用额外高度。 |
| approval/question 到达 | 不强切 Chat；显示所属会话、请求摘要和原有合法操作。提问保留单选/多选/自由输入语义。 |
| 提交中 | 当前请求按钮禁用，显示提交中；全页导航不被永久锁住。 |
| 提交失败 | 保留输入及选择，行内错误与重试；不自动重新答复。 |
| 已由其他客户端回答 | 从权威状态撤销表单并提示状态已更新，不继续发送旧答案。 |
| 切换会话 | 只渲染新会话 pending；旧会话迟到结果不关闭新卡，不恢复旧焦点。 |
| 断线/重连 | 保留已知内容并标暂不可提交，重新确认请求身份后恢复；不把断线当拒绝。 |

关闭视觉展开不是拒绝或回答。提交成功后焦点返回原视图内仍存在的触发点，触发点卸载则回当前会话输入/可聚焦标题；重试仍定位原请求。验收 T42。

## V-B02：作业真实状态

来源：[SessionJob](../../../packages/api/session-controller/src/types.ts)。列表展示 kind、label、status、可选 detail、开始/结束时间和可计算耗时；完整五态为 running、stopping、completed、killed、failed。stopping 显示“停止中”，killed 显示“已终止”，不与失败或成功混合。

没有 detail 显示“此作业未提供详情”；无通用 result 字段时显示“当前数据未提供结果正文”。只在已有正式关联证据时提供“定位结果”；否则可“返回所属会话”，但不能声称已定位到结果。禁止根据列表序号或工具数量显示百分比、2/3 进度或伪造结果。完成状态不保证存在正文或文件。

空列表、首次加载、加载失败重试、断线保留陈旧快照、重新连接、作业消失、长标题和未知类型均需补稿。只读列表不放取消/重启按钮。验收 T44。

## V-B03：目标状态与激活

来源：[Goal 类型](../../../packages/goal/goal/src/types.ts)。目标正文、phase 和 blockedReason 来自持久状态，activation 从官方实时查询/事件来源取得，禁止由持久投影推算。轮数只写“已启动轮数 / 轮数上限”，不画任务完成百分比。

| 状态 | 界面要求 |
|---|---|
| 无目标 | 空态与合法创建入口；加载未完成不能先断言没有目标。 |
| active，activation 加载中 | 显示激活状态加载，暂不宣称自动继续；重连也进入此态。 |
| active + armed | 显示允许自动继续；暂停/编辑/清除依官方可用性。 |
| active + disarmed | 显示当前未自动继续；使用官方允许的恢复动作，不把 active 当持续执行。 |
| paused | 已暂停，展示官方恢复/编辑/清除入口。 |
| blocked | 展示 blockedReason 的 code/message；仅使用官方允许动作，不能自动恢复或把原因隐藏在 hover。 |
| complete | 完成，保留正文及轮数；不误显示运行中。 |
| 保存中/失败/ref 冲突 | 保留草稿；禁重复提交；冲突展示刷新和重新编辑，不覆盖服务器新版本。 |

刷新和进程重启后的 activation 必须重新读取。旧原型“2/4 任务”仅是模拟示意，不作为此字段的正式设计。验收 T45。

## V-B04：六类预览

统一头部为资源名称、类型、来源/路径与关闭；正文独立滚动，状态与重试可见。来源遵循[官方预览入口](../../../packages/client/ui-sidebar-documentpreview/src/client/index.ts)及 G04，不把任意路径直接转换成浏览器 file URL。

| 类型 | 正常稿 | 必补异常稿及限制 |
|---|---|---|
| Text | 行范围与文本，分页/截断可见 | 未支持编码、长行、超限、缺页、读取失败；不声称摘要为全文。 |
| Markdown | 安全 Markdown 和合法链接 | 相对资源失效、不可信链接、超限；不注入主页面 HTML。 |
| HTML | 隔离预览框与来源标识 | 脚本/相对资源依官方 sandbox/打包策略；失败与超限给说明，不建议关闭隔离。 |
| Image | 等比缩放，不撑开列宽 | 未支持 MIME、读取/解码失败、失效资源、大文件；关闭后释放对象 URL。 |
| PDF | 现有查看器能力内展示 | 查看器不可用、权限/读取失败、超限；不暗增编辑/注释/下载功能。 |
| Code | 语言、行号、代码文本 | 未知语言降为文本、长行、超限和定位失败；不执行代码。 |

六类均有 loading、取消/关闭、断线、权限拒绝、文件移动删除、会话切换迟到、卸载重开。限额取官方配置；官方没有可复用值的在 M0 实测定型，不在原型编造已实施限额。安全与资源释放验收 T36。

## V-B05：设置字段与插件贡献

七个呈现插件不是七个相同表单，也不代表总共七个字段。设置壳只拥有导航与容器；通用页各行继续由功能 owner 贡献。缺必要公开接入按 G03 阻塞，禁止通过复制官方 store 或读取私有运行值绕过。

| 对应呈现 | 已核对的字段/内容及来源 | 编辑、生效与异常设计 |
|---|---|---|
| ui-settings-general | [GeneralSection](../../../packages/client/ui-settings-general/src/client/GeneralSection.tsx)是 item 容器；[ui-theme](../../../packages/client/ui-theme/src/client/index.ts)贡献外观/字号，[locale](../../../packages/client/locale/src/client/index.ts)贡献语言，[ui-conversation](../../../packages/client/ui-conversation/src/client/apply.ts)贡献忙碌时 Enter 行为，[ui-chat](../../../packages/client/ui-chat/src/chat-settings.ts)贡献 transcriptView=normal/compact | QS 通用页列出各功能贡献，不能只换通用壳而丢行；对应呈现由原职责的 QS 注册负责，纯服务保持唯一。主题/语言保留官方服务；涉及新视图对应插件先补映射，不把它们并进 settings-general。验证本地效果与 Host 持久化差异。 |
| ui-settings-models | [ProviderEditor](../../../packages/client/ui-settings-models/src/client/ProviderEditor.tsx)：供应商、baseURL、models、API key；手工声明路由按官方条件呈现协议等字段 | 使用实际 schema 校验和路径操作；秘密只写凭证通道、不回显旧值；空白不默认为删除秘密；模型与凭证分步保存失败要分别显示，不用一个成功 toast 掩盖部分失败。未知供应商不伪造可编辑表单。 |
| ui-settings-plugins | [官方注册](../../../packages/client/ui-settings-plugins/src/client/index.ts)：shell.timeoutMs/maxOutputBytes、agent-loop.maxParallelToolCalls、subagent-model-selection.enabled/allowedModels、web-search-deepseek.baseURL/maxUses 及凭证字段 | 四张内置卡分别对应子注册；数值范围、可空与继承值由 schema 决定。只修改已观察字段；复位与清空不同；不得暴露 agents 数组为任意配置编辑器。运行中任务是否受影响逐 owner 验证，未验证不写立即生效。 |
| ui-settings-plugin-inventory | [库存页](../../../packages/client/ui-settings-plugin-inventory/src/client/PluginInventorySettingsTab.tsx)的真实目录与状态 | 只读；不放安装/升级/卸载按钮冒充能力，空态/缺服务/读取失败分开。 |
| ui-permission-presets | [permission.defaultPreset](../../../packages/client/ui-permission-presets/src/client/settings-store.ts)，选项来自动态 schema | 保存携带 revision，作用后续创建的会话；不假称修改现有会话权限，不把本地登录当授权。 |
| ui-model-selection | [共享目录及选择](../../../packages/client/ui-model-selection/src/client/index.ts)，包括 /model 和 composer 选择座位 | 当前会话选择与供应商配置区分；目录无模型、失效选项、切会话、选择失败；不重复注册 resolver/命令。进行中请求不声称被追溯替换。 |
| ui-agent-preset | [agent-presets.default/modeSelectionEnabled](../../../packages/client/ui-agent-preset/src/client/settings-store.ts)及只读预设目录 | 默认作用新会话；选择器可见性不等于改写既有会话组成；保存失败保留原值与错误，不伪造预设编辑器。 |

所有可写字段须补只读/namespace 未提供、加载中、schema 校验失败、保存中、网络失败、冲突与重新加载；秘密不得进入布局、localStorage、截图和普通日志。每项列字段路径、schema 来源、请求载荷、revision 规则、存储位置、影响已有/新会话及生效时点。尚无运行证据的时点标“待验证”，阻塞对应保存功能验收，不用“实时生效”占位。验收 T46，同时保留 T29/T30。

部署模式必须有两份状态稿：remote.$host.isLoopback 为 true 的 host 模式按实际 writable 提供持久保存；memory 模式的 settingsScope/describe 不提供 Host 持久化，显示不可用或只读，不显示假保存成功。此限制不自动禁止独立 Remote 操作或功能 owner 的本地展示偏好，逐字段按实际机制判断。settingsSchema 为独立服务，describe 为 settingsScope.describe() 返回的镜像。

## V-B06：反馈

消息操作区的赞/踩只针对合法持久助手消息；目标包含 Session 与 messageId。点击已提交评价按官方撤回语义处理；撤回过期评价不得误发新评价。裸 /feedback 打开 Session 反馈，不误带当前消息 ID；带参路径与按钮共用 G02 唯一状态 owner。依据[dialog](../../../packages/client/ui-message-feedback/src/client/dialog.ts)和[controller](../../../packages/client/ui-message-feedback/src/client/controller.ts)。

对话框固定显示反馈对象，包含官方分类、文本、提交/取消及错误区；补未评价、赞、踩、撤回中、提交中、失败保留草稿、目标不存在及会话切换。未提交时取消不产生写入；提交已经被 Host 接受不能声称关闭即撤销。迟到响应不得覆盖另一对象的新表单。验收 T34/T47。

## V-B07：结构化草稿限制

普通 @ 文本可编辑发送，不触发完整引用选择。检测到来自官方界面的结构化草稿，先判断是否具备已验证的无损展示/提交能力；不支持则显示保留的引用概要与“此草稿含当前界面暂不支持编辑的引用，请切回官方界面继续”。该草稿保持不可编辑/发送，不影响用户切换到其他会话。

入口允许时显示切官方动作，入口关闭时显示开发者配置说明；不能临时开启按钮、抹去引用或清空草稿。切回后的引用身份、顺序和内容必须一致；网络错误不能误报为不支持格式。验收 T37。

## V-B08：布局与标签

默认 Chat 主区、检查器右栏，其余按需打开；同一当前会话内多面板，不做多会话并排。关闭标签仅释放视图/资源引用，不删除文件、不取消作业；重新打开按资源身份定位，失效则给提示。移动标签改变布局，不改变所属会话。

补选中插件卸载后回落可用视图、最后标签关闭、卸载后恢复、刷新、存储损坏和版本不匹配；不能以清空其他会话数据“修复”布局。窄屏使用可切换单主区与可关闭侧层，隐藏区不能残留键盘焦点；拖拽提供键盘等价动作。持久化由 G01 的唯一 owner 定义，不在原型另创跨 Host 保存规则。验收 T23/T33/T35。

## V-B09：目录双入口与部署

会话欢迎区与侧栏工作区入口使用同一个选择协议。浏览式显示“选择 Host 上的目录”、路径编辑、父目录/子目录列表、加载/错误、取消与确认；长路径可换行/复制，不能撑开面板。新建目录仅在官方已有能力和权限允许时提供独立动作及失败状态，不混成“确认即新建”。

原生分支显示打开系统选择器与等待反馈；无可见 DOM 不意味着无插件职责。远端 Host 不支持本地系统选择器时按能力使用 Host 浏览式或提示不可用。取消不创建会话、不替换工作区，错误留在原入口；A 入口请求晚于 B 时不能调用 B 的回调。两入口都验证 open/busy/onPicked/onCancel/onError，回调归发起实例且只结算一次。验收 T43。
