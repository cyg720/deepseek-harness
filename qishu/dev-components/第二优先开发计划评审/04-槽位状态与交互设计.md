# 槽位、状态与交互设计

新增约束见 [09/G08–G11](09-编码前接线与范围冻结.md)和[视觉规格](11-原型状态与字段规格.md)：分页失败公开可观察；pending 使用稳定 session 宿主，不随 Chat/trajectory 卸载；双目录入口保留各自请求身份。这是拟议迁移，当前仍由 Transcript 拥有交互槽；实施同步声明、渲染与全部消费者，不重复声明或回答。

> 二合一范围：D1–D7 转写诊断与 W1–W12 工作台差异化统一纳入第二优先。官方→QS 映射以 03 为准；底层服务与库保持唯一，不能按页面合并插件。

## 槽位方案

qs-shell 保留顶层槽，qs-transcript 拥有 qs.stage.transcript.row（keyed/session）。qs.stage.interaction 当前也由转写拥有，但按 G09 拟迁移到 qs-composer Stage 的稳定 session 座位，避免切换轨迹时卸载；保持 chain 及审批/提问优先级，不产生两个声明者。新增行须完成 G06 的类型/分派/组件表及注册改造，不是仅注册一个新 key 即可。

工具树由独立 qs-ui-tool 注册到 `qs.stage.transcript.row` 的 tool-call key，并在该 entry 下声明拟议 `qs.tool.call.toolview` 子槽；八个对应工具视图子插件注册在此槽。槽名是方案候选，M0 验证 typed SlotMap、父子权限和唯一声明者。不得直接声明或渲染 `tool.call.toolview`、`conversation.input.overlay` 来借用官方已占有的子槽。

qs-composer 声明拟议 `qs.conversation.input.overlay`；qs-ui-input-trigger 注册候选菜单，qs-ui-commands 注册 popup，分别管理其 apply、locale、订阅与卸载。数据和动作由所属插件注入，样式使用 QS 令牌。官方 ui-commands/ui-input-trigger 继续加载并持有业务状态；QS 只是提供另一套视图，不注册第二个相同名称命令源。

## 状态所有权

公共槽见 [09/G03](09-编码前接线与范围冻结.md)。现有 qs.composer 为 single，计划保留外部槽并新增内部 chain，参照官方 ui-subagent 的只读接管；仍需装配验证。Chat/trajectory 的 QS 标签条、视图注册/选择、session 级记忆由 Stage 拥有，官方 conversation.view 不自动成为 QS 宿主。助手动作和 Goal dock 独立贡献，不在核心组件塞业务分支。

| 状态 | 权威所有者 | QS 可以持有的部分 |
|---|---|---|
| 工具及子调用、轮次、步骤 | 官方 Chat/Conversation 投影 | 折叠、展开、复制反馈；不保存第二份执行状态。 |
| 模型重试 | retry 投影及 Host 策略 | 可见倒计时；显示到期不代表重试已开始。 |
| 队列及取消 | Session 控制器 | 当前条目按钮 pending 和局部错误，不擅自删除/排序。 |
| 分页数据 | Session | 触顶观察器、失败自动加载暂停、锚点和阅读意图。 |
| 上下文 | token-meter 投影 | 格式化数值和展开面板；不改容量或执行压缩。 |
| 命令目录、选项请求、提交 | commandUi/inputTriggers 会话 controller | 菜单 DOM、焦点和可访问属性，不另建网络缓存。 |
| 草稿、claim、修订号 | SessionInput | textarea 选择区；输入文本写回官方，不能本地递增官方 draftRev。 |
| 审批/提问 | 既有 pending interaction | 原有 UI 与草稿机制，命令或工具卡不得自行回答 pending。 |

## 命令闭环的拟议顺序

1. 有有效 Session 才解析该 Session 的 controller 和命令能力；空会话入口提示先进入会话，避免因按 `/` 自动创建多条空会话。
2. 输入变化先写官方草稿，取得同一修订的 state，再以 caret、phase 对应的 guard 调用 track；不得把新文本搭配旧 draftRev。
3. 菜单快捷键先走 arbitrate。consumed 或 pick-highlighted 时不进入普通 submit；IME 组合输入不触发选择或发送。
4. 普通发送仍走 inputActions.submit。带参命令保留 claim；action 与 popup 交给官方贡献执行；失败读取 notices。
5. popup 使用官方 controller 的选项、提交状态与确认，成功后官方 scoped 事件按 CAS 消费 token，QS 恢复焦点。
6. 卸载 QS 视图仅取消自有订阅、焦点绑定、观察器和计时器；不 dispose 官方会话 controller，不把关闭 UI 当取消远端命令。

冻结按 G02 由 qs-composer 汇总唯一写入 setLocalFreeze：popup、确认、claim 交接、本地提交属于未决原因；清除一个原因不能解除另一个。焦点恢复使用当前视图的 DOM owner，不默认调用无生产消费者的 bindComposerFocus。共享 trigger 的 QS 能力过滤采用 G05 新增公开接入方案，现有 guard 本身不能做到仅保留斜杠。

该顺序是接线方案，不是已经执行过的验证。尤其 textarea 与 Lexical 所有输入机的修订同步、菜单 pick 后输入回显和 confirmation 焦点，必须由 M0 证明。

该接线还受 09/G05 的输入能力限制：共享 controller 的 @ 来源不能随 QS 视图全局停用。已有结构化草稿的官方/QS 往返须无损；尚不能支持时保留草稿并提供明确限制，不静默转成普通文本。命令呈现落点按 G02 逐条验收，反馈不得重复注册 decoration。

## 过程折叠与长会话

将“数据 hidden”和“用户折叠”分开：hidden 节点不因诊断展开而重新显示；折叠只影响可见节点的呈现。结束轮过程收起时保留一份最终答案，错误、截断与停止提示保持可发现。进行中显示已知步骤与活动，不设置伪进度条。

读取 nodes.source/processSource 和现有 locations/timeline 索引；禁止每一行在流式 render 内遍历完整事件窗口。若多行共享折叠状态，状态按当前 Session 绑定和轮次身份持有，重装必须清理，不污染同编号的另一会话。

顶部历史加载只允许一个在途请求；前插前捕获可见行，前插后补偿几何差；浏览器原生滚动锚定与手动补偿不得重复。负载展开、字体/媒体尺寸改变、同一帧新增输出都纳入验收。用户主动发送恢复跟随，后台增长不抢夺正在阅读历史的位置。

## 官方界面回退

保留 `defaultUi` 与 `showOfficialUiEntry` 既有配置语义，不修改默认值。官方组件和服务不因 QS 增强而停用。双向切换验证的是同一 Host/Session 的两种 UI；这与“全部 QS 插件停用后官方启动”是两项不同验收。

开发者返回官方用于体验原生功能，不把跳回官方当第二优先缺失功能的默认实现。若 QS 暂不支持某个工具结果类型，应在该卡片内明确限制，而不是静默隐藏。

## 工作台面板和设置的增量协议

右栏内部业务布局与 QS 外层几何分别明确 owner；G01 完成之前，以下槽名及复用关系仅是候选。官方服务加载不保证其会话 store 已接纳或座位已绑定，不能靠隐藏挂载官方界面维持 QS 功能。资源打开、标签关闭和两界面切换共同验证 pin/释放及 binding 清理。

拟议槽名不是现有 API：qs-shell 继续持有布局状态；qs-ui-sidebar-right 声明其子面板注册/标签/标题槽，文档、文件、任务等对应插件贡献视图。命名与 single/list/keyed 选择由 M0 的 SlotMap 实装验证确定。qs-ui-settings-general 声明 QS 设置 section/action/onboarding 等子槽，各设置插件独立贡献；不得重声明官方同名槽。

面板地址包含当前 Session、资源地址和面板类型；只持久化允许的布局/已选标签信息，不持久化凭证、完整工具结果或第二份业务状态。失效资源、停用插件、布局版本变化及窄屏恢复需有可见回退。UI tab 关闭只释放自有订阅，不删除 Host 文件或取消已经接受的作业。

| 状态 | 权威所有者 | QS 所有权 |
|---|---|---|
| 资源、文件及预览内容 | 官方 resources、documentPreviews、workspaceFiles 及 Host 策略 | 当前 tab、展开和滚动；迟到响应绑定原资源/Session。 |
| 工作区与子代理导航 | 官方 workspaces/sessions | 选择器状态、失败反馈；不把标签切换当创建会话。 |
| 作业/调度 | 官方镜像及对应 Host 服务 | 只读状态格式化，未获支持不创建写动作。 |
| 目标 | remote.goals 和事件 | 表单草稿、提交中及失败；ref/版本冲突刷新。 |
| 轨迹 | 官方 trajectory target | 独立视图选择、展开、定位及历史阅读位置。 |
| 设置和模型 | settingsScope、modelDirectories 及官方 Host | 表单草稿、验证提示、配置生效反馈；服务实例不复制。 |
| 布局 | 既有 QS layout store | 同会话面板几何和标签状态；需定义版本与安全恢复。 |
| 外部系统授权 | 经确认的 Host 凭证与身份机制 | 只显示授权状态与脱敏描述，静态登录不作鉴权依据。 |

所有列表、预览、设置保存、目标动作和授权请求都绑定发起时的身份。切会话、关闭、登出与卸载后，迟到结果不能改新视图或清空新草稿。设置提交与布局保存独立，离开页面不假称已经撤销服务器写入。
