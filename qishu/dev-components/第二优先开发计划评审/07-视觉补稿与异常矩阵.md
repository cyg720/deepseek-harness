## D 组既有原型与使用方式

登录演示账号后打开交互演示，选择下面任一组。在对话顶部选择具体状态；工具卡在原对话区展开，命令候选位于原输入区，确认使用已有弹窗。退出预览恢复原会话草稿，切换其他会话不显示旧会话预览。全部为本地固定数据，不执行命令、请求模型或修改真实文件。

实现文件为 [second-priority.js](../../prototype/second-priority.js) 与 [second-priority.css](../../prototype/second-priority.css)，由现有 index.html 加载。原型不作为正式插件模板；D 组正式实现仍按五个官方插件逐项对应，W 组按完整对应表扩展，工具八个子插件保持独立注册。

正式验收要求逐组覆盖桌面、窄屏和键盘焦点；既有原型记录不替代这些状态逐一复核。文本仍可选中与复制，长词/路径不撑破容器，弹层不遮住待回答交互。使用颜色加文字/图标表达状态，不只用红绿区分。新增按钮配置可访问名称，菜单使用正确的 combobox/listbox 关系及焦点恢复。

## 异常恢复矩阵

| 异常 | 用户可见反馈 | 正确恢复 | 禁止行为 |
|---|---|---|---|
| tool result 缺 call | 参数不在已加载历史中 | 可向前加载历史 | 猜工具名/参数并展示成功。 |
| 工具失败 | 错误摘要及保留输出 | 由用户继续对话或官方既有流程处理 | 卡片自行重跑命令。 |
| 模型重试已排期 | 次数和等待状态 | 按官方 started/结束更新 | 计时结束自动 submit。 |
| 历史页失败 | 顶部错误及手动重试 | 暂停自动触发后重试 | 不断触顶重发。 |
| 会话切换 | 保留各自阅读及草稿 | 回到原会话恢复对应状态 | A 请求结果改变 B UI。 |
| 手动压缩失败 | command 错误，原历史保留 | 保留可读原因 | 显示虚构压缩成功率。 |
| 压力投影不足 | 暂无估算 | 等待真实样本/容量 | 缺数据当 0% 或以此禁用发送。 |
| slash 目录失败 | 目录不可用及重试 | 官方目录服务重试 | 绕过仲裁执行猜测命令。 |
| popup 迟到/确认取消 | 仍关联开启时 Session | 关闭视图/返回正确草稿 | 清除后续新草稿或忽略风险确认。 |
| 当前轮结束时 steer | 不能引导的明确反馈 | 保留队列，按官方结果恢复 | 本地隐藏任务假装成功。 |
| UI 卸载/HMR | 恢复后基于现有状态渲染 | 清理自有监听并重订阅 | 取消共享 pending 或重复注册源。 |
| 新未知节点/媒体 | 有限摘要和类型限制 | 可展开安全诊断文本 | 静默丢弃或把任意 HTML 当结果执行。 |

## 验收证据要求

新增稿经评审确认后才能确定 1:1 视觉基准。正式验收固定语言、字体、缩放、浏览器、视口及 fixture，至少取现有断点两侧样本。几何/滚动与 ARIA 用自动断言，截图用于颜色、间距、溢出和状态辨识复核；截图通过不替代真实 Host 操作证据。

## 原型证据与正式验收界限

共 7 组、39 个状态。检查及截图索引见 [第二优先原型验收](../../prototype/validation/第二优先原型验收.md)。现有队列完整发送流程继续使用“发送与恢复”，本轮队列原型补状态和编辑/移除/引导反馈。加载、重试、压缩结果由状态选择器呈现；不把手动切状态当成真实异步接线通过。

正式开发仍需验证：官方数据投影、分页异常传播、textarea 与官方输入机的修订/引用语义、跨会话迟到请求、审批与命令同时出现、真实工具副作用、真实模型与媒体权限、HMR/卸载重装、逐文件覆盖率和性能。原型通过不解除 M0 阻塞项。

## 编码前仍须细化的视觉输入

当前 61 个 W 状态属于交互提案，不能直接认定覆盖全部生产字段。对应组件的视觉签收按 11 已补文字规格、仍需渲染及签收下列输入，并与 [09](09-编码前接线与范围冻结.md)技术验证同步：六类预览的格式/超限/安全限制；反馈的赞踩、撤回、消息级及会话级入口；带结构化引用草稿切入 QS 的可见限制；子代理父级不可用但运行中可停止；七个设置分区的实际字段、权限和生效时点；通知跨会话归属和已读策略。

这些是待补细节，不更改现有原型检查的通过数，也不宣称已画出全部状态。先确认产品范围和真实字段，再补到原工作台中，按对应任务逐组签收。

## W 组异常恢复要求

目录选择取消保留当前工作区；文件失效提示刷新或关闭；预览拒绝不另走无权限路由；任务断线标明数据未刷新；目标/设置保存失败保留草稿且防重复提交；授权撤销立即停止后续受保护请求；布局缺插件忽略失效面板并可恢复默认。所有迟到结果按资源/会话/请求身份隔离，不跨页面提示假成功。
