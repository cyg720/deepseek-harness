## 四、允许/必须偏离原型的项（规范授权）

| 项 | 原型现状 | 我们的做法 |
|---|---|---|
| 状态色 | 未定义完整语义色板，深色错误色为继承值 | 补齐 error/warning/success/disabled 明暗成对，保证 ≥4.5:1 |
| 装饰字号 | 存在 8–10px 的装饰性文本 | 关键信息不使用装饰字号；<12px 仅用于非必要装饰 |
| 主题主属 | 原型把 dialog/toast 放在 `#root` 外，靠 CSS 变量继承覆盖 | 统一 portal 到应用根内的 overlay 容器（或复制主题属性），确保弹窗与 toast 也随主题 |
| 主题挂载 | `.dark` 挂在 `body` | 挂在**应用根**（避免与官方 `ui-theme` 的 body 写入互相干扰），并在根上声明 `color-scheme` |
| 实时 resize | 原型只在初始化读 `innerWidth`，无 resize 监听 | 实现时补 resize 处理（规范明确要求"需在实现中显式验证"） |
| 可访问性 | 部分图标按钮仅靠 title | 图标按钮必须有可访问名称；`inert` 处理隐藏面板；弹窗关闭后恢复焦点 |
| i18n | 硬编码中文文案 | 全部进 `locales.ts` typed 字典（中文优先，预留 en） |
| 移动端管理操作 | 悬停才暴露 | 触屏下常显（规范要求） |

## 五、`factory.svg` 与品牌

- 品牌：四角描边星标（原型 `paths.spark`）复用到 `Icon`；字标「奇术 / QISHU · AI WORKSPACE」；桌面顶栏 logo 32×32 / 圆角 9 / 产品名 18px；登录故事区 logo 用 `--qs-lime` 底、产品名 21px。
- `factory.svg`：原型用 `<object type="image/svg+xml">` 独立加载并自带动画（3s/6s）。落地方式（按优先级）：
  1. 作为包内资源按构建管线引入（首选，保留独立动画）；
  2. 退化为内联 SVG 组件并自带同参数动画（差异登记：动画由 CSS 而非 SVG 内部驱动）；
  3. 再退化为静态 SVG（需评审同意，属视觉降级）。
- 登录页与工作台**不共享主题**：登录页颜色固定（规范明确），工作台随主题切换。

## 六、样式核对方法

1. 每个里程碑结束，按第三节清单逐行核对（截图 + 计算值）。
2. 断点与特殊状态取样见 [08-视觉差异清单与新增交互稿](08-视觉差异清单与新增交互稿.md) 第四、五节：固定视觉环境（浏览器/视口/DPR/字体/缩放/截图参数）+ 断点**两侧**（389/390/391、699/700/701、959/960/961、1149/1150/1151、1599/1600/1601）+ 移动软键盘 + 长内容。
3. 深浅两套主题都要跑到；深色重点查"深色会话/应用悬停不得变浅色填充"。
4. 与原型并排比对：原型本地打开方式见 `../../PRD/1-AI工作台/prototype/使用说明.html`（`serve.cjs` 可起本地静态服务）。
5. **原型不加载 webfont**（Inter 仅在本地存在时生效）→ 记录实际回退字体并保持两侧一致；由此产生的排版差异必须在验收记录中显式标注，而不是当作缺陷。
6. 原型为**固定初始状态、无 resize 监听** → 实时缩放行为由我方实现，必须显式验证（规范原文要求）。
