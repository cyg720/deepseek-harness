## 一、1:1 保留范围（验收对象）

以 [02-样式还原对照](02-样式还原对照.md) 第三节清单为**唯一验收对象**，覆盖：布局尺寸、断点、圆角/边框/阴影/层级、字体与字号、图标规格、焦点样式、交互状态（浅/深各四组）、动效时长与 reduced-motion。原型中未列出的区域（右栏业务内容、应用中心、待办、日程、设置弹窗）**不在本阶段 1:1 范围**。

### 原型已覆盖的三类：核对结论

| 项 | 原型已实现 | 核对结论 |
|---|---|---|
| 审批卡 | 标题（`reason ?? toolName`）、详情区（工具/目标/影响 + 命令代码块）、`role="group"` 可聚焦详情、拒绝 / 允许一次、`aria-busy`、提交锁、失败提示与重试、撤销入口 | ✅ 与 `PendingApproval` 语义一致（`answer('allowed-once' \| 'rejected')`）。**差异**：原型把 `{目标, 影响}` 当作已知字段，真实数据需从 `callId` 关联的工具调用**派生**；派生不出时用原型的兜底文案（"暂时无法获取调用详情…可以拒绝本次操作"） |

### 六类交互的结构要求

### 1) 审批卡（M1 极简 → M2 定稿）

- 结构：状态条（"等待授权"）→ 标题（`reason ?? 工具名`）→ 详情区（`callId` 解析出的命令/参数/目标；解析失败时只显示工具名 + 一句说明）→ 操作行（拒绝 / 允许一次）。
- 状态：等待、提交中（双按钮禁用）、失败（错误提示 + 恢复可点）、撤销（整体消失）。
- 可访问性：详情区可聚焦滚动、`role="group"` + 可访问名、键盘可达双按钮、破坏性操作不默认聚焦。

### 2) 提问表单（通用）

- 结构：标题（`header?`）→ 问题（`question`）→ 详情（`detail?`）→ 选项（单选/多选）→ 其他（自由输入，选中"其他"或直接填写）→ 提交。
- 多问题批次：逐题分组、整体提交；未答必答项时定位并提示。
- 状态：未答、部分答、提交中、失败可重试、撤销消失。
- 可访问性：字段集 + 图例、`aria-describedby` 关联详情、错误与字段关联。

### 3) 方案审批卡（plan-review）

- 结构：方案标题 + 方案正文（Markdown 只读）+ 操作行（**批准必需；拒绝可选**，标签按 `intent.approve` 匹配，不得按位置或固定文案判断）。
- 状态：同审批卡。
- 可访问性：正文可滚动聚焦；按钮标签使用请求方给定文案。

### 4) 连接中断提示

- 位置：`qs.status`（底部条）+ 输入区上方一行（发送禁用原因）。
- 状态：重连中、已断开、已恢复（短暂提示）、手动重连按钮。
- 可访问性：`role="status"`，文本变化播报一次，不重复轰炸。

### 5) 根故障页

- 触发：**根错误边界**捕获 root occupant **内部**的渲染异常（T2）。**不含**"root 被退位"——退位后我们没有渲染点，由官方接管（T3，见 [07](07-异常与恢复矩阵.md)）。
- 结构：标题 + 简述 + "重试渲染" + "重新加载页面" + （可选）复制诊断信息。
- 要求：**不得**回落到官方 UI；样式沿用令牌，保持产品感。
- 可访问性：焦点落在标题；按钮键盘可达。

### 6) 空态与加载骨架

- 空态：会话列表空、右栏空、工具入口空——每处一句"缺什么 + 下一步"。
- 加载：首屏骨架、历史分页顶部指示。

> **审稿状态**：☐ 待审　☐ 已批准（批准后写入 M2 待办；未批准前不得实现视觉细节）

## 会话交互的还原范围

| 项 | 当前原型与正式实现约定 |
|---|---|
| 流式与输入 | 生成期间可加入待发队列，停止按钮独立显示；停止不表示清空队列 |
| 逐条引导 | 按钮名“引导当前轮”，当前轮不可用时禁用；竞争失败保留任务；禁止还原为本地排序 |
| 归档 | 确认文案说明生成、待发与 pending 需先处理；空闲后归档，不隐式停止 |
| 队列暂停/继续 | 原型模拟入口不纳入本阶段交付；正式 UI 仅提供官方逐项编辑/移除/引导。断线或模型阻塞时保留未提交草稿，恢复后由用户重新发送，不承诺暂停 Host 已接收队列 |
| 延迟失败 | 原型独立显示失败内容并保留新草稿；正式逐条重试须有公开、稳定的失败标识，M1 未证实时不显示该入口 |
| 新增状态 | 首次发送取消/失败/部分成功、断线阻塞、模型阻塞、加载失败、管理失败、局部卡片故障均纳入对照 |
| 原型专属 | 模拟失败、恢复模型、演示标签与其他测试开关不进入产品 |

会话演示代码见 [conversation-demo.js](../../prototype/conversation-demo.js)，证据及旧截图适用范围见 [组合状态修订记录](../../prototype/validation/2026-09-17-组合状态修订.md)。`conversation-*.jpg` 是已有画面记录；涉及改动按钮或归档文案时以当前可交互原型为准，不使用旧画面进行像素验收。

## 开发者入口的条件呈现
