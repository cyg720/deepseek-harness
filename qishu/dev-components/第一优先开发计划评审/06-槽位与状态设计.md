# 第一优先槽位与状态设计

2026-09-20 修订。插件对应与迁移清单见 [12-官方插件对应与整改验收](12-官方插件对应与整改验收.md)。本页描述当前十包结构。

## 槽位声明与渲染

| 父 entry / 声明者 | 子槽 | 类型与作用域 | 贡献方 |
|---|---|---|---|
| root / qs-shell | qs.gate | single/root | qs-login |
| root / qs-shell | qs.chrome | single/root | qs-shell 顶栏 |
| qs.chrome / qs-shell | qs.brand.mark、qs.brand.name | single/root | qs-ui-brand |
| root / qs-shell | qs.sidebar | single/root | qs-ui-sidebar |
| qs.sidebar / qs-ui-sidebar | qs.nav | single/root | qs-sessions |
| root / qs-shell | qs.stage | single/root | qs-composer 的 Stage |
| qs.stage / qs-composer | qs.stage.body | single/session-maybe | 同包 WelcomePane |
| qs.stage / qs-composer | qs.stage.transcript | single/session | qs-transcript |
| qs.stage / qs-composer | qs.composer | single/session-maybe | 同包 Composer |
| qs.stage.transcript / qs-transcript | qs.stage.transcript.row | keyed/session | 同包基础消息行 |
| qs.stage.transcript / qs-transcript | qs.stage.interaction | chain/session | qs-approval(1)、qs-questions(2) |

| root / qs-shell | qs.status、qs.overlay | list/root | 布局状态条与提示宿主 |

一个 single 槽在 QS 组合中只有一个贡献者。跨包以 slots.inject 等待父声明；卸载父声明后子贡献撤销，重装后恢复。root 以负优先级遮蔽官方，不改为同优先级竞争；官方仍独立加载。

## 状态所有权

- qs-shell 拥有几何、开合、布局持久化和界面切换；通过 owner props 将 hidden/user 传给左栏，将 hidden/selected/setSelected 传给右栏。侧栏不创建第二份布局 store。
- qs-login 提供 qsAuth 与可选 useQsAuth。缺失登录插件显示故障面；未登录不渲染会话子树。登录只作演示入口，不构成 API 认证。
- Session 及 SessionInput 拥有会话日志、草稿、提交、队列、运行和错误状态；qs-composer 调用官方动作。无会话首次发送由组件持有取消令牌及预分配会话 ID，等待 create/open/输入机就绪后交接一次，失败保留草稿，不自动重发。
- qs-transcript 按 Session binding 保存阅读意图，按节点 key 订阅 source/processSource。loadOlder、hasMore/loadingOlder 来自官方 Session；前插保锚点、主动提交恢复跟随，后台增长不抢历史阅读位置。
- qs-approval 与 qs-questions 读取真实 pending；请求结算驱动清理，界面切换或卸载不等于批准、拒绝或撤销请求。单选载荷不混入旧自定义回答。
- qs-sessions 拥有本地置顶及菜单 pending；列表与操作结果仍以官方会话服务为准。旧菜单回包不关闭新菜单。

## 空会话与订阅

Stage 先判断当前会话是否存在，再渲染严格 session 的 qs.stage.transcript。欢迎与输入保持 session-maybe，无绑定时 inputActions 可缺省。稳定空源与快照缓存避免 useSyncExternalStore 无限重渲；不在每个流式行扫描原始事件窗口。

消息行接收父 entry 绑定的 keyed hooks；注册了子槽不代表自动继承父 hooks。审批/提问宿主显式传 pendingInteraction，chain 不依靠异常退位。

## 生命周期验收

验证全部十包装配、品牌/左右栏独立等待及卸载重装、会话插件卸载时转写和交互槽同步撤销、重装后唯一贡献恢复。真实 Web 回归覆盖登录、新建和继续发送、审批提问、流式、分页、主动跟随及官方切换。实际测试结果见 12 引用的报告；逐文件覆盖率与环境门禁单列，不用组件渲染通过代替。
