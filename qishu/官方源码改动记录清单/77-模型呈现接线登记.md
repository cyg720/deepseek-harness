客户端 modelDirectories 仍由官方 ui-model-selection 独占。本批未复制模型目录或修改 Host selectModel。官方命令装饰扩展至已存在且可用的客户端贡献，两个调用入口使用同一 UI 与附件规则，移除后回退原贡献。上游升级需保留这项装饰行为及其测试，并重生成客户端目录、核对新增包的源码路径与解析依赖。代码中的中文注释解释改动用途；纯 JSON 及生成文件由本记录说明。

定向测试已覆盖模型选项身份与推理强度、DOM 错误及子会话限制、插件装卸，以及官方客户端命令装饰回退。整体浏览器、逐文件覆盖率和所有 W10 能力未验收，不能将装配状态记为完整实现。详细后续结果见[131 记录](../PRD/1-AI工作台/复核测试/131-独立模型选择呈现接线.md)。二开包及其测试不纳入官方源码登记。
