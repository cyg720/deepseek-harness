# 第一优先遗漏补全：官方文件登记

2026-09-18。仅登记本次追加修改的官方原文件；QS 自有实现、测试、说明和笔记不列入本目录。

| 官方文件 | 是否必须改动 | 本次追加修改及影响 |
|---|---|---|
| [apps/web/tsconfig.json](../../apps/web/tsconfig.json) | 是 | 将交互闭环浏览器测试排除出 Client 编译程序，避免 Host 依赖进入 Client。 |
| [docs/config-catalog.md](../../docs/config-catalog.md)、[中文](../../docs/config-catalog.zh.md)、[配对记录](../../docs/config-catalog.i18n.yaml) | 是 | 重新生成并同步 QS 配置类型的源码行号引用，刷新双语校验记录。 |
| [pnpm-lock.yaml](../../pnpm-lock.yaml) | 是 | 固定 QS transcript 新增的官方 connection workspace 依赖，用于历史失败后的重连重试。 |
| [tsconfig.host.json](../../tsconfig.host.json) | 是 | 把交互闭环浏览器测试加入 Host 编译程序，确保测试获得正确的类型检查。 |

此处六个文件均已有总表条目，不增加官方原文件总数。回退时须同时移除对应 QS 测试或重连依赖，否则会失去类型检查、安装一致性或恢复功能。详细实现与测试证据见[第一优先遗漏补全与验收](../PRD/1-AI工作台/复核测试/16-第一优先遗漏补全与验收.md)。
