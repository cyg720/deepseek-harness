# 奇术 UI 设计规范

[English](README.md) | 中文

<a id="summary"></a>

## 概述

本规范用于统一奇术工作台、登录页及配套弹窗的编码实现，提取现有原型的设计，并区分已实现的数值与后续编码要求。本目录提供设计文档，不提供可安装的样式包、组件 API 或导入入口。

视觉基线为沉静绿色、克制的层次对比、细边框、小圆角以及对话区域的充分留白。对话是主要任务入口，导航和上下文工具为其提供辅助。

## 产品标识

产品中文名称为 **奇术**，英文标识为 **QISHU**。页面标题、登录文案、AI 署名、帮助内容与导出文档标题使用同一名称。Logo 使用现有圆角方块中的四角线形星标，复用 `brand()` 与 `paths.spark` 中的图形，不另画一套标识。

桌面顶部栏的 Logo 容器为 32 × 32 px、圆角 9 px，产品名字号为 18 px。登录故事区使用深绿色底上的浅黄绿色 Logo，产品名字号为 21 px。登录页固定配色与工作台可切换主题分别处理。

## 主题配色

以下为原型已定义的语义 CSS 变量。色值采用十六进制，八位色值包含透明度。组件按用途选色，不能因为某个固定色值在一种主题中看起来合适就直接使用。

| 变量 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#f9faf8` | `#1e2923` | 工作台背景 |
| `--surface` | `#ffffff` | `#26322a` | 顶部栏、面板、弹窗、输入框 |
| `--subtle` | `#f3f5f1` | `#2c3a2f` | 次级容器背景 |
| `--sidebar` | `#f0f3ed` | `#233026` | 左导航背景 |
| `--text` | `#263931` | `#e0e8d7` | 主要文字 |
| `--muted` | `#839086` | `#a0ad93` | 次要文字基色 |
| `--line` | `#e5eae1` | `#3b4838` | 分割线与边框 |
| `--accent` | `#355c47` | `#617f4b` | 主要操作色 |
| `--accent-soft` | `#e8eee3` | `#354b32` | 柔和强调与深色导航悬浮 |
| `--lime` | `#d8f38b` | `#d8f38b` | 品牌高亮 |
| `--danger` | `#b44838` | `#b44838` | 破坏性操作文字；深色模式继承该值 |
| `--shadow` | `0 12px 40px #233b2410` | `0 12px 40px #233b2410` | 已声明的阴影值；组件另有局部阴影 |

原型将 `.dark` 挂到 `body`，并同步设置 `color`、`background` 与 `color-scheme: dark`。弹窗和提示容器位于 `#root` 外，因此主题作用范围必须包含它们，不能只给工作台内部设置变量。

登录页固定色：故事区背景 `#152d25`、表单区背景 `#fcfdf9`、故事区标题 `#eef4e9`、高亮 `#d8f38b`、提交按钮 `#355a41`。工作台局部覆盖包括深色辅助文字 `#abbc99`、深色建议文字 `#b0c299`、深色上传边框 `#536648`。这些是已观察到的局部值，并非额外导出的设计变量。

正式编码要求为错误、警告、成功和禁用状态分别定义两种主题下的文字与背景配对。原型尚未定义完整的语义状态色板，深色模式继承危险色不代表所有深色错误状态都已具备足够可读性。

## 页面布局

页面保留一个主要工作区域。顶部栏承载全局标识和面板开关，左栏承载导航，中间承载当前对话，右栏承载辅助上下文。

| 区域 | 桌面基线 | 组成 |
| --- | --- | --- |
| 登录页 | 两列 `minmax(520px, 1.4fr) minmax(430px, 1fr)`；表单最大宽度 370 px。 | 左侧深色工厂插图，右侧独立浅色登录表单。 |
| 顶部栏 | 高 68 px；水平内边距 24 px。 | Logo、产品名、左栏开关；工作台切换与右栏开关。 |
| 左侧栏 | 宽 238 px；内边距 `21px 15px 12px`。 | 工作区、新建会话、置顶与最近会话；底部为最近应用、六类能力入口、账号及设置。 |
| 对话区 | 弹性宽度；内容最大宽度 690 px；滚动区水平内边距 30 px。 | 新会话显示欢迎语与输入区；已有会话显示消息，输入区位于滚动区下方。 |
| 右侧栏 | 宽 306 px；Tab 栏高 58 px；内容内边距 `23px 20px`。 | 工作区、待办提醒、日程安排三个 Tab；文件和当前项目位于工作区 Tab。 |

工作台占满 `100dvh`，对话内容、会话列表和右栏内容各自滚动。弹性子元素保留 `min-width: 0` 与 `min-height: 0`，避免长文本或滚动内容将面板撑出视口。收起时消除面板宽度，并使用 `inert` 禁止其中的控件继续获得焦点。

<a id="type"></a>

## 字体与图标

字体栈为 `Inter, "Microsoft YaHei", "PingFang SC", sans-serif`，控件继承字体。原型没有加载网络字体，Inter 仅在本机可用时使用。保留中文回退字体与 `font-synthesis: none`。

| 角色 | 实际字号／字重 | 用途 |
| --- | --- | --- |
| 欢迎标题 | `clamp(26px, 2.6vw, 37px)`／450；行高 1.45。 | 简短问候与任务邀请。 |
| 登录标题 | 31 px／550；故事标题 `clamp(35px, 3.3vw, 52px)`／500。 | 表单与故事区分别设置层级。 |
| 输入与消息 | 输入区 14 px；消息文字 13 px；AI 正文行高 1.95。 | 承载任务输入与较长回答。 |
| 导航与面板 | 会话、右栏 Tab、待办与日程标题为 12 px；能力入口与文件名为 11 px。 | 紧凑导航与辅助内容。 |
| 辅助标注 | 多数为 10–11 px；装饰性英文标识含 8–9 px。 | 这是原型现状；关键操作说明不能采用装饰性小字号。 |

图标使用 24 × 24 viewBox、无填充、1.7 px 描边、圆形端点与连接，并继承 `currentColor`。标准图标为 19 px，导航与文件图标多为 14–16 px。纯图标按钮必须有可访问名称，不能仅依赖悬浮提示。

<a id="geometry"></a>

## 间距、圆角与层次

复用组件尺寸，不将所有数值强行归入一套并不存在的间距网格。原型使用 7–10 px 的内部间隙、12–18 px 的卡片间距及 20–30 px 的页面或面板内边距。

| 元素 | 数值 |
| --- | --- |
| 边框 | 通常为 1 px 实线；上传区域使用 1 px 虚线。 |
| 圆角 | 标签 5 px；会话行 7 px；图标按钮 8 px；输入框及普通按钮 9 px；结果卡片 11 px；对话输入区 15 px；弹窗 17 px。 |
| 对话输入区阴影 | `0 8px 24px #41502d05`；聚焦时 `0 6px 24px #496b2610`。 |
| 弹窗遮罩 | 阴影 `0 25px 120px #23342433`；遮罩 `#1a2b224d`，模糊 4 px。 |
| 叠放顺序 | 移动遮罩 z-index 19；右面板 20；左面板 25；提示 100；原生 dialog 位于顶层。 |

<a id="components"></a>

## 组件规则

控件按用途设计，同一操作在各页使用同一外观。下列选择器用于定位原型示例，不代表公共组件 API。

| 组件 | 参照 | 行为与外观 |
| --- | --- | --- |
| 按钮 | `.btn`, `.icon-button` | 主按钮为强调色底配白字；次按钮为容器底配边框；破坏性操作使用明确文案和危险色。默认图标点击容器为 34 × 34 px。 |
| 登录字段 | `.field`, `.input-wrap` | 固定标签、前置图标及密码显示开关；字段最小高度 44 px，提交按钮高 48 px。校验错误在表单附近显示。 |
| 对话输入 | `.composer` | 内边距 `17px 16px 12px`；新会话文本域最小高 69 px，对话中最小高 53 px，最大高 150 px。附件在上，工具与模型在下，发送按钮位于右下。 |
| 会话导航 | `.session-row` | 单行省略；悬浮或聚焦显示管理入口；当前会话保持可辨识。置顶与选中是不同状态。 |
| AI 结果 | `.message`, `.result-card` | 用户气泡靠右，AI 回答靠左。结果包含来源、时间与状态，相关操作紧邻结果。 |
| 应用入口 | `.recent-app`, `.catalog-card` | 最近应用图标提供名称；目录卡片包含图标、标题、简短说明和一个主要入口操作。桌面目录为两列。 |
| 辅助控件 | `.right-tab`, `.todo-item`, `.calendar-day` | Tab 切换同一面板；待办将复选框与文字配对；日历选中态、事件标记与当天标记分别呈现。 |
| 弹窗与提示 | `dialog`, `.toast` | 弹窗宽 `min(590px, 100vw - 30px)`，宽内容使用 830 px 上限；最大高 88dvh。右上关闭，下方取消／确认。提示位于底部居中，不阻断操作。 |

<a id="states"></a>

## 交互状态

同时定义默认、悬浮、选中、焦点、禁用、加载、空白和错误状态。主题切换必须覆盖全部状态，包括弹窗中的控件。

| 状态 | 原型规则 | 编码要求 |
| --- | --- | --- |
| 深色导航悬浮／焦点 | `.session-row`、`.tool-link`、`.recent-app`、`.new-chat`：背景 `--accent-soft`、文字 `--text`。 | 覆盖 `:hover`、`:focus-visible`、`:focus-within`；当前会话悬浮时也必须保持深色。 |
| 浅色导航悬浮 | 会话背景 `#e4eadf`；能力入口背景 `#e2e9db`；最近应用背景 `#e0eacb`。 | 不能将这些浅色背景直接用于深色组件。 |
| 选中 | 浅色会话 `#e0e9d7`；深色会话 `--subtle`；当前 Tab 有 2 px 下边线。 | 持续选中状态不能依赖鼠标停留。 |
| 焦点 | 按钮／链接：3 px `#80a65c`，偏移 3 px；输入控件：2 px `#8ead80`，偏移 1 px。 | 保留可见焦点；对话输入区以外层聚焦边框替代文本域轮廓。 |
| 禁用／加载 | 禁用按钮透明度 .4，光标 not-allowed；生成中提供停止。 | 使用真实禁用语义，并显示明确的加载文字；不能只靠颜色表示状态。 |
| 空白／错误 | 空面板说明缺少的内容；登录错误使用 alert 区域。 | 提供下一步操作或修正方式，操作失败时保留已输入内容。 |

深色导航参照背景为 `#354b32`，文字为 `#e0e8d7`；[悬浮验证记录](../PRD/1-AI工作台/prototype/validation/theme-brand-report.json)中这组控件的文字对比度约为 7.57:1。该证据仅适用于已测控件，不代表整站无障碍审计通过。

<a id="responsive"></a>

## 响应式行为

按级联应用以下断点规则。面板初始可见性由 JavaScript 视口判断决定：宽度大于 700 px 时默认展开左栏，大于 960 px 时默认展开右栏。

| 视口宽度 | 最终布局变化 |
| --- | --- |
| ≥ 1600 px | 顶部栏 73 px；左栏 257 px；右栏 335 px；对话内容最大宽度 750 px。 |
| 1151–1599 px | 采用页面布局章节中的桌面基线。 |
| 961–1150 px | 左栏 213 px；右栏 274 px；对话区内边距 22 px；隐藏平台副标题与深度思考开关。 |
| 701–960 px | 右栏以 306 px 宽度覆盖工作区，位于 68 px 顶部栏下；登录页改为等宽两列。 |
| ≤ 700 px | 顶部栏 61 px；左侧浮层 238 px；右侧浮层 `min(306px, 90vw)`；侧栏互斥展开，并提供可点击收起的遮罩。 |
| ≤ 700 px 内容 | 隐藏登录插图，显示表单区品牌；应用目录单列；表单及对话输入文字 16 px；欢迎标题 28 px。 |

编码必须保证长名称、附件名称、弹窗操作和对话输入区不超出视口。触屏上的删除与管理操作无需悬浮即可访问。原型根据视口设置初始状态，但没有通用 resize 监听；正式实现需要明确验证实时调整窗口时的行为。

<a id="motion"></a>

## 动效

动效用于表达状态或连接，不能阻碍阅读与输入。侧栏宽度过渡为 .2 s；消息入场为 .25 s、上移 5 px；生成提示圆点以 1 s 为周期，相邻延迟 .2 s。

工厂 SVG 使用等距示意图、半透明 AI 控制台和连接现场的操作员。光点呼吸与虚线流动周期为 3 s，漂浮周期为 6 s、位移 5 px。两份样式均在 `prefers-reduced-motion: reduce` 下禁用动画；工作台同时禁用过渡与平滑滚动。

<a id="implementation"></a>

## 编码落地要求

将设计迁入应用代码时遵守以下要求。这些要求说明如何落地本规范，不代表本目录已经提供相应 API。

- 集中维护主题值和共享组件状态，复用上述语义角色；不要将原型重复覆盖规则或行内状态颜色复制到各个应用。
- 将主题作用于应用内容与浮层的共同祖先。切换主题或调整可见产品名时保留会话数据。
- 分离布局、共享控件和业务呈现。复用按钮、字段、弹窗、Tab、文件及消息展示规则，不为每页维护没有明确必要的变体。
- 使用语义按钮、输入、标签、Tab、弹窗、alert/status 区域及状态属性。关闭浮层后恢复焦点；隐藏面板不能获得焦点。
- 产品文案通过应用的类型化语言字典提供。文件名与用户消息属于用户内容，与 UI 翻译分开处理。
- 将真实加载、授权失败、数据不可用、结果为空和执行错误设计成独立可见状态。模拟成功提示不能替代这些状态的实现。

下例复用现有深色导航规则，需要配合上述主题变量和共享控件样式。这是样式参照，不是包导入示例。

```css
.dark :is(.session-row, .tool-link, .recent-app, .new-chat):is(:hover, :focus-visible, :focus-within) {
  background: var(--accent-soft);
  color: var(--text);
}
```

状态伪类必须附着在目标选择器本身；格式化或转换选择器时，不能意外引入后代组合符。

<a id="acceptance"></a>

## 验收清单

按下列清单验收实现。[原型浏览器记录](../PRD/1-AI工作台/prototype/validation/report.json)记录已有交互检查，不代表新增应用代码已经通过。

- 检查登录、新会话、已有会话、应用目录、弹窗、文件、待办和日程；支持切换主题的界面两种主题均需检查。
- 实际操作悬浮、选中后悬浮、键盘焦点、禁用、加载、空白与错误状态。深色会话和应用入口悬浮时不能变成浅色背景。
- 测试 390、700、960、1150、1440、1600 px 等代表宽度及各断点两侧。页面不能横向溢出，控件不能无法访问。
- 验证键盘导航、可见焦点、弹窗关闭、触屏管理入口与减少动态效果设置。
- 正式实现以普通文字至少 4.5:1 对比度为验收目标。逐项检查原型中的小字号文字及深色状态色，不能假设整套色板都符合该目标。
- 保存浅色、深色、悬浮与移动端截图以及实际执行的检查记录；主题变化与业务数据变化应相互独立。

<a id="dev-note"></a>

## 开发备注

无额外设计提案。运行时 CSS 导出、组件实现与应用 API 接入不属于本次文档提取范围。
