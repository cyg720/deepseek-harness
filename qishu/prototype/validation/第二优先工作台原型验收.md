# 第二优先工作台原型设计与验收

## 入口与范围

在[现有原型](../index.html)登录后，打开“交互演示 → 第二优先 · 工作台差异化（二合一）”。W1–W12 对应评审 V08–V19 和组件 C9–C20，覆盖合并的第三优先全部十二类能力。原有“第二优先 · 转写与诊断”的七组状态继续保留，见[诊断原型验收](第二优先原型验收.md)。

| 原型组 | 可评审的界面与交互 |
|---|---|
| W1 检查器与资料 | 文档、可交付物、附件、引用标签；文本/JSON/示意图片预览；无权限、失效与大小限制。 |
| W2 通知与反馈 | 运行/完成/失败、已读、完成通知、反馈失败保留与重复提交禁用。 |
| W3 工作区与文件 | 目录选择取消/确认、文件列表、预览、会话内定位提示、空/失败状态。 |
| W4 多面板布局 | 会话/检查器/作业并列，拖拽及向前移动，默认恢复、保存、刷新恢复、缺插件说明。 |
| W5 后台作业 | 进度、任务身份、结果展开、失败/断线说明，只读目录。 |
| W6 调度目录 | 状态、下一次执行时间与时区、空/失效/失败，只读目录。 |
| W7 目标管理 | 编辑、暂停/恢复、失败和冲突保留草稿、清除确认与取消。 |
| W8 子代理 | 父子关系、子会话切换、一次性只读与可续聊输入、父会话不可用、停止。 |
| W9 请求轨迹 | Chat/trajectory 切换、请求指标、上下文展开、历史缺窗、媒体限制。 |
| W10 设置与模型 | 七个分区、独立草稿、已保存值、失败重试、权限确认、只读和凭证引用说明。 |
| W11 外部系统 | 通用模拟授权、超时/权限不足、受保护读取、撤销；不收集凭证。 |
| W12 品牌与外观 | 复用奇术标识和主题，深浅色切换、窄屏和官方入口范围说明。 |

## 模拟与正式开发的界限

这些文件只用于设计评审，不是 Cordis 插件实现。正式开发仍须遵循官方呈现插件逐一对应 QS 插件，不能将该演示脚本搬入一个集中式生产插件。D/W 分类和七个设置标签不改变正式包职责。

原型只保存面板排序到独立的 qs-prototype-workbench-layout-v1 本地键；授权、设置编辑等为当前预览内样本，不接模型、真实目录、调度器或第三方。目录选择不修改原工作区，退出恢复原会话。没有提供文件上传、富文本编辑、任务取消/重跑或调度写操作的虚假入口。

设置具体字段、参数校验、加载时序与 Host/远端差异须参照官方实现细化。第三方接入对象和认证方案、真实受保护路由、文件权限、迟到请求、读屏器以及审批/提问叠加仍为正式开发验证项。上表提供十二类能力的交互提案，不等于全部生产分支完成或解除 M0 决策阻塞。
