# 样式、国际化与交互安全

## 摘要

一比一还原原型要通过官方表现层机制实现，同时保留键盘操作、主题、本地化、流式性能和官方界面共存。原型 CSS 和模拟脚本是设计参考，不是可以直接代替正式插件的实现。

## 样式所有权

官方 web-styling 规定 ui-theme 拥有共享 `--dsw-*` 令牌、语义 alias、字体、动效和浅深主题；ui-layout 应用主题快照。feature 消费令牌，不再创造全局主题。组件使用 CSS Modules/clsx，不引入 Tailwind 或另一个组件库，不散落字面颜色和主题分支。

| 细节 | 官方规则/机制 | 开发注意 |
|---|---|---|
| 局部变量 | 组件布局契约可使用局部 custom property | 不把共享色板藏在局部变量里规避主题 owner |
| 全局样式 | theme owner 负责；动态 clientBundle 可编译模块 CSS 或 inline 样式文本 | style 注入生命周期与 root 视图生命周期不是同一回事 |
| Elevated surface | shadow 包含细描边，按 elevation token 呈现 | 不叠加普通中性色边框形成双描边 |
| 中性分隔线 | 官方约定 0.5px hairline，状态色/虚线另有规则 | 不能把所有 border 一刀切改同一宽度 |
| 圆形/胶囊 | 对 full-round border-radius 配 round corner-shape | 避免全局角形平滑改变圆弧 |
| 动效 | 令牌化并支持 reduced-motion | 隐藏动画后仍应保留清楚的状态反馈 |
| Portal | overlay 跟随对应主题与应用根 | 不因挂到 body 丢主题或污染官方界面 |

以上是当前官方风格约束。qs 原型采用不同视觉时，应显式写出令牌映射和所有权，不可一边声明遵守官方主题，一边把第二套 body/html 全局规则散在七包里。

## 控件与国际化

先查 ui-primitives 的 component catalog。已有 Menu、Modal、MarkdownText、CodeBlock 等应优先评估复用；视觉差异通过其已有接口或明确的受控扩展实现。不可导入另一个 feature 插件内部组件，也不要为每包复制一套弹窗、焦点管理和 Markdown 引擎。

产品文字统一进入 typed locale 字典，通过 t 或已本地化的 primitive label props 传递。范围包括正文、aria-label、tooltip、placeholder、单位和状态格式化。primitives 自身没有默认语言回退，调用方要传完整 labels。

用户文本、模型内容、代码 token、路径、协议 option label 保持原值。不能把数据“翻译”后再回传 Host，也不能用中文显示字符串进行业务判断。

## 不可信显示内容

模型输出、工具输出、链接、文件名和问题 detail 都不是可信 HTML。MarkdownText 提供不可信 GFM/数学和链接处理能力；先复用并验证已有接口，禁止把流式字符串直接送入 innerHTML 或自行放开 URL scheme。

文件链接应走已有 resource/preview 能力，不能从显示路径拼接任意 file:// 或 Host API 地址。真实文件访问和权限由 Host 服务控制，前端过滤只影响呈现。审批详情未知时不伪造影响信息。

`DSH_CLIENT_*` 构建值会进入公开产物；不放 API key、认证 token 或服务秘密。静态登录不保存密码，也不提供安全隔离；浏览器入口开关不等于角色授权。这里只说明源码开发边界，真实身份能力按已有 authorization/connection 协议另行接入。

## 可访问性和响应式

- Tab 顺序与可见焦点；隐藏面板使用合适的 inert/卸载策略，不能只 opacity:0。
- 弹窗焦点约束，Esc 关闭后回到触发者；抽屉遮罩和触摸关闭路径可达。
- disabled/loading/error 状态有清楚反馈；异步错误能被辅助技术感知。
- 流式输出避免每个 token 强制播报整段历史；根据现有组件能力设计适当播报节奏。
- IME 输入、触摸、软键盘、200% 缩放、长标题和长代码块分别验证。
- 深浅主题与断点两侧检查，不只拍 1440px 的正常态截图。
- 跟随滚动保留用户阅读意图，加载历史不抢焦点。

## qs 样式的待确认边界

[奇术样式规范](../../styles/README.md)是设计资料，[第一优先计划](../../dev-components/第一优先开发计划评审/02-样式还原对照.md)要求还原该原型。M0 需将设计令牌映射到具体代码 owner：哪些沿用官方 alias、哪些仅在奇术根内覆盖、哪些需要复用 primitive 的视觉参数。不能仅因 qs 不在 client 目录，就跳过样式与可访问性规则。

切官方后要确认：奇术 CSS 不匹配官方节点、快捷键不拦截、弹窗不残留、官方主题仍正确。切回后确认状态保留；卸载七插件则另测 effect 清理。这是三组不同检查。
