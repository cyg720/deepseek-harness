# 授权中心0.4.0：反馈落实与交付验证

已依据用户填写的23项主反馈和7项补充反馈调整[需求正文](授权中心.prd.md)及[离线HTML](授权中心.prd.html)，编辑修订号7。原始PRD.md、DDL.md保持为输入资料；含用户反馈的原文、旧HTML、SQL及数据保存在[反馈版本目录](history/v0.3.1-user-feedback/授权中心.prd.md)。该目录的旧HTML尚未包含用户后填的反馈，以其中Markdown为反馈依据。

当前要求：一套系统一家企业；账号可关联多个部门，无主部门；应用授权组决定可见范围，用户取得的权限组决定功能操作；AppKey标识应用，接口和工具使用当前用户token。数据权限交给业务应用，委托和权限刷新删除。令牌30天、多设备、仅存摘要；首次登录改密，本人改密后旧token失效并重新登录；冻结暂停、解冻恢复仍有效token。自身日志保留3个月后自动删除，自身参数非空且立即生效，物理删除、version比较及北京时间秒精度同步到字段与验收。

配套[SQL](授权中心.schema.sql)按用户指定的全新库与`qs__auth__`前缀修订：14张业务表、1张默认分区、14个显式索引、168条列注释。委托表删除，账号组织关联新增；应用范围字段删除、令牌改摘要、数据库维护更新时间和版本。引用删除、日志月份截点、操作码分隔符、可见组数量等候选方案在第十二章保留，不当作用户已批准实现。

当前76条业务测试计划、30项现行验收、7项退役验收；旧测试编号保留追溯，不把已删除行为继续列为执行要求。10组数据的当前版本位于[测试数据/v0.4.0](测试数据/v0.4.0/authorization-fixtures.json)，baseline同步到该版本；旧数据保存在反馈版本目录。数据是接口测试上下文，不是已装载的数据库种子或可用登录凭据。
