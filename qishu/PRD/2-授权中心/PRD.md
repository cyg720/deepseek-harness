

## 一、鉴权中心

```
鉴权中心验证流程（验证应用授权接口）：

┌─────────────────────────────────────────────────────────┐
│  Step 1: 验应用身份                                      │
│  请求头 AppKey 是否有效？应用是否被冻结？                 │
│  无效 → 返回 401                                        │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  Step 2: 静态权限检查                                    │
│  用户是否通过【权限组_用户关联表】或【权限组_组织关联表】 │
│  拥有该 operation_code 的权限？                         │
│  无权限 → 跳转 Step 4（委托兜底）                        │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  Step 3: 数据范围检查（仅Step2通过时执行）               │
│  根据应用授权表中的 data_scope_type 返回数据过滤条件：    │
│  · SELF        → creator_id = {user_id}                │
│  · DEPT        → dept_id IN (用户所在部门)              │
│  · SPECIFIED   → dept_id IN (specified_org_ids)        │
│  （数据范围仅控制行级过滤，不控制按钮可见性）              │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  Step 4: 委托授权兜底（仅Step2无权限时执行）              │
│  查询委托授权表，必须同时满足：                          │
│  ① 被授权人匹配                                         │
│  ② 权限组匹配（含 operation_code）                      │
│  ③ resource_type 一致                                   │
│  ④ resource_id 在委托的 resource_ids 列表中             │
│  ⑤ 当前时间在 [生效时间, 失效时间] 内                   │
│  全部满足 → 放行，数据范围以委托中指定的为准              │
│  不满足 → 返回 403                                       │
└─────────────────────────────────────────────────────────┘
```

## 一、功能需求
      1、账号管理：
            操作：新增、编辑、删除、详情、列表
            备注：【服务账号只能通过 AppKey + AppSecret 或证书登录，且强制绑定 IP 白名单】
      2、组织结构管理：
            操作：新增、编辑、删除、详情、列表
      3、用户组管理：
            操作：新增、编辑、删除、详情、列表
            备注：【将跨部门的人合成独立小组】
      4、令牌管理：
            操作：登录、退出、刷新令牌、注销令牌
            备注：【Master-Token：正常登录使用，Scene-Token：场景登录使用，过期时间：1小时】
      5、参数管理：
            操作：新增、编辑、删除、详情、列表
      6、字典管理：
            操作：新增、编辑、删除、详情、列表
      7、操作管理：
            操作：新增、详情、列表
      8、权限组管理：
            操作：新增、编辑、删除、详情、列表
      9、权限组_用户关联表：
            操作：新增、编辑、删除、详情、列表
      10、权限组_组织关联表：
            操作：新增、编辑、删除、详情、列表
      11、应用授权：
            操作：应用注册、操作授权码绑定、获取应用授权明细、验证应用授权、应用授权刷新
      12、委托授权表：
            操作：申请委托授权
            备注：【鉴权中心的 验证应用授权 接口，在静态权限校验失败时，自动查询此表是否存在有效委托。】
      13、日志中心：
            操作：新增、详情、列表、自动归档
      14、开放能力：
            操作：获取令牌、注销令牌、刷新令牌、获取用户详情、获取用户权限
