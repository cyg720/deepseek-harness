# 目录双入口请求身份与采纳控制

日期：2026-09-23。推进 G10 的目录流程所有者；尚未装配独立原生/浏览式选择器，不能作为完整 W3/T43 验收。未提交、未推送。

## 已实现

qs-sessions 分别声明和消费 qs.workspace.hero.directoryFlow、qs.workspace.sidebar.directoryFlow。占用状态从官方槽注册表订阅；只有有实际流程贡献时才显示添加动作。两个入口共用一个 DirectoryFlow 控制器，以入口和请求身份区分不同实例，避免同帧重复提交、双入口同时选择及旧回调误结算。

选中 Host 路径后通过官方 workspaces.create 登记，再由 uiWorkspace.openWorkspace 导航。每次登记结果及最终 beforeOpen 均检查请求身份；取消或卸载不回滚已接受的 Host 登记，但禁止其带走当前选择。会话变化、显式会话/工作区导航以及选择器撤销均使待采纳请求失效。新请求不接受旧成功、失败、取消或登记完成回调。失败只保存可重试状态，不将远端诊断作为 UI 文本。
