# 子代理授权真实保存验收

日期：2026-09-23。范围为子代理模型配置卡的真实 Host 授权保存及刷新持久化；不是全部 W10、第二优先或全仓最终验收。

## 已验证行为

正式 Web 测试 profile 启动后，浏览器通过静态登录打开 QS 插件配置卡，从真实模型目录选择候选。等待 subagent-model-selection 的 settings/mutate 响应，并断言请求同时包含 enabled=true 与精确 provider/model 的 allowedModels，expectedRevision 为数字；断言 Host 成功回执中的允许路由与 UI 所选完整路由一致。整页刷新后重新打开卡片，启用状态及同一条完整模型路由仍被选中。

首次测试定位使用路由前缀，匹配了带后缀的其他模型而失败。已改为通过完整 provider/model 文本精确定位 checkbox，重跑通过。这是测试定位问题，不能通过选择第一个匹配项掩盖歧义。

测试使用 scaffold 隔离数据，不修改真实用户配置，不接入真实登录。原有 Shell/AgentLoop 保存、语言主题字号、导航与插件清单回归保留在同一真实 Host 场景。
