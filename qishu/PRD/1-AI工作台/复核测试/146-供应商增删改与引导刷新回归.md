## 浏览器确认的行为

新增真实 Web 用例，在隔离 Harness home 创建自定义 pi-ai 路线、指定协议、密钥和模型。通过真实 RPC 保存并检查设置与凭据文件，128K/8K 分别持久化为 128000/8000。修改供应商和模型名称后刷新，名称与协议保持，已存密钥不回显。

网络层中断一次 settings mutate 请求后，界面显示失败并保留供应商与密钥草稿；重试成功后继续流程。删除配置默认不勾选删除密钥，实际凭据仍保留；再次创建后明确勾选，删除对应凭据。另一独立凭据在全过程仍保留。测试不调用外部模型，所有密钥为合成测试值。

首次用例超时源于 getByLabel 对嵌套 select 标签的精确匹配；实际 ARIA 中控件名与协议选项正确。改为按 combobox 角色定位后通过，没有修改业务协议选项或放宽断言。

## 发现并修复的真实问题

对已完成配置后的页面刷新增加 MutationObserver，记录实际打开过的欢迎和凭据引导对话框。修复前用例失败，记录到 Internal Testing Notice 和 Set up DeepSeek 两个弹窗，证明确有短暂模态抢焦点，最终 DOM 不存在不能证明未闪现。

对照官方 WelcomeNotice 和 DeepSeekOnboardingDialog，奇术两个引导在权威状态仍未查明时暂不打开对话框；已确认时直接完成，读取明确失败则仍显示可重试入口。延迟出现的 dialog 在挂载后正确 showModal。修复后浏览器全过程没有记录到任何引导弹窗打开。
