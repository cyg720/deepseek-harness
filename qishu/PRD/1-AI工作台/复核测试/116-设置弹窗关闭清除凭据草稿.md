# 设置弹窗关闭清除凭据草稿

日期：2026-09-23。核对后续设置插件生命周期时发现：WebSearch 编辑器归插件持有，设置弹窗关闭只卸载卡片，不会卸载插件，因此旧实现可能在重新打开时保留未保存凭据。

修复：增加 clearSecret 动作，在 SearchCard effect 释放时调用。它只清除字面量及草稿引用，不清除公开配置草稿；在保存期间同样允许清除，不声称撤销已发送的 Host 写入。插件释放仍清理所有资源。

验证：DOM 测试断言卡片卸载调用清理；编辑器测试断言在途保存仍可清除明文；真实 Web 场景在凭据写入失败后关闭弹窗、重新打开，密码框为空，重新输入后只重试凭据，settings/mutate 总计仍为一次。
