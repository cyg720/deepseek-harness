# WebSearch 草稿与部分结果阶段

日期：2026-09-23。实现 search-editor.ts；可见 WebSearch 表单、注册和真实 Host 保存尚未完成。

编辑器消费官方 SettingsScope 和字段 schema 校验，支持 baseURL/maxUses 草稿、恢复继承、固定编辑版本及配置冲突阻止保存。凭据字面量仅留在当前表单实例，不写配置、持久缓存或日志。密钥空输入表示不修改，不代表删除 Host 凭据；凭据引用固定在首次编辑时，配置改变引用后阻止错写。

部分保存按明确回执清理：配置成功但凭据失败时清除公开字段草稿，仅保留密钥以供用户重试；重试使用当前配置版本且不重复配置操作。凭据成功清除明文。放弃、连接重置和释放均清除明文；旧连接回执不清除新实例草稿，保存期间不允许再次编辑。

新增四组回归覆盖真实组合载荷、部分成功局部重试、校验、继承复位、版本冲突、引用变化、明文清理、重复发送、旧回执、只读和缺失版本失败。配置包测试与四项覆盖率通过，日志 logs/repair-v1-search-editor-coverage.log；最终全仓类型与本次文件静态检查记录于 logs/repair-v1-search-editor-types.log、logs/repair-v1-search-editor-lint.log。
