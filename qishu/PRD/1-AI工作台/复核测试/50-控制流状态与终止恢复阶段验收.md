# 控制流状态与终止恢复阶段验收

日期：2026-09-23。对应 W5/C13 与 49 核查记录中的控制流前置。本阶段实现共享控制状态及终止恢复，不代表 QS 作业列表或 G07 通知已交付。

## 实现

ISessions.control 提供只读 state 和 retry。状态为 loading、ready、reconnecting、failed、disposed，baseline 记录已接收完整基线次数。唯一 SessionControlOwner 由官方根装配启动、等待卸载；官方 Gateway 继续自动处理载体中断，终止失败由所有者合并重试、等待旧消费者静默后启动替代流。旧实例回调失效；卸载中的重试不得重新打开流；处置拒绝时不启动竞争消费器，错误交给调用者。

不改 Host 线协议、任务权限或既有 jobsBySession 数据；原始失败保留诊断日志，不进入可读状态。官方目录新增二开实现和测试位于 qs 子目录。公共测试替身同步接口，不假设已经收到基线，也不伪造重试成功。官方原文件改动见 [34 登记](../../../官方源码改动记录清单/34-控制流恢复登记.md)，累计 134 个原文件、131 项保留修改、3 项已还原；不包含二开自有文件。
