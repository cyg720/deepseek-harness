# 模型设置跨界面同步与并发冲突验收

日期：2026-09-23。范围：官方与奇术模型设置的共享配置、反复装卸、两个页面的过期版本保护。本阶段不声明 W10 或第二优先整体验收完成。

## 真实浏览器行为

测试专用 model-settings.overlay.yml 开启开发者官方界面切换按钮，默认仍先进入奇术。没有改变生产默认配置。既有首次配置用例扩展为两轮 QS→官方→QS 根界面切换，每轮先从 QS 保存端点，官方模型编辑器读取相同值，再从官方 Apply 保存另一端点，返回 QS 后读取新值。两边继续使用同一 Host 和模型设置状态，密钥字段始终不回显。

另外开启独立浏览器页面，从官方模型编辑器修改同一个端点；第一个页面保留旧 QS 编辑器并提交不同草稿。真实 settings mutate 版本校验返回冲突，QS 明确提示关闭并重新加载，旧草稿仍在。直接读取隔离 Host 的 settings.yaml，确认并发页面的新值存在，旧草稿未写入。关闭、重新加载、重开后得到最新值。
