# 预设策略控件与设置区域接线

日期：2026-09-23。本轮将 121 报告中的策略写入器接入 QS 预设设置区域；尚未装配正式 Web，不代表第二优先整体验收完成。未提交 Git。

## 已实现

设置区域消费官方 settingsScope.describe 共享镜像，呈现默认预设和选择器开关。默认值按机器标识提交，开关提交布尔值，均携带用户操作时的版本。保存期间禁止重复操作，失败保留镜像原值，成功后重新读取 Host 生效目录。损坏预设禁用选择，未知的已保存默认值保持可见；只读连接与无效描述不产生可写控件，选择器关闭时默认下拉禁用。

插件重连废弃旧写入回执，并重新读取设置和目录。卸载释放写入器，控件卸载后旧结果不触发新页面刷新。界面使用 QS 样式令牌和中英词典；未添加真实登录，也未接入 W11。
