# 转写节点呈现修复

## 问题与处理

用户标注的四处异常源于 qs-transcript 只认识 user、steering、context、assistant-step，官方 system-prompt、turn-process、turn-tail 被分派到 JSON 兜底，且兜底 flex 行未约束 pre 宽度。context 同时直接输出完整指令正文。

对照官方 ui-chat 的 register-node-renderers、SystemPromptRow、ContextInjectionRow、TurnProcessNodeView 与 TurnTailChatData 后，在 qs-transcript 内补充类型分派。系统提示、上下文和思考内容默认折叠，正文保留完整文字，展开面板最高 240px 并自动换行；过程行显示已记录的活动摘要，尾部读取完成状态和可用的精确 Token 总量，不重复 closing/finalNode。未知扩展仍可展开检查，默认不输出原始 JSON。没有改变官方会话投影、上下文注入、模型请求或持久化记录。

## 验证

- 包级 TypeScript 编译和客户端 bundle 构建通过。
- 组件与映射测试：3 文件、14 用例通过，新增默认折叠/展开、尾部去重、过程摘要与未知详情回归。
- 构建产物测试：2 文件、4 用例通过。新增真实 Chromium 场景冷加载已有 fresh-round-trip 记录，通过正式 Web 组合与 QS 登录打开历史，验证 1771px 与 760px 视口下折叠、展开、详情高度及转写宽度；尾部文本增加 owner-local 快照。
- 当前 8081 服务的“AI助手身份介绍”会话：转写 clientWidth=750、scrollWidth=750，system prompt 1 条、context 3 条、unknown 0 条，默认可见正文不包含 controlAnchorSeq。
