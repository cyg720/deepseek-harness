## 媒体支持边界

支持文本与思考内容、官方 Markdown 安全渲染、HTTP(S) 图片及通过官方 API 加载的 POSIX/Windows 绝对路径图片。结构化附件/图片块、其他非文本内容仍不绘制画廊，但会显示可见限制提示并保留原记录；相对图片路径及正文文件引用交互尚未实现。浏览器测试确认未鉴权文件请求被拒绝；本轮未改写服务端文件权限。默认 workspace-write 的读权限不等于“禁止读取工作区外”，因此没有新增这种错误断言。

## 性能结果与限制

生产 FallbackRow 的合成 Node SSR 诊断：100 条 × 128 KiB 负载，关闭状态中位耗时 23.4803→0.3683 ms，序列化调用 100→0 次。完整原始样本、命令与负向控制见 [合成性能测量](08-合成性能测量.md)。这是组件 CPU 证据，不是浏览器交互延迟、内存基准或长会话全部性能验收。展开仍可读取完整内容，收起移除格式化展示文本，不删除持久化数据。

## 安全结果与剩余风险

js-yaml 4.x 统一到 4.3.2，sharp 0.35.3 升至 0.35.4。实际运行路径、维护者公告、安装校验、未升级依赖的利用条件与 34 条剩余告警见 [依赖安全修复](07-依赖安全修复.md)。当前没有因锁文件存在依赖就宣称漏洞可利用，也没有把未证实可达解释为没有漏洞。

静态演示登录仍是界面门，不是服务端用户鉴权；官方入口显示参数仍是开发者呈现配置。此次没有改变这些既定第一优先边界。
