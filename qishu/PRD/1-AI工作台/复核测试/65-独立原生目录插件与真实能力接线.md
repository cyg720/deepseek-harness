# 独立原生目录插件与真实能力接线

日期：2026-09-23。实现 ui-directory-picker-native 对应的独立 QS 包；W3/G10/T43 及第二优先整体仍未全部完成。未提交、未推送。

## 实现与组合

qs-ui-directory-picker-native 独立填充两个 QS 目录流程槽，OS 操作委托官方 uiWorkspace.pickDirectory，Host provider 保持唯一。Web 正式 auto 行在原生分支通过 additionalClientSurfaces 追加本包，浏览分支不挂原生 UI。组件按请求身份保留一次调用，StrictMode effect 重放不重复打开对话框；采纳阶段重装不会重新打开，关闭、更换请求及卸载拒绝旧回调。

取消 QS 入口撤销本地采纳，不代表主动关闭 OS 窗口；既有官方 Client 方法没有逐请求取消参数。测试通过 Host capability 替换 OS 返回结果，工作区登记、会话创建、Loader、Gateway 与浏览器保持真实。真实 OS 对话框的视觉、焦点和平台行为尚未验收。

## 测试发现及纠正

初始固定组合测试因 overlay 未使用 insert 而缺少呈现，随后发现 Web scaffold 在场景 overlay 之后强制 browse。加强替换前 capability.kind 必须为 native 的断言后，证实此前结果不能作为真实原生 provider 装配证据。现为 scaffold 增加目录组合选项，默认保持 browse；固定 native 插入官方 native provider 和官方原生呈现，auto 保留正式 bundle 的动态装配。最终测试使用这些真实组合；早期失败日志保留，不删除因此未到达的快照。

新增 Web 测试曾误纳入 apps/web Client 编译，造成 Host/Client 合并错误并在源码旁生成编译产物。已显式划归根 Host 程序，类型检查通过。按该失败编译的创建/修改时间窗口、未跟踪身份、source map 与原 TS 对应关系核查后，仅清除 508 个本次生成物；余下 18 个未跟踪 JS/声明文件是已有 QS CSS 声明和原型脚本，保留。清理路径证据在 logs/repair-v1-native-picker-artifact-cleanup.json。
