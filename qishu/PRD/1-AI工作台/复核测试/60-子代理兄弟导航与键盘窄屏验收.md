# 子代理兄弟导航与键盘窄屏验收

日期：2026-09-23。补齐 C16/W8 目录交互，并验证运行中子会话的停止与续聊；第二优先整体仍未完成。未提交、未推送，不接真实登录。

## 目录与键盘

新增目录所有者选择器，浏览祖先目录时不改变当前 Session。选择兄弟会话仍使用官方目录中的完整地址，切换目录根释放原目录及后代观察；重新进入另一个会话时重置目录范围。

健康记录的导航按钮支持上下循环、Home/End、右键展开或进入后代、左键收起或回到父项。诊断条目不参与导航；选择器及其他表单保留原生按键。目录使用原生嵌套列表和按钮，不声明 ARIA tree。Escape 关闭与焦点归还沿用已有行为。真实浏览器验证兄弟往返、后代焦点及 760 像素视口左右边界。

DOM 回归捕获并修正了一个焦点错误：不带 :scope 的后代选择器会因外层 ul 使当前按钮再次匹配，现只查找当前行直接分支内的后代。组合浏览器还暴露异步测试时序：展开后立即按第二次右键时目录未必到达；测试现等待后代可导航记录，再验证移动焦点，不增加固定延迟。

## 停止与继续提问

对照官方 InputBar 发现 QS 输入框在父级不可用时仍可编辑。现在可续聊子会话只有 parentAvailable 明确为 true 时才能编辑和提交；未知状态使用“尚未确认可用”的提示，不当作已离线。保留非空草稿，父级恢复后恢复编辑；运行中独立停止按钮不受此限制。组件回归覆盖 false、undefined、恢复 true、草稿保留、发送禁用及停止动作。

真实 Host 测试启动官方 continuable 子代理，以一个 hang 回放步骤保持运行；在目录响应中注入 parentAvailable=false，证明禁用输入、保留停止且未被只读组件错误接管。点击停止实际调用 subagents/interruptByParent，并断言没有调用 session/cancel；持久 turn/end 出现 aborted。官方队列预置一条待续输入用于保持暂停工作，撤销目录故障并重新打开子会话后，浏览器发送唤醒请求；两个真实回放调用依次输出排队答案和唤醒答案，断言输出顺序及 subagents/prompt 传输。

故障注入只改目录响应的可用性，不终止真实父 Agent，因此本场景不单独证明父执行者真实销毁后的服务行为。取消、排队、输入、持久记录和回放消耗检查均保持真实；三个回放步骤全部消费后测试方可通过，没有关闭消费检查。测试分别保留断言与清理失败，避免 finally 的回放不足错误掩盖原始问题。
