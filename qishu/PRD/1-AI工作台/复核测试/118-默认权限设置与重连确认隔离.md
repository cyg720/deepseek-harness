# 默认权限设置与重连确认隔离

日期：2026-09-23。延续 117 报告，实现独立 qs-ui-permission-presets 的新会话默认权限行；尚未接入正式 Web 装配，未提交 Git。

## 已实现

选项来自官方 permission.defaultPreset 动态 schema，支持常量和联合选项；缺失字段、当前值不在选项中或解析失败时不可写。界面沿用奇术设置行样式，包含加载、不可用、读取失败与重试、只读、保存中、已保存、冲突、未确认写入状态。

普通选择提交官方 settings.mutate，载荷为 permission 命名空间、defaultPreset 单字段 set 操作、选择时的 revision。完全访问必须另行勾选风险确认。保存新默认值不发送当前会话权限命令，提示明确作用于之后创建的新会话。

重连可能不改变设置 revision，因此风险确认同时保存连接代次。重连或版本变化关闭旧确认；控制器拒绝旧代次提交。保存和读取的迟到回执不得更新重连后或已卸载的状态；较旧的成功响应不得回滚已推送到共享镜像的新版本。远端错误原文不进入视图。
