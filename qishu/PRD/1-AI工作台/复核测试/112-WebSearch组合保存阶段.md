# WebSearch 组合保存阶段

日期：2026-09-23。新增 search-save.ts，未接入 WebSearch 表单，不代表完整设置或第二优先验收。

配置和凭据使用两个既有官方接口，不存在跨接口原子事务。组合保存器先执行配置原子写入，只有成功且当前凭据引用仍等于用户编辑时引用才写凭据；逐项返回 written/refused/conflict、未修改、未执行、引用变化等明确结果。返回值不包含密钥明文。

配置成功但凭据失败时保留配置成功事实，调用方可清除已成功字段，仅携带凭据草稿重试。该局部重试不会重复提交配置。保存期间拒绝重复提交，复制请求以隔离调用方后续修改；释放阻止后续凭据副作用，但不声称回滚已发出的 Host 写入。

四组新增用例覆盖真实操作载荷、调用顺序、配置冲突、部分失败、局部重试、无凭据草稿、引用变化、重复提交、调用方修改和两个阶段的释放时序。配置包测试和覆盖率通过，详见 logs/repair-v1-search-save-coverage.log；全仓 Host/Client 类型检查和新增文件静态检查通过，分别见 logs/repair-v1-search-save-types.log、logs/repair-v1-search-save-lint.log。

后续必须把逐项结果接入可见提示，并正确保留失败字段、清除成功字段；实现 baseURL/maxUses 输入、继承复位、凭据明文草稿生命周期、事件刷新与真实 Host 浏览器验收。本阶段未改官方原文件，无真实凭据写入，无提交推送。
