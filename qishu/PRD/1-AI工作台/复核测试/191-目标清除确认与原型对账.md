# 目标清除确认与原型对账

日期：2026-09-24。范围：第二优先 W7/V14 的清除目标确认。界面依据原型，业务动作复用官方 goalPresentation 与 Host CAS；本轮不代表全部 D/W 状态验收通过。

## 发现与修复

[异常矩阵](../../../dev-components/第二优先开发计划评审/07-视觉补稿与异常矩阵.md)的 V14 明确要求清除确认；[原型](../../../prototype/workbench-priority.js)的 clear-goal 动作打开确认框。QS GoalDock 原实现直接调用 onClear，缺少确认。官方 GoalBar 也直接清除，但不能用官方视觉交互覆盖 QS 原型要求。

[目标条](../../../../packages/qs/qs-ui-goal/src/client/GoalDock.tsx)现在使用工作台共用样式的原生模态，显示目标正文及保留会话内容的说明，初始焦点为取消。取消和 Escape 不调用接口；确认提交打开时捕获的 id/revision。若期间远端更新同一目标，由 Host CAS 拒绝旧版本；不自动改成较新版本。显式刷新后再次打开确认，显示刷新后的正文和版本。切换会话或目标身份丢弃确认；断线禁用确认。失败使用现有错误及刷新入口。

此处复用既有独立 QS 插件和官方唯一目标服务，没有新增服务、修改官方源码或调整原型。双语 README、字典及已有 QS Agent Note 同步更新；不向官方源码改动目录登记二开文件。
