# 独立模型选择呈现接线

日期：2026-09-23。W10 的独立 qs-ui-model-selection 已实现并装配，第二优先整体未完成；未提交 Git。

## 实现

独立对应官方 ui-model-selection，沿用原型输入区下拉布局，复用唯一 modelDirectories，不复制目录或调用模型 API。模型标识使用完整供应商/模型键精确查找，避免分隔符碰撞；同一路由保留已选推理强度，更换模型采用目标模型默认强度。动态呈现模型声明的强度，不把原型演示开关当作通用供应商能力。子会话隐藏绑定 Agent 的选择入口。

/model 入口使用相同目录。源码核对发现官方装饰器原本只作用 Host 命令，而 model 是客户端贡献，因此补充既有客户端贡献的装饰支持。原贡献的可用性仍先检查，菜单与裸回车采用同一有效 UI 及附件规则，卸载后恢复原贡献。官方改动登记在 [77 批](../../../官方源码改动记录清单/77-模型呈现接线登记.md)。
