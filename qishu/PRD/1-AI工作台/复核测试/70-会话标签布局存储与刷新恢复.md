# 会话标签布局存储与刷新恢复

日期：2026-09-23。工作区未提交。QS 座位已接入生产存储和官方恢复动作，W4 仍有明确剩余项，第二优先整体未完成。

## 功能

每个会话使用独立 localStorage 键保存版本 1 布局元数据，保留标签顺序、活动位置、分栏比例、浮窗矩形、展开及全屏状态。首次恢复通过官方 restore 动作一次提交；已有活跃布局优先，不被存储覆盖。不保存标题正文、导航参数、运行时身份或撤销历史。

恢复使用官方 parseFileAddress，并要求文件地址所属会话与当前会话相同，类型通过当前官方注册表识别且具有 QS 正文贡献。其他会话文件、无会话绝对地址、损坏地址、不支持协议、失效插件和同一栏的重复页面被剔除，显示固定本地化提示。资源是否仍存在和 Host 访问权限继续由官方资源提供者处理，布局校验不能代替 Host 授权。

浮窗限制在恢复时的实际视口内，分栏保留官方 20% 最小比例。损坏版本、存储读取或写入失败、超过存储上限均有可见提示，当前内存面板可继续使用。清除记录按钮仅删除本会话存储，不关闭当前标签或释放正在使用的资源。
