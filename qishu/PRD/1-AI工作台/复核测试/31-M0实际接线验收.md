# M0 公共接口实装与接线验收

日期：2026-09-20。基线：`dev-workbensh` / `906b6de1e2` 加当前工作区；未提交、未推送，未接真实登录。结论：公共接口和部分 QS 接线已实现，完整 M0 尚未完成，不能据此放行第二优先全部组件。

## 实际实现

1. Session Controller 增加必填 `historyLoad` 请求状态；不改 Session 持久格式、不改 `loadOlder/loadThrough` 的 `Promise<void>`。请求身份和连接代次约束旧结算；跳转合并显示最低目标。失败保留窗口，QS 显示本地化通用提示并允许手动重试，不输出原始错误对象。
2. 官方右栏提供 `sidebarRightPresentation`，官方座位复用同一 store、adoption 和 TabDomain；反馈提供 `messageFeedbackPresentation`，官方按钮和弹层复用同一 Surface。六类文档预览提供共享只读身份。上述公开面已实现，不等于对应 QS 业务呈现已实现。
3. Input Trigger 提供独占消费者策略。控制器创建后无租约不启用来源；官方挂载允许 `/` 和 `@`，QS 挂载只允许 `/`；释放撤销候选、迟到仲裁和同步回调编辑，旧 release 不影响新租约。结构化草稿在 QS 保留引用身份并只读，建议按钮也不能覆盖它。
4. pending 的声明和唯一渲染移到 Stage 固定 session 座位，不跟随转写滚动区域；行分派按实际有效槽贡献而非固定生产白名单，订阅提供引用稳定的快照。
5. 官方目录自动装配增加 `additionalClientSurfaces` 两分支配置及 schema；保持唯一平台判定和 Host。附加呈现与原 Host/Client 同一加载、回滚及卸载事务。配置门禁检查两个分支的静态包名和 manifest 依赖。
6. 修复实装时触发的两个生成问题：Client catalog 的 CRLF 字符串转义，以及 Typert 跨 Host/Client 面的已构建公开声明解析。后者只接受 manifest 声明且已加载的入口，不放开任意私有类型导出。

## 失败、环境限制与未运行项

- 扩大回归唯一失败：`packages/api/session-controller/tests/media-references.host.spec.ts:175` 的 `/api/file reads files and symlink targets outside the default cwd without a workspace registry`。本机 Windows 在创建符号链接时返回 `EPERM`，尚未进入该符号链接读取断言。未改成跳过、未用普通文件代替符号链接、未绕过安全测试，因此该场景仍未通过。
- `verify-cordis-config.ts` 全仓扫描报告 `apps/cli/tests/profiles/acp/cordis.yml: root must be a Loader entry array`；该文件本轮无修改。新增配置检测器的正/负向单测通过，不代表全仓配置门禁通过。
- 整图用例输出 fixture 未实现 inventory RPC、Connection 清理等警告，断言通过；不据此证明真实 Host 网络链路全通过。
- 未执行完整 M0 的真实 Chrome 双界面场景、30 次 production 性能样本、六类真实预览安全组合。未测项目不得继承原型结果或既有第一优先结果为“本轮通过”。
