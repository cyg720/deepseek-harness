# 供应商连接编辑与部分失败重试

日期：2026-09-23。范围：独立 `qs-ui-settings-models` 插件的供应商卡内连接表单。当前未装配到正式 Web；完整模型设置与 W10 仍未完成。

## 实现

供应商卡新增 DeepSeek/pi-ai 连接编辑，使用奇术卡片、主题令牌和中英词典；不支持的适配器显示部署配置提示。端点仅允许 HTTP(S)，清空只删除该字段的 user 覆盖。密钥只写，空输入保留原值；拒绝纯空白、赋值语句、包裹引号及非打印 ASCII。字段规则参照官方 ProviderEditor 和 apiKey，Host 仍负责最终验证与授权。

表单通过官方共享 operations 调用分步保存器，配置变更带原 revision，只提交端点或新增凭据引用，不重建命名空间。pi-ai 未配置的原生认证路线可以持久化空配置，使用密钥时记录派生引用。供应商配置定位变化会创建新的编辑实例。独立卸载保留在途 Host 操作的事实，但禁止迟到回执继续写密钥或更新编辑器。

配置成功立即采纳确认视图。密钥失败显示部分失败并保留草稿；重试按确认的 user/revision 生成差异，不重复提交已完成配置。已确认配置后关闭仍重新读取目录；无改动关闭不重读。已知只读状态禁用对应字段及保存操作。
