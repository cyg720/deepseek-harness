# 自定义供应商创建与乱序确认保护

日期：2026-09-23。范围：独立 `qs-ui-settings-models` 的自定义供应商创建。正式 Web 装配和真实浏览器验收仍待完成。

## 实现

从官方 `CustomProviderCard` 核对创建语义：标识以小写字母开头、允许数字与单连字符分段、不得与目录已有路线重名；需要 HTTP(S) 端点及至少一个有效模型。协议选项从官方设置 schema 的 providers 字典 api 枚举读取，不硬编码或在 schema 缺失时臆造协议。

创建卡支持名称、端点、协议、可选只写密钥、手工模型编辑和发现候选采用。创建前模型发现不传不存在的 provider 标识，仅使用端点、协议和可选临时密钥。单次配置写入带打开草稿时的 revision，路径为 providers.<route>。未输入密钥时不创建 apiKeyEnv，也不调用凭据写入。

配置提交成功后锁定已提交的路线字段；凭据失败只重试凭据，不重复创建。取消部分成功的创建会通知目录刷新。创建与已有供应商编辑共享密钥校验和官方操作服务，没有新增 Host 服务或接口。

## 乱序保护

复核发现创建确认可能晚于更高版本配置推送，直接采纳确认视图会使有效凭据引用退回旧版本。当前保留已观察到的最高版本，用其检查密钥写入目标。确定性回归模拟先启动创建、再收到版本 4 移除凭据引用、最后收到版本 3 创建确认；结果显示部分成功，且不向旧引用写密钥。
