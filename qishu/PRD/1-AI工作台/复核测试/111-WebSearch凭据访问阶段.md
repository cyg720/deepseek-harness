# WebSearch 凭据访问阶段

日期：2026-09-23。本阶段实现配置卡内部凭据读取与写入，不代表 WebSearch 完整功能已完成。

## 已实现

credential-access.ts 消费官方 credentials.describe/set。仅保存引用、配置状态、可写性和加载/提交状态，不读取旧密钥明文，也不将新密钥或 RPC 原始错误发布到可观察快照。缺失引用的可写性按照官方逻辑由 Host 判定，未加载或明确只读时不写入。

本次 set 的明确回执决定写入结果，旧密钥 configured=true 不能证明新密钥成功。成功写入后刷新徽标失败，保留写入成功事实但将状态标为读取失败。引用切换或卸载会使旧写入及其后续读取回执失效；已经发出的 Host 写入无法被本地释放撤销。

## 验证

四组可控异步测试验证：已有凭据下的新写入拒绝、传输失败、成功写入后的读取失败、引用切换、重复提交、卸载、旧读取逆序、只读、缺失引用及写后复查期间切换引用。

配置包 9 文件、24 用例通过，四项覆盖率 100%，日志 logs/repair-v1-credential-coverage.log。新增访问器及前三组测试曾通过全仓类型和静态检查，最后一组测试的检查以最终 types/lint 日志为准。没有使用真实密钥或外部服务。
