# 供应商模型列表编辑与恢复继承

日期：2026-09-23。范围：独立 `qs-ui-settings-models` 的手工模型列表编辑。模型发现、自定义供应商创建、引导、正式 Web 装配仍未完成。

## 实现

参照官方 DeepSeekModelsEditor 和 ModelListEditor：支持增删模型、标识、显示名称、上下文容量和最大输出 token；容量输入接受十进制 K/M 简写，空白表示移除逐模型覆盖。空标识、去首尾空白后重复标识、非正整数和超出安全整数范围的容量阻止保存。标识和名称保存前去首尾空白。

草稿保留原模型记录，编辑可见字段不会丢失未知属性。模型数组仅在显式编辑后成为用户覆盖，保存仍通过官方 settings 操作；整个模型数组作为单字段写入，与其他命名空间字段隔离。恢复继承显示 namespace.base 或 schema 默认值，并对 user.models 提交 unset，不复制仍含用户覆盖的 effective value。

## 本轮发现并修复

真实载荷断言发现：配置成功、密钥失败后，Host 回传对象字段顺序不同，JSON.stringify 比较会将已提交模型再次视为有差异。修复为配置确认时清除本批模型修改标记；在途表单禁用编辑，后续新编辑重新设置标记。凭据重试不重放已提交数组，且不依赖对象键顺序。测试先失败，修复后通过。
