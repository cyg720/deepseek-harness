# 轨迹阅读状态恢复

日期：2026-09-23。阅读状态恢复已实现，完整第二优先仍未验收，未提交。

## 实现

轨迹插件按官方 SessionBinding 对象在 WeakMap 中保存 scrollTop、请求展开序号集合与历史展开序号集合。不同会话不共享状态；缓存不持有正文、附件字节或第二份会话模型。轨迹重新挂载时首帧恢复展开内容，再恢复滚动位置，避免内容收起导致高度变化。

滚动监听在 layout effect 中注册并在卸载时移除；清理不读取已由聊天接管的滚动容器。首次进入轨迹从顶部开始，聊天保留其原有独立位置逻辑。阅读标签固定在阅读滚动区顶部，使用户切换视图时无需先滚回顶部。

当前恢复基于相同已加载内容和展开状态下的像素位置，不等同于在异步图片尺寸变化或前插历史时保持同一文本锚点。插件完整卸载后不承诺恢复旧实例内存。流式中间态、完整节点、长历史性能及其他 D/W 功能继续保留。
