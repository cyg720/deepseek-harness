# 模型发现候选与过期响应隔离

日期：2026-09-23。范围：独立 `qs-ui-settings-models` 的 pi-ai 模型发现及候选采用。自定义供应商创建、引导和正式 Web 装配未完成。

## 实现

参照官方 ModelListEditor 与 LlmModelDiscoveryRequest，使用现有 `operations.discoverModels` 查询。供应商编辑表单提供路线、当前端点、协议和可选未保存密钥；清空端点时传入已知部署端点，没有已知部署端点则保留路线查询方式。服务可按其路由目录返回模型，查询不等于网络连通性测试。

候选按模型标识去重，可按标识或名称筛选、切换当前筛选项、逐项勾选及关闭。已有模型默认不选且不能重复采用；筛选批量切换不会丢失隐藏项选择。用户明确添加候选后仅更新草稿，仍须保存才持久化配置；查询本身不写配置或凭据，未保存密钥仅用于本次查询。

端点、协议、路线、密钥或操作服务变化会失效此前请求；卸载后的成功和失败回执均不影响新视图。采用时再次检查当前草稿，避免查询期间手工添加的模型被重复加入。远端错误只呈现通用失败提示，空结果可见，失败保留手工添加和重试入口。
