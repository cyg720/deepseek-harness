# 子代理独立插件与真实目录导航

日期：2026-09-23。范围为第二优先 C16/W8 的独立插件与基础真实目录导航，不代表 C16 或第二优先整体完成。W11 仍按用户决定延期，不接真实登录；未提交或推送。

## 已实现

新增独立 qs-ui-subagent，对应官方 ui-subagent。两项贡献分别为会话标题的目录/谱系导航、输入链中的只读呈现，均按 slots.inject 等待宿主声明并随卸载撤销。单独 Host 入口不创建会话执行者。Web bundle、resolver、Client 编译、源码别名及生成目录已接入。

目录直接订阅官方 Session 列表；导航使用目录返回的 parentSessionId、childSessionId、mode 完整地址。只在展开时观察后代目录，收起、切换或卸载均释放观察。加载、失败、空目录、父级不可用分开呈现；损坏、版本不支持及不可读取条目不可导航，递归和祖先链的循环引用不继续展开。原生按钮支持 Tab/Enter，Escape 关闭并恢复入口焦点，外部点击关闭。

输入条件逐项对照官方 selectReadOnlySubagent：one-shot 接管为只读；continuable 的父级明确不可用且当前未运行时接管；未知可用性不当成离线；仍运行时让出接管，保留普通输入区的停止操作。权限判断仍由官方 Host 与输入服务执行。

## 中间失败与修正

生命周期夹具最初重复提供 sessions 服务；已改为使用测试运行时自带的唯一 Session 所有者并对动作作调用断言。只读条件使用官方类型，未用运行时断言掩盖接口问题。Host 编译发现 snapshotSubagentDescriptor 的两个重载不能直接接受联合 mode，现使用明确的模式分支。

浏览器最初通过尚未同步的标题选择父会话；改为按持久标识选择且先明确恢复父级。第二次精确匹配用户消息失败，页面证据确认历史实际存在：用户气泡内还包含复制按钮文案，现限定转写区域匹配内容。返回父会话后的 textarea 通用定位同时匹配反馈表单，已改为准确的 qs-composer-input。没有删除失败断言、改变业务状态或伪造浏览器服务以取得通过。

文档检查发现中文开发备注标题、配置目录中英文条目未同步和模型体验说明缺少具体事件名，均已修正后重跑完整门禁。

## 剩余工作与质量界限

C16 仍需要真实运行中的停止/父级离线组合、可续聊发送、兄弟快速导航、目录指标、与官方树键盘操作的功能核对和窄屏实测。当前组件使用嵌套列表及原生按钮，不宣称已实现官方树的 Arrow/Home/End 导航。目录运行/未运行表示实时活动，不伪造成功、失败或完成进度。

本次没有新增外部运行时依赖；共享官方 Session 的请求代次、观察和导航。未进行新一轮完整安全公告审计、全仓覆盖率或合成性能基准，不以本包测试替代这些门槛。第二优先其他剩余功能沿用任务清单继续推进。
