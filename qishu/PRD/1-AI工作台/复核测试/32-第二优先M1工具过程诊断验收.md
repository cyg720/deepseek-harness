## 与原型（V01–V03）的对应与差异

| 原型状态 | 实现情况 |
|---|---|
| V01 运行中/成功/失败/已中断/缺调用/空结果/未知媒体 | 已实现。状态由官方语义判定（`interrupted` 归“已中断”）；缺调用给出说明并不补名称/参数/耗时；空结果与非文本结果各有可见说明；未知内容只输出转义文本 |
| V01 八类工具子呈现 | 已实现为八个子插件，键与官方 wire 名一致；`bash`/`pwsh` 等族内共用呈现但各自注册 |
| V01 「缺调用」态的行内「查看更早历史」按钮 | **未实现为行内动作**：分页入口仍是转写顶部既有控件（同一视口可达）。不在工具行内造第二套历史动作，也不伪造跳转 |
| V02 当前轮/步骤、多活动、结束折叠、展开、失败无答案、停止、指标缺值 | 已实现。坐标为「第 N 轮 · 步骤 M」（答案未定时不给步骤号）；活动只报已记录计数；指标缺值显示「暂无数据」 |
| V02 展开过程只显示计数 | 展开显示计数与提示；具体过程由下方各条持久行呈现（不复制最终答案） |
| V03 scheduled/started/cancelled、保留部分输出、原因展开 | 已实现。阶段取官方 `retryState`；原因折叠显示已有代码与消息（脱敏后为空时只显示代码） |
| V03 重试耗尽后失败 | 由本轮 `turn-error` 行陈述（官方数据里耗尽不是重试行的状态），重试行不自行宣称耗尽 |
| V03 无倒计时、无按钮 | 已实现：不设置本地计时器，失败页不提供重放或重新执行入口 |

## 未覆盖与阻塞（不得当作已完成）

- **M0 的正式接线缺口不因本报告解除**：G01/G02/G04/G05/G07/G10/G11 的 QS 消费者仍未实现；真实登录、真实 Chrome 双界面、30 次 production 性能样本、六类真实预览安全组合均未执行。

- 过程折叠只隐藏“已结束轮的过程成员”与恢复显示，不含多面板联动、跨会话并排或视觉签收；桌面/窄屏/键盘焦点逐组复核仍未做（07 的要求）。
- 计划里的 C1「检查器定位」「工具动作」等能力未在本里程碑出现，工具卡不提供任何执行动作。
- 逐工具视图按官方**持久字段**校验，未复刻官方全部展示细节（例如 bash 的持久壳会话卡、搜索的转存路径解析）；这些差异记录在包 README 的“已知限制”。
