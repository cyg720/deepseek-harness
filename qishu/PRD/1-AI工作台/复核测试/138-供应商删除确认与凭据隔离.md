# 供应商删除确认与凭据隔离

日期：2026-09-23。范围：独立 `qs-ui-settings-models` 内的供应商删除确认及重试。正式 Web 装配和真实 Host 浏览器验收仍未完成。

## 实现与差异

参照官方 ModelsSection.removeProviderProfile 的先凭据、后配置顺序，配置使用精确路径 unset，不重建命名空间。QS 确认区域显示供应商名称和路线 ID，明确移除的是用户配置，部署配置可能重新生效。配置删除带已读取 revision，冲突不当成成功。

默认保留凭据，因为配置条目不证明密钥独占归属。只有引用等于供应商约定派生名称、凭据确认已配置且可写、目录中没有其他供应商显式引用时，才显示用户可选的密钥删除复选框。此检查只覆盖当前已知供应商目录，不宣称发现所有外部密钥使用者；用户仍需明确选择。未选择、非约定引用、只读或共享凭据均不发送删除密钥 RPC。

凭据拒绝或传输失败不删除配置。密钥已删除而配置失败时显示部分失败并保留重试；同一确认实例不会重复已经确认的凭据删除，避免删除重试前重新写入的密钥。关闭部分成功确认会刷新目录。单实例在途操作拒绝重复提交；卸载后不继续第二步，也不根据迟到响应关闭其他视图。已发送的 Host 写入不能撤销。
