## 已验证行为

使用正式 Web 装配与 QS 页面，官方录制回放仅替换外部模型。Host 配置初始默认 ptc 并开启预设选择；无会话时在 QS 选择 standard，不产生预设选择 RPC。用户提交录制输入后创建真实会话，可控 Promise 暂停选择 RPC，确认 prompt 请求为零、输入只读且显示取消本次发送。

放行真实选择请求后，Host 返回成功，第一条消息自动继续且 prompt 请求仅一次。等待真实 turn/end 并读取持久日志，确认 standard 的 agent-preset/selected 先于用户主动消息；用户主动消息只有一条，文本载荷与原始输入完全一致。上下文注入按官方 source.kind 与用户主动消息区分，不将它误报为重复提交。

初稿误查等待期间的发送按钮，实际产品此时显示取消发送；另一处误将全部 user/message 都当作用户主动消息。已按照实际 UI 与官方消息来源契约修正测试，保留 RPC 次数、提交顺序及精确载荷断言，不改生产逻辑来迎合测试。
