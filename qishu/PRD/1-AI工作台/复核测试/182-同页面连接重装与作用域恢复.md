# 同页面连接重装与作用域恢复

日期：2026-09-24。真实浏览器补验收发现两个生命周期问题，均已修改源码；最新组合的浏览器 9 项全部通过，包含控制台零错误断言；最终全量覆盖率退出 0；1,457 文件通过、11 跳过，23,532 测试通过、1 预期失败、125 跳过，门禁统计范围四项均 100%，404.59 秒。第一项修复单独验证通过不能替代第二项追加修复后的最终结果。

## 场景与缺陷

测试保持同一文档，通过一次受控 SSE 构建通知进入官方 HMR 实现；bundle 加载、Cordis 插件卸载重装、HTTP 与 WebSocket 仍是生产路径。测试不刷新页面，不重写共享构建文件。证据要求旧 WebSocket 关闭、新 WebSocket 打开、文档标识不变，重新选择历史会话后任务可由运行变为完成，且只有一次完成通知。

第一项缺陷：连接级联卸载使会话作用域适配器短暂消失，`ScopeProvider` 抛出 `SlotAssemblyError`，异常越过条目错误边界销毁 React 根，最终页面正文为空。负向浏览器日志：`logs/repair-v1-same-page-connection-diagnostic-fixed.log`。受控 DOM 回归修复前 1 失败、1 通过，日志 `logs/repair-v1-scope-remount-negative.log`。

修复保持初始缺少适配器时报错；已经安装过的适配器被撤销时，卸载其绑定子树并断开旧数据源订阅，外层继续监听名单，重装后恢复绑定。组件本地状态不承诺跨已卸载子树保留；测试允许本地静态登录插件级联重装后在同一文档重新登录，不把页面导航当作恢复。

第二项缺陷：进一步断言控制台没有错误时，旧检查注册表的异步清单发布仍在连接释放后发送，产生 `syncInspectManifest has no active Connection`。负向日志为 `logs/repair-v1-connection-console-quality.log`。注册表现在随提供它的插件释放；排队发布不再执行，本地查询取消且迟到结果不再回传。已被 Host 接受的 RPC 不会撤销；只有已释放实例的迟到失败不再报告，活动实例错误继续可见。
