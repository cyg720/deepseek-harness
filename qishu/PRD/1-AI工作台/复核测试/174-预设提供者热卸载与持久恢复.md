# 预设提供者热卸载与持久恢复

日期：2026-09-24；工作区 HEAD `4904755062`。本批修复真实发现的 Host 生命周期缺陷，不宣称第二优先整体验收完成。

## 已复现的缺陷

真实浏览器将预设选择 RPC 暂停在发送准备阶段，通过真实 Loader 禁用 `@deepseek-ai/dsh-agent-presets` 条目，再释放请求。草稿保留且没有提示词发送。恢复同一 Loader 条目后，界面选择值可以短暂改变，但实际 RPC 返回 `gateway/internal`：`scope key is already bound to a parent; re-linking requires the binding returned by the original bind`。原始失败保存在 `logs/repair-v1-preset-provider-recovery-probe.log`。

原因是 Agent scope 可长于提供者实例；scope 的父级仍有绑定，而新服务实例的私有 WeakMap 丢失了原绑定句柄。单看下拉框值会误判恢复成功。首轮用例另有未打开设置页就查找刷新按钮的测试问题，已修正，日志保留；它不是产品缺陷。

## 修复及边界

二开 helper `packages/preset/agent-presets/src/qs/scope-bindings.ts` 以稳定 Loader 条目为所有者保留绑定表，条目和 Agent scope 都是弱引用键。官方服务使用同条目原先授予的重绑定句柄；其他 Loader 条目和直接装配实例不共享权限。scope 的单次绑定及循环检查不变，不开放任意重绑定。

恢复后的选择仍受空白会话检查约束。此批不承诺提供者缺失时保留活动能力，不向新建的不同条目迁移所有权，也不为已开始轮次的会话更换组成。实际恢复路径为提供者恢复、设置页刷新目录、显式重新选择，不通过刷新整个页面清除现场。
