# 模型双界面与同步命令弹层

日期：2026-09-23。第二优先整体仍未验收，未提交 Git。

## 缺陷与修复

真实浏览器发现官方输入框的裸 /model 回车没有保留模型菜单。源码确认客户端命令在 adjudicate 调用内同步打开弹层，原输入壳在命令执行后关闭弹层，导致新菜单立即消失；异步 Host 命令不一定复现。将旧弹层及触发菜单的清理移到提交状态进入锁定后、执行副作用前，保留同步打开的新菜单。没有新增等待时间或改变 Host 接口。

新增 tests/qs/submit-popup.client.spec.ts 覆盖同步和可控延迟两种命令打开方式，断言弹层保留且普通消息 sink 未调用。临时恢复原清理顺序时，同步用例失败、异步用例通过；随后恢复修复代码。原顺序复现日志为 logs/repair-v1-model-dual-red.log。

浏览器夹具通过真实工作区入口准备空白会话，以当前选中行定位会话，避免假定列表第一行就是当前会话。模型目录没有保证提供描述，断言供应商名称及实际选择回执，不假设描述存在。
