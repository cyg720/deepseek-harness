# 模型设置共享访问服务

日期：2026-09-23。本轮只完成独立 QS 模型设置插件的复用前置，不宣称模型设置界面已交付。未提交。

## 接口与架构

官方 ui-settings-models 在内部创建 ModelsSettingsStore、ModelsOperations、SettingsSchemaOperations 和 WelcomeNoticeStore。新增 modelsSettings 访问服务公开这四个已有对象；官方页面继续使用原对象，未来 QS 插件通过 Cordis inject 消费服务。服务不重复读取供应商、配置或凭据，不创建第二份欢迎确认状态。原型控制 QS 视觉，官方实现控制 API 与业务规则。

访问类位于官方目录的 src/client/qs/access.ts，符合二开隔离；原 index.ts 只负责发布既有对象。访问服务随官方 fiber 释放，依赖它的呈现会卸载；官方重装时依赖呈现获得新实例。

## 已执行验证

真实 Cordis Context 回归断言访问面与官方槽注入的 controller、operations、schema、welcome 严格同一对象，状态初始 idle。测试消费者在卸载后释放，服务不可再获取；重装后消费者收到新对象，旧 controller 和 welcome 不复用。官方模型设置全部 9 文件、238 用例通过。根级 Host/Client 类型检查、定向 lint 及 ui-settings-models 的 tsdown 构建通过。

生成器首次拒绝未归属的 Client 服务，已按既有 Client 服务规则明确文档 owner，不混入 Host 服务目录。服务目录生成器最终成功，97 个产物核对后无需写入。完整 doc-sync 34 项通过、0 失败、0 跳过，用时 55.29 秒；相关文件 git diff --check 通过。日志为 logs/repair-v1-model-settings-access-*.log。本轮没有运行完整 QS 覆盖率、浏览器或全仓全量测试，不作为整体验收。
