# 轨迹用量、首字延迟与阅读键盘验收

日期：2026-09-23。前一轮属于实际进展：新增独立轨迹呈现、修正文档与浏览器失败并记录了未完成范围。本轮继续 W9，不改变第二优先总体范围，未提交代码。

## 已落实

请求卡增加输入、输出、缓存读取、缓存写入和推理 token 计数，读取官方 RequestView.usage。字段缺失、非数字、非有限数或负数均显示“未记录”，不以 0 代替；真实 0 原样展示。未将供应商缺失项用其他指标推算。

首字延迟读取官方 trajectory target 内助手消息的 timing，按 request.resultSeq 对应消息 seq 关联；仅在 stepStartTime 和 firstTokenTime 均已记录时取差值。失败重试没有结果时不会借用同轮次/步骤后续成功请求的时间。无结果或时间缺窗显示未记录，不以总耗时代替首字延迟。当前运行中尚未形成结果节点的首字延迟不实时显示。

阅读标签按照原型采用手动激活：左右方向键循环移动焦点，Home/End 跳到首尾，Enter/空格经原生按钮激活。移动焦点不会卸载正文、激活 target 或更改草稿。标签使用单一 Tab 入口并与阅读 tabpanel 建立 aria-controls/aria-labelledby 关系；视图卸载后仍有可进入的标签。

UI 外观继续以 qishu/prototype 为准；本轮复用官方数据类型及已有 target，不改为官方界面。不新增官方服务或第二份数据投影。
