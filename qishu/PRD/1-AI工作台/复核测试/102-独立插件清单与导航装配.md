# 独立插件清单与导航装配

日期：2026-09-23。新增 qs-ui-settings-plugin-inventory，并将其与 qs-ui-settings-plugins 分别装入 Web；未提交。第二优先整体仍未完成。

## 已实现

清单通过 remote.pluginInventory.list 延迟读取，父设置区只拥有动态标签与页面保留逻辑。清单提供全局及代理预设分组、完整模块名与条目标识、全局失败项优先、启用与条件状态、运行阶段、搜索、跨预设跳转和坏预设提示。没有预设目录时仍显示全局清单；所选预设不可用时回退到默认或首个预设。null Fiber 状态明确显示“未观察到运行状态”。

页面使用奇术令牌和原型卡片/表单样式，700px 以下单列。条件及元数据均按 React 文本渲染，不执行表达式；RPC 失败不直接输出原始错误。读取失败可重试，旧 effect 的成功和失败都不会更新新页面。清单不提供启用、禁用、卸载或凭据写入。预设名称委派官方 display 辅助，用户名称保持原样。

清单是读取时快照；已访问标签隐藏时保持状态，关闭设置会卸载页面，重开再读取。四类配置卡未完成，不能把本次只读清单交付当成插件配置功能完成。
