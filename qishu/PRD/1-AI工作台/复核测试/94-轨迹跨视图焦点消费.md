日期：2026-09-23。轨迹侧已消费官方跨视图工具定位请求；QS 工具卡的发起入口仍待接线，未提交。

## 实现

官方 ConversationViewRequest.focus 在 trajectory 中表示工具调用 ID。消费端先查已加载工具结果及其子调用，再查运行调用，最后查只有助手调用块的历史；不把调用 ID 解释为请求序号。

找到目标后展开祖先链与所在历史记录、移动焦点并滚动，再调用 completeViewRequest。确认后保留可由用户收起的展开状态。缺窗时显示提示且不确认，后续历史加载使目标出现后自动完成。调用 ID 使用属性值比较，不拼接 CSS 选择器，含引号或方括号的 ID 同样有效。

内容呈现抽到 Content.tsx；运行工具与历史子调用共用 ToolCall.tsx，避免两套递归展示和循环模块依赖。历史工具结果补出其嵌套子调用。
