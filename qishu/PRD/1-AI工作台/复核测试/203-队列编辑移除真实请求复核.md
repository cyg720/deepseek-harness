## 编辑网络失败与恢复

新增一次真实浏览器 updateQueue 请求中止，在请求到达 Host 前返回网络失败。随后断言队列操作失败提示、原消息 ID 和编辑草稿仍存在，持久 Inbox 日志没有插入失败编辑的文本。再次失焦提交同一草稿，沿用成功回执和消息身份断言，继续移除及全部原有投递操作。只中止首次请求，恢复阶段没有模拟响应。

## 队列在途操作锁

修复后 Composer 测试文件39项通过；全 QS 161文件942项通过，四项逐文件覆盖率100%，日志 logs/repair-v1-queue-all-coverage.log。单包首次覆盖率命令因 Host apply 由其他 QS 生命周期用例覆盖而失败，日志 logs/repair-v1-queue-busy-coverage.log；随后扩大测试选择至全部 QS，没有增加排除或降低阈值。

## 会话实例隔离复核

官方 ui-renderer 的 SessionMaybeEntry 在空白页接纳首个 Session 时保留实例，在已选会话切换到不同 Session 或回到空白时重建实例。QS composer 使用 session-maybe，不额外增加与该机制竞争的 sessionId 重置逻辑。新增 DOM 回归在旧编辑请求未完成时卸载旧实例，再挂载含相同队列项 ID 的新会话实例；旧请求迟到返回失败后，新实例无错误提示、移除按钮可用且操作只调用新实例回调。

Composer 文件40项通过，日志 logs/repair-v1-queue-incarnation.log；官方 scoped-slots 与 session-provider 两文件46项通过，日志 logs/repair-v1-queue-renderer-lifecycle.log；新增文件 lint 退出0。该证据由真实官方生命周期测试和 QS 实例回归共同提供，不冒称浏览器已经执行跨会话网络迟到场景。本轮仅添加测试和记录，没有继续修改生产代码。
