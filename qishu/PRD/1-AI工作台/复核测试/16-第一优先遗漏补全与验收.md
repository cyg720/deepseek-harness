# 第一优先遗漏补全与验收

日期：2026-09-18。范围：第一优先最小可用工作台及其计划中已明确的交互与验收要求；本次没有扩展附件输入、设置页、调度面板或逐工具专属视图。未提交、未推送。

## 本次补全

| 项目 | 实现及验证 |
|---|---|
| 首次发送交接遇阻塞 | 中止自动交接，保留可编辑草稿；恢复连接不会自动提交，必须再次发送。新增阻塞前后受控时序回归，断言真实 submit mock 没有被调用。 |
| 历史加载、失败与重试 | 区分加载、失败和真正的空会话；失败显示错误及重连重试，复用官方 connection.reconnect；DOM 断言错误状态不会被误报为空会话。 |
| 阅读位置恢复 | 按官方 SessionBinding 保存内存阅读位置和跟随意图；切换界面后恢复。浏览器验证阅读位置 130px 在官方/奇术切换后保持；DOM 验证恢复与后续滚动保存。 |
| 历史前插锚点 | 加载前记录可见行与屏幕偏移，前插后补偿实际偏移并保存位置。真实 Host 载入 40 轮历史，浏览器断言记录数增加且原行屏幕位置不跳动。 |
| 布局偏好 | 左右桌面侧栏可拖拽及方向键调宽；持久保存宽度、显隐和辅助标签；登出重置。浏览器验证拖拽后刷新保持宽度及标签，DOM 验证存储损坏回退和重置。 |
| 静态保持登录 | 仅在用户勾选后持久化演示用户名及标记；刷新恢复，登出清除。无真实登录接口、不存密码，不把此标记当作后端鉴权。 |
| 提问草稿清理 | 监听官方 PendingQuestion 结果完成或撤回，清理对应请求草稿；隐藏但未完成的请求保留。官方 PendingQuestion 实例验证外部回答及撤回两条路径。 |
| 整条消息复制 | 用户文本、助手正文可整条复制；排除思考内容，显示复制成功或失败状态。断言剪贴板真实参数为完整正文。 |
| 新会话快捷键 | 工作台列表挂载时支持 Ctrl+K/Command+K，忽略重复、输入法组合和模态对话框状态，卸载解绑。 |
| 交互闭环验收 | 新增真实 Host+Chromium 审批允许/拒绝、提问回答、提问期间停止；检查最终答案载荷、Session 事件与文件副作用；保存待处理卡片 ARIA 快照。 |

## 尚未满足的门槛与验证边界

- 覆盖率门槛未通过；这不是功能测试失败，也不能据此宣称可以通过全部 CI。
- 本次没有执行整仓全部测试、在线模型 API 测试或真正的 HMR 热替换验收。已验证界面切换中的待处理卡和草稿保持，不将其等同于 HMR。
- 阅读位置保留在 SessionBinding 的内存生命周期内；刷新页面不会恢复历史滚动位置。布局和用户选择的静态登录标记才使用持久存储。
- 登录继续是静态展示门，不是安全认证；附件输入等明确后续优先级功能没有纳入。
