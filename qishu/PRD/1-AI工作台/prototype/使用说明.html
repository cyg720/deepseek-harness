组件 6 / 7：审批与提问

登录后点击顶栏「交互演示」，选择操作审批、详情不可用、用户提问、自由回答、方案确认或仅批准方案。每次选择创建独立演示会话；卡片显示在对话流中，沿用浅深主题和移动布局。

  • 审批显示工具、目标、影响与命令，可选择「拒绝」或「允许一次」。详情缺失时显示说明，不编造命令。
  • 提问支持单选、多选、自由文本和多题整体提交。单选与其他答案互斥；多选可同时附加自由文本。必答项为空时定位并提示。
  • 方案正文只读，按钮使用请求给定的标签；可体验双按钮或仅批准选项。
  • 展开卡片底部「演示状态」可模拟下一次提交失败或请求方撤销。失败保留答案并允许重试；撤销移除卡片，不记为用户拒绝。提交中禁止重复回答。
  • 待处理请求与已填答案随会话保存在本机；切换会话、调整窗口或刷新后可继续。提交结果归属于发起会话。存在待处理请求时，新任务发送会提示先完成确认。
  • 所有授权与回答都是模拟，不连接审批接口、不执行命令，也不代表已完成评审文档中的真实接口、HMR 或模型验收。

interactions.js 保存演示场景、卡片呈现与答复交互。专项验证可运行 node validation/interactions.cjs；环境变量与下方通用验证脚本相同，未指定地址时直接读取本目录入口。

系统状态：连接、故障与加载

顶栏「交互演示」的「系统状态」提供连接中断、根故障页、空态与加载骨架。连接中断时仍可编辑草稿，发送禁用；点击重新连接可体验恢复，也可模拟重连失败。根故障页支持重试渲染、重新加载及查看或复制诊断信息。

空态展示会话列表、右栏和工具目录的缺省内容，不删除原有数据。加载骨架提供完成加载和历史分页入口；分页可模拟失败，再重试加载。点击「退出演示」返回正常工作台。所有状态均由本机模拟，真实错误边界、网络恢复和分页接口尚未接入。

system-states.js 为状态原型；运行 node validation/system-states.cjs 可检查恢复路径并生成 preview/system-*.png 与专项报告。浏览器环境变量同下方验证说明。

第一优先：发送与恢复

从顶栏「交互演示」进入「发送与恢复」。可体验流式输出与队列、首次发送取消、创建失败、创建部分成功、发送失败、模型不可用、会话加载失败、管理操作失败和交互卡局部故障。所有状态只在本地模拟。

  • 流式生成时可继续编辑并加入待发队列。队列支持编辑、移除和引导当前轮；停止当前轮后按队列继续。生成异常中断后，部分输出保留，队列等待点击「继续待发队列」。引导会从队列移出该项并补充到当前轮；当前轮不可用时禁用，竞争失败保留任务。仅为本地模拟，不接 Host。
  • 首次发送期间输入只读，取消会保留草稿且不创建会话。创建部分成功会保留已创建会话；重试归入工作区不会重复创建，也不会自动发送。
  • 切换会话或新建会话不会停止后台生成；普通草稿和附件按会话在当前页面内保留。刷新后普通草稿不保留，未完成的本地生成显示为已停止，已保存队列可手动继续。
  • 管理会话中的「归档会话」隐藏列表项并保留消息；生成中、有待发任务或等待确认时不允许归档，处理完成后可归档。没有自动删除或归档恢复入口。
  • 「管理操作失败」使下一次归档或重命名失败，可原地重试。队列有独立的失败模拟按钮。局部卡片故障不撤销请求，重试后仍可回答。存在审批或提问时发送禁用，草稿可编辑。

运行 node --test validation/conversation-state.cjs 检查会话生命周期；preview/conversation-*.jpg 为新增状态截图。测试和截图只验证原型，不代表正式插件或后端验收。

“延迟发送失败”演示先清空旧输入，随后显示失败内容；期间输入的新草稿保持不变。首次发送等待与暂停队列继续都会重新检查连接、模型和确认状态。滚动位置与是否跟随最新消息按会话分别保存。

演示数据与保存

  • 业务数据的示例日期固定为 2026-09-13；日历可浏览其他月份。工作区之间隔离会话、资料、待办和日程。
  • localStorage 的 yuvi-prototype-v1 保存交互数据和偏好。自动登录只保存演示身份，不保存密码；未勾选时登录身份只放在 sessionStorage。
  • 附件大小限制为 20 MB，不上传文件。工作区保存文件元信息；当前页面内可预览 TXT、CSV、MD、JSON、LOG。刷新后不保留用户文件正文。
  • 清除浏览器的此站点数据即可恢复初始样例。使用 file 地址与 localhost 地址时，浏览器存储互相独立。

自适应布局

支持手机、平板、桌面及横屏窄高窗口。窗口跨越 700 px 和 960 px 断点时自动调整侧栏，返回桌面时恢复该布局的开关状态；缩放不会重建对话输入框或弹窗。手机端左右栏互斥，平板右栏使用遮罩浮层，可点击遮罩或按 Esc 收起。输入区随可用视口高度适配，长内容在各自区域内滚动。

原型的实际限制

没有真实认证、后端 API、模型推理、通知调度、设备操作或外部服务连接。模型选择与深度思考只改变演示交互；语音输入使用可点击的示例转写，不访问麦克风。当前项目是工作区内的单个展示项目，新建按钮更新项目名称，不创建独立的项目数据容器。

代码与验收

index.html 为入口，styles.css 为样式，app.js 为本地状态与交互，factory.svg 为登录页动态插图，serve.cjs 为静态服务器。preview/ 保留实测截图，validation/ 保留浏览器验证脚本与结果。

验证脚本使用 Playwright；可用环境变量 PLAYWRIGHT_MODULE 指定模块目录、BROWSER_PATH 指定浏览器可执行文件、PROTOTYPE_URL 指定已启动的原型地址，然后运行 node validation/verify.cjs。脚本在隔离浏览器中检查关键流程，不修改用户浏览器数据。
