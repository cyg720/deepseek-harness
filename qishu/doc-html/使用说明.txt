栖树 · DeepSeek Harness 离线源码导览

打开 index.html 即可使用，推荐现代 Edge、Chrome 或 Firefox。
只复制 index.html 到另一台电脑，也可以阅读全部内置内容，无需服务器或联网。

内容总览
1. 六层项目地图与新手学习顺序。
2. 应用启动、消息执行、会话恢复、UI 装配四条源码路线。
3. 307 个项目包的中文 README、类型分类、依赖关系与源码入口。
4. 4,000 个内置源码、配置和文档文件；源码可按行定位与搜索。
5. 概念讲解与二开导航。
6. 当前 HEAD 可达的 19,676 条本地 Git 提交及变更文件统计。
7. 全站搜索、深浅色主题、动画过渡、已读进度与源码书签。
8. 新增“可视矩阵”：空间组态、关系矩阵、启动对比、场景流转、记录回放。

可视矩阵：推荐的新手学习顺序
1. 点“带我开始”，播放“发一句消息，收到回答”，每一步看右侧输入、输出、机制与源码。
2. 回到“空间组态”：9 个分区覆盖全部 307 个项目包；支持旋转、倾斜、缩放和平面阅读。
3. 点击一个包，读中文说明，查服务与事件，再点“在关系矩阵定位”核对直接关系。
   直接关系模式将选中包固定在每一页；包依赖、服务协作、事件监听分别查看。
4. 在“启动对比”比较 web / desktop / headless / sdk / sdk-minimal / acp。
   引用清单来自模板与 bundle 配置；不执行条件表达式，不表示运行时实际激活树。
5. 逐步学习文件读取、Shell 审批、取消、恢复会话和子智能体委派，共六个场景。
6. “记录回放”可导入本地 JSONL（v4 头部）或事件 JSON，按 seq 观察事件及原始 data。
   上限 8 MiB、10,000 条；只验证事件信封，不执行工具、不还原完整 Agent 状态。
   内置示例是手工教学数据；动画间隔与节点位置都不代表真实耗时或调用拓扑。
7. 导出/导入学习进度可迁移已读步骤和源码书签；导入的会话数据不会写入进度文件。

矩阵收录 89 个文档服务条目、77 个文档事件条目、1,751 条包/服务/事件关系记录。
这是当前源码和生成文档的可查证快照，不覆盖未声明的动态运行时关联。
空间地图采用可旋转的 2.5D 投影，默认只显示选中包的直接关系，避免连线淹没内容。

功能清单
左侧“功能清单”按 9 个大模块组织全部 307 个包级功能条目。
搜索支持中文用途、包名、细分模块和模型工具名称，点击模块可单独筛选。
每个条目提供五个维度页：作用与使用、实现与注释、引用与协作、配置与限制、来源与验证。
其中包含中文 README、具体工具名、原始 JSDoc、依赖及反向引用、服务/事件角色、
启动组合引用、配置声明、已知限制、测试位置与完整源码列表。
这是全量包职责清单，不是每一个函数、运行时分支或外部动态工具的枚举。
条目来源为本地源码快照与仓库文档；目录收录不代表已运行每项产品功能。
可复制浏览器 #features/… 地址定位一个条目，刷新后仍可打开对应功能。
生成逻辑：features_data.py；交互与布局：features.js、features.css。
验证：node qishu/doc-html/verify-features.cjs，结果在 verification-features.json。

历史中文说明的范围
近期 25 条记录提供人工标题解读，其他记录提供基于提交类型、标题关键词、
变更目录和文件统计的中文自动摘要。自动摘要不是每条历史差异的人工审查，
也不是所有原始标题与正文的逐句翻译。原文始终保留，完整历史 diff 没有内置。
在提交详情中打开文件时，看到的是当前源码快照，绝不是该提交当时的文件版本。
合并提交的变更统计相对第一父提交。日期使用 Git 中的作者日期。

更新资料
在项目根目录执行：
  python -X utf8 qishu/doc-html/build.py
生成需要 Python 3.11+ 和 PyYAML（缺少时可用 python -m pip install PyYAML 安装）。
浏览器阅读生成好的 HTML 不需要 Python、Node、PyYAML 或网络。
生成器只写此目录，不修改项目功能代码，不运行网络请求。
同一 HEAD 的历史统计缓存于 .history-cache.gz；删除它可强制重采集。
index.html 是生成文件，请修改 template.html、style.css、app.js 与 guide.json 后再生成。
矩阵的实现与样式在 matrix.js、matrix.css；讲解在 matrix-guide.json；提取器在 matrix_data.py。
matrix-guide.json 的 reviewedHead 同样需要人工复核后更新。
新增具体中文提交解读可写入 history-zh.json（键为 10 位提交号）。
guide.json 的 reviewedHead 是人工核实过的基线，不会被生成器自动升级。
升级源码后应复核流程和动画图；仅源码锚点仍存在不足以证明语义不变。
runtime-map.html 是 archify 从 runtime.workflow.json 生成的独立动画图，已经内置到首页文件。
manifest.json 保存基线、收录范围和文件 SHA-256，方便比较不同快照。

浏览器验证
verify.cjs 使用 Playwright 以 file://、断网状态测试主要交互。
需要已安装 Playwright 和 Edge；也可用 BROWSER_CHANNEL 指定其他已安装浏览器。
若 Playwright 不在项目依赖中，可用 PLAYWRIGHT_MODULE 指向其模块路径。
  node qishu/doc-html/verify.cjs
  node qishu/doc-html/verify-matrix.cjs
验证结果保存在 verification.json 和 verification-matrix.json，页面预览保存在 preview-*.png。

Esc：关闭详情
源码窗口内可按行定位、查找下一处符号、沿 import 跳转并收藏当前行。
