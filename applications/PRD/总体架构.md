
### 目标：AI安全生产智能体平台
    建设面向集团型企业或单企业的多租户安全生产智能体平台，覆盖设备实时运行监测、720全景可视化、安全检查、隐患闭环管理、SOP标准作业步骤智能检测、AI算法训练部署，并延伸至实时双工交互（语音/视频）与具身智能（机器人/无人机）控制。
    通过使用deepseek harness 智能体基座来建立 智能体中枢，统筹其他智能体的运行，实现智能体之间的协作和通信。用于协调不同智能体之间的任务分配、资源调度、数据交换、能力支撑等。

    每个独立的应用都自己维护 参数管理、字典管理、日志管理、操作管理、数据权限管理等功能。
    每个应用的操作功能按钮如果需要参与授权就需要向鉴权中心进行注册推送那些功能按钮。
    所有应用都依赖于鉴权中心，用于认证、授权、权限管理、应用授权等。

### 统一响应格式及状态码
    格式：
    {
        "code": 200,
        "msg": "success",
        "data": {}
    }
    状态码：
        200 成功、400 请求参数错误、401 未认证、403 未授权、404 资源不存在、500 服务器错误、501 未实现、500 服务器错误、503 服务不可用、504 网关超时


### 功能系统模块
    1、AI工作台
        1、用户登录注册
        2、承载所有应用界面入口
    2、鉴权中心
        作用：负责用户认证、授权、权限管理、应用授权等。
        备注：完全独立应用，不依赖其他应用。
        工具：提供系统相关接口提供原子级操作工具
        skill：提供操作skill手册
    3、IoT物联中台
        作用： 负责设备的采集、处理、存储等。
        备注：负责设备的采集、处理、存储等，与设备直接交互，不依赖其他应用。
        工具：提供设备相关接口提供原子级操作工具
        skill：提供操作skill手册
    4、媒体处理中心
        作用：负责视频、音频等媒体的处理、存储等（ZLMediaKit）。
        备注：可以使用开源的视频处理库（如OpenCV、FFmpeg等）来实现视频处理功能。
        工具：提供视频相关接口提供原子级操作工具
        skill：提供操作skill手册
    5、应用中心
        作用：负责应用的注册、管理、审批、上下架、监控等。
        备注：独立应用（在DSH中是一个插件），应用不一定有UI界面，更多是提供给智能体使用
        工具：提供应用相关接口提供原子级操作工具
        skill：提供操作skill手册
        内置应用：
            全景VR应用:
                作用：负责720全景全景可视化展示，管理、编排。
                备注：提供720全景全景可视化展示功能，支持用户通过VR设备查看设备实时运行状态。
                工具：提供720全景全景可视化展示相关接口提供原子级操作工具
                skill：提供操作skill手册
            AI算法检测应用:
                作用：负责AI算法的采集、标注、训练、部署、监控等。
                备注：提供AI算法的采集、标注、训练、部署、监控等功能，支持用户根据需求训练和部署AI模型。
                工具：提供AI算法相关接口提供原子级操作工具
                skill：提供操作skill手册
            SOP标准检测应用:
                作用：负责SOP标准作业步骤智能检测，管理、编排。
                备注：提供SOP标准作业步骤智能检测功能，支持用户根据SOP标准作业步骤进行智能检测。
                工具：提供SOP标准相关接口提供原子级操作工具
                skill：提供操作skill手册
            安全检查应用:
                作用：负责安全检查，管理、编排、隐患闭环管理。
                备注：提供安全检查功能，支持用户根据安全检查标准进行检查。
                工具：提供安全检查相关接口提供原子级操作工具
                skill：提供操作skill手册
            企业驾驶舱应用:
                作用：负责企业驾驶舱展示，管理、编排。
                备注：提供企业驾驶舱展示功能，支持用户通过VR设备查看设备实时运行状态。
                工具：提供企业驾驶舱相关接口提供原子级操作工具
                skill：提供操作skill手册
    6、智能体中枢
        作用：负责智能体的调度、协调、通信等。承担主智能体的角色。统筹负责用户对话沟通交流，可以根据用户需求回答、生成、执行等任务，协调不同智能体之间的任务分配、资源调度、数据交换、能力支撑等。
        内置子智能体：
            pi agent 编程智能体:
            鉴权中心智能体:
            应用中心智能体:
            消息推送智能体:
            RAG知识库智能体:
            skill中心智能体:
            可视化智能体:
            安全检查智能体:
            设备监测智能体:
            视觉分析智能体：
            具身控制智能体：
        备注：deepseek harness 智能体中枢基座
    7、插件中心
        作用：负责插件的管理（DSH插件）、自定义扩展插件等。
        内置插件：浏览器接管插件。
        工具：提供插件相关接口提供原子级操作工具
        skill：提供操作skill手册
        备注：主要是开发人员使用，提供插件给相关应用或智能体调用
    8、具身智能终端:
        作用：负责具身智能终端的控制、协调、通信等。
        备注：负责具身智能终端的控制、协调、通信等，与用户直接交互，不依赖其他应用。
        工具：提供智能终端相关接口提供原子级操作工具
        skill：提供操作skill手册
    9、执行网关（工具）
        作用：负责提供各类工具执行，支撑插件中心、智能体中枢、智能体的运行，原子API，无状态，输入输出明确。
        工具：提供执行网关相关接口提供原子级操作工具
        skill：提供操作skill手册
        备注：主要是开发人员使用，提供工具给相关应用或智能体调用
    10、skill中心
        作用：负责skill的管理、审批、上下架、更新、删除等。
        备注：主要是开发人员使用、使用用户自定义skill，提供skill给智能体或者智能中枢调用。
    11、RAG知识库
        作用：负责存储、检索、更新、删除等，包含时序数据检索。
        工具：提供知识库相关接口提供原子级操作工具
        skill：提供操作skill手册
        备注：主要是开发人员使用，提供知识库给相关应用或智能体调用。
    12、消息推送中心
        作用：负责消息的推送（飞书、企业微信、短信、邮件、钉钉等）、提供消息客户端webhook对接智能中枢进行对话。
        工具：提供消息推送相关接口提供原子级操作工具
        skill：提供操作skill手册
        备注：将大模型对话消息推送给对应账号的消息终端，实现用户与智能体的实时双工交互。
