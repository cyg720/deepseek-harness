# 平台公约

本公约统一平台各应用的接口路径、分页、返回结果及编辑规则，供前端、后端和测试共同使用。版本1.0，依据本轮用户授权制定，属于待实现的开发约定，不代表已有接口已经实现。授权中心采用本公约；其他模块接入时应核对各自PRD。

## 接口路径与请求

接口以 `/api/v1/{模块}/{资源}` 开头，模块和资源使用小写英文，多词用短横线。授权中心模块名为 `auth`。路径版本变更用于不兼容的接口变更；业务编码不作为接口版本。

| 动作 | 方法与路径示例 | 规则 |
| --- | --- | --- |
| 新增 | POST /api/v1/auth/accounts | JSON请求体；成功返回生成的id和version |
| 分页列表 | GET /api/v1/auth/accounts | 查询条件放查询参数 |
| 详情 | GET /api/v1/auth/accounts/{id} | 不存在返回404 |
| 部分编辑 | PATCH /api/v1/auth/accounts/{id} | JSON请求体必须带version |
| 删除 | DELETE /api/v1/auth/accounts/{id}?version=7 | 比较版本；成功data为null；重复删除返回404 |
| 业务动作 | POST /api/v1/auth/accounts/{id}/password-reset | 独立动作路径；需要版本时在JSON体中传入 |

请求体为UTF-8 JSON，字段采用camelCase。数据库BIGINT标识符及version用十进制字符串传输，避免浏览器丢失精度；分页数字和业务code使用JSON整数。时间统一为北京时间，格式为 `YYYY-MM-DD HH:mm:ss`，精确到秒，不混用UTC或带时区格式。

需要用户身份的接口使用 `Authorization: Bearer <token>`；需要应用身份的接口使用 `X-App-Key`。登录不要求已有用户token，但需要调用应用身份。具体接口的主体和权限由模块PRD规定；不能因为带了请求头就跳过身份及权限检查。凭据不得放URL、普通日志或错误详情。

## 分页、筛选与排序

| 参数 | 规则 |
| --- | --- |
| page | 从1开始，省略为1；必须为正整数 |
| pageSize | 省略为20，范围1至100；越界返回400，不偷偷改成最大值 |
| sortBy | 模块公布的排序字段；不在白名单返回400；默认id |
| sortOrder | asc或desc，默认desc；其他值返回400 |
| 业务筛选字段 | 各模块逐项定义；未支持的字段返回400 |

同值排序追加id作为次排序键，方向与sortOrder一致；日志等复合主键资源由模块声明稳定的次排序键。total是当前用户有权查看且符合筛选的数据总数；超出末页返回空items，保留实际total。分页不承诺并发增删期间的跨页快照一致性。不得把用户给出的字段名直接拼进SQL，值由MyBatis绑定，动态列名只从固定白名单选取。

```json
{"code":200,"message":"成功","data":{"items":[{"id":"101","version":"7"}],"page":1,"pageSize":20,"total":1}}
```

## 统一响应与错误码

响应固定包含 `code`、`message`、`data`。成功统一使用HTTP 200和code 200；新增、删除也遵守该规则，无返回业务数据时data为null。message供人阅读，客户端按HTTP状态和code判断，不能靠匹配中文提示分支。

| HTTP | code | 含义 | 处理方式 |
| --- | --- | --- | --- |
| 200 | 200 | 成功 | 读取data |
| 400 | 40001 | 字段或参数不合法 | 定位错误字段并修改 |
| 401 | 40101 | 缺少或无效用户凭据 | 转登录；登录失败提示凭据无效，不透露账号是否存在 |
| 401 | 40102 | token已到期 | 清除当前登录凭据并转登录 |
| 401 | 40103 | token已撤销或被新token替换 | 当前设备重新登录 |
| 401 | 40104 | 缺少或无效AppKey | 提示应用接入异常，避免反复跳用户登录 |
| 403 | 40301 | 没有操作权限 | 提示无权操作 |
| 403 | 40302 | 账号冻结、应用冻结或应用下线 | 阻止操作，提示对应主体不可用 |
| 403 | 40303 | 必须先修改初始密码 | 进入强制改密流程 |
| 404 | 40401 | 目标不存在 | 刷新页面或返回列表 |
| 409 | 40901 | 版本已变化 | 保留输入，重新读取后由用户确认再提交 |
| 409 | 40902 | 唯一值重复 | 修改编码等重复字段；不得覆盖已有对象 |
| 409 | 40903 | 仍有引用，不能删除 | 提示引用；先单独处理关联 |
| 409 | 40904 | 状态冲突，如未到续期时间 | 保持当前状态，读取最新结果 |
| 500 | 50001 | 内部处理失败 | 提供诊断标识，禁止显示堆栈和SQL |
| 503 | 50301 | 依赖不可用 | 提示稍后重试；不得当作授权通过 |

错误data固定为对象，包含traceId；字段错误可附fieldErrors数组，引用冲突可附references数组。引用详情只返回当前操作者有权看到的字段，无权部分只提示“存在无权查看的关联”，不得因此允许删除。服务器生成诊断标识，不把客户端传入的任意字符串直接写入日志。

```json
{"code":40001,"message":"请检查输入内容","data":{"traceId":"example-trace","fieldErrors":[{"field":"pageSize","message":"请输入1至100的整数"}]}}
```

## 编辑时漏填、空值与版本

PATCH只修改明确提交的字段；路径id定位对象，请求体不再传id。所有编辑必须提交读取时的version；服务端在同一条条件更新中比较版本，成功后增加1，返回最新version。不能用更新时间代替version。

| 输入情况 | 处理规则 |
| --- | --- |
| 没有提交某字段 | 保持原值 |
| 显式传null | 可空字段清空；必填字段返回40001 |
| 空字符串或全空白 | 必填文本拒绝；可选文本统一清空为null；密码不裁剪空格并按密码规则校验 |
| 空数组 | 支持集合编辑的字段清空集合；模块规定至少一项时拒绝 |
| 提交数组 | 完整替换该集合，不默默追加；校验每个元素及重复值，失败整体不变 |
| 未知字段或只读字段 | 返回40001，不忽略；审计字段、密码散列、token摘要等不得写入 |
| 缺少version | 返回40001 |
| version过旧 | 返回40901，不能覆盖他人的修改 |
| 仅提交version或提交后没有有效变更 | 返回40001，不递增版本 |

新增时省略字段使用模块明示默认值；没有默认值的必填字段拒绝。新增请求不能带id、version或其他只读字段。编辑唯一字段发生冲突返回40902；任一字段失败时，其他字段、关联和版本均不改变。

## 删除、重复请求和敏感结果

删除不默认连带删除。授权中心的账号、组织、权限组有引用时返回40903，其他数据保持原样；其他业务模块是否提供关联删除，由该模块业务规则明确，不由平台统一替它决定。不得在通用删除实现中启用不受业务约束的级联清理。

GET可以重试；新增和业务动作超时后不能直接当作失败。默认不提供通用幂等结果缓存：客户端应先查询状态，或执行模块定义的恢复流程。唯一编码重复提交返回40902；PATCH旧版本重试返回40901；DELETE重复执行返回40401。确需幂等键的接口另行明确保存时长、请求内容一致性及重放结果，不能仅凭请求头声称幂等。

登录、token换发、首次改密凭据、随机密码重置结果使用 `Cache-Control: no-store`。一次展示的随机密码仅由首次成功响应返回，前端弹框供复制；关闭、刷新或离开页面即清除，不提供再次查询明文入口，不写本地存储、URL、日志或审计。用户主动复制到系统剪贴板后，平台不能保证剪贴板中的内容也已消失。响应丢失或用户未保存时，需要再次执行有权限的重置操作，不能找回旧随机密码。

## 开发与测试落实

各模块在自己的PRD列出具体路径、字段和权限，引用本公约，不再各自定义另一套分页或错误格式。平台统一约定变更时，应同步更新依赖模块的PRD、接口定义和测试。

验收至少覆盖：分页默认值和越界、稳定排序、HTTP与code一致、ID精度、字段缺失/null/空值、未知和只读字段拒绝、版本冲突、引用删除不产生副作用、敏感结果不缓存。上述约定尚未进行真实接口测试；各模块需在实现后记录实际结果。
