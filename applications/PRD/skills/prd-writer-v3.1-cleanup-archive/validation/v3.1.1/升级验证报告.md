# prd-writer 3.1.1 升级验证

技能目录继续使用 `prd-writer-v3.1`，入口元信息升级为 `3.1.1`。

## 变更

- [技能入口](../../prd-writer/SKILL.md)、[DDL 规范](../../prd-writer/references/database-ddl.md) 和起草模板要求正文完整建表 SQL 与同内容 `.schema.sql`，包含表/列注释、约束、索引语句和查询依据；区分空库初始化、存量迁移、候选假设和批准状态。
- [HTML 模板](../../prd-writer/assets/offline-shell.html) 按实际标题建立多级目录；父目录文字点击定位并折叠/展开，箭头只切换折叠。子标题有唯一目标，支持重复标题、跳级标题、键盘操作、搜索后定位、编辑/导入同步和导出重开。代码围栏不产生目录项。折叠状态是当前阅读状态，正文重建或重新打开时默认展开。
- [新增演示](toc-ddl-demo.prd.html) 配套 [SQL](toc-ddl-demo.schema.sql) 包含两张合成表、六列注释、主键、唯一/外键/检查约束和复合索引。此演示不是授权中心方案；原授权中心文件本轮未重新生成。
