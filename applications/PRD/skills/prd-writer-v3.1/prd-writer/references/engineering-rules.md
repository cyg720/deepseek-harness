# 工程契约规则

本文件用于检查需求与设计边界，不代替项目代码、依赖文档或架构评审。

## 接口

分别记录 HTTP 状态码、业务 code、字段级错误、用户提示、可重试性及诊断标识。
存量全 200 协议可以保留；应说明监控如何区分业务成功/失败，以及应用之外的 HTTP 错误。
新增 HTTP 语义或 URL 风格须按兼容变更处理。

公共 save 可以是内部实现，但不能使公开动作边界不明确。
例如：新增拒绝带入用于选择现有对象的 id；编辑要求有效目标 id；编辑不存在资源时不得意外转为新增。
这些是建议的清晰契约；若项目确有显式 upsert，需独立说明其授权、唯一性与重试语义。

明确全量替换还是局部修改。缺失字段、null、空字符串、空集合分别定义，不允许模型自行混同。
客户端不能直接改写 tenant_id、创建人、审批结论等受控字段；实际允许字段依角色与状态决定。
对外响应与持久化实体分离，避免直接暴露不该读取的属性。

## 幂等与重试

幂等检查同一操作的重复请求是否产生额外的预期业务效果，不要求响应字节完全相同。
重复删除第一次成功、之后报告已不存在，并不因此自动违反幂等。
请求审计可以逐次记录；需要防止的是重复业务动作、重复发货/付款/通知等不应重复的效果。
是否重复通知也须依据已明确的业务语义决定，而不是以日志条数判断幂等。

有副作用的创建、导入或外部调用，按风险定义业务键或幂等键、作用域、保留期限、参数不一致、处理中和失败重试行为。
这些不是所有 POST 的强制同一实现。重放结果之前仍需验证当前授权与数据范围。

## 并发与约束

应用层 exists 检查可改善错误提示，但不能替代数据库唯一性保证。
唯一约束要与业务范围一致：全局/租户/组织、大小写、空值及软删除策略均需说明。
写入冲突要在项目异常处理边界映射；不能把所有数据库异常都映射为重复编码。

高风险更新默认要求显式冲突策略，不接受未经批准的静默覆盖。
使用版本控制时，契约应携带或绑定用户读取时的版本，并在写入时原子校验。
仅在实体上存在 @Version，并不自动定义跨请求的陈旧表单处理与用户恢复体验。
低风险后写覆盖只有在明确接受该风险后才能采用。

引用关系必须定义删除、软删除、归档、恢复和级联的业务后果。
涉及外部系统、消息或设备执行时，补充局部失败、超时、重复、补偿及确认语义；不强制引入某种架构。

## 数据与迁移

业务字典、API、Java 属性、数据库列分别记录名称与约束，再验证映射一致。
数据库 NOT NULL、请求必填、服务端自动生成是不同概念；不可合并为一个“必填”值。

JSON 用 TEXT、JSON 或 JSONB 的选择依据存量兼容、合法性校验、查询索引和原始文本保真需求。
时间字段区分时间点、本地日历时间与日期。TIMESTAMPTZ 不保存原始时区名称；需要该信息时另存。
创建时间可有插入默认值；更新时间需明确 ORM、应用或触发器的维护责任。
审批、完成、删除等事件时间在事件发生前通常应未设置，实际按业务定义。

初始化 DDL 与存量迁移分开。IF NOT EXISTS 不是结构一致性验证。
迁移写明适用版本、已有数据处理、约束验证、锁表/可用性影响、验证方法、回退或前滚恢复。
不凭空声明迁移工具已安装，不擅自给项目新增迁移框架。
索引与查询及数据规模对应；不机械地给所有时间列建排序索引。

## 安全与运行

检查认证、动作授权、对象授权、字段授权及适用的数据范围。
多租户边界不仅是写入 tenant_id，也包括查询、计数、导出及适用的缓存、搜索、文件、后台任务。
租户与主体上下文应由服务端验证；客户端选择上下文不等于被授权。

SQL 值参数化；可变排序字段和方向使用白名单映射，不能将任意标识符当成普通绑定值。
纯文本按输出上下文编码。需要富文本时定义允许内容与清理策略，不能仅写“前端转义”。
日志说明主体、动作、资源、范围、结果、时间及关联标识，并定义敏感字段脱敏和访问控制。

性能指标写明数据规模和分布、负载、环境、测量边界、分位数、错误/超时、持续时间及验证方法。
无基线时写“建议目标/待确认”，不能把模板中的 200ms、100ms 当作已验证能力。
高风险模块按需要补可用性、告警、回退、恢复目标；不要求每个小模块重复一套平台级规范。

## 规范依据（便于团队核对）

- IETF RFC 9110：9.2.2 幂等；第 15 节 HTTP 状态码。
- PostgreSQL 15 文档：CREATE TABLE 的 IF NOT EXISTS；5.2 默认值；8.5 时间类型；8.14 JSON；11.6 唯一索引。
- Jakarta Persistence：版本属性与乐观并发控制。
- OWASP API Security 2023：API1 对象级授权；API3 对象属性级授权。
- OWASP Cheat Sheet Series：SQL Injection Prevention；Cross Site Scripting Prevention。
