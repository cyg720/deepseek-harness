# DeepSeek Harness 原生桌面端技术分析

## 摘要

你不需要从零写一个 Electron 工程。当前仓库已经有桌面窗口、独立后端、通信协议、插件管理、安装包和更新机制。最适合你的起点是：先运行现有桌面版，再制作 Windows 未签名测试安装包，最后逐步加入企业品牌、智能体中心和账户权限。

这里的“原生桌面端”指能够安装、具有独立窗口并能调用操作系统能力的桌面应用。聊天界面仍然由 Web 技术渲染；它不是使用 WinUI、WPF 或 SwiftUI 重写的界面。

## 先记住这六件事

1. `apps/desktop` 管理 Electron 窗口、桌面菜单、启动恢复、插件安装、更新和打包。
2. `apps/desktop-host` 在独立 Node.js 子进程中加载 Harness 后端及匹配的前端资源。
3. 聊天 UI 主要来自 `apps/web` 和 `packages/client`；不要只在桌面目录里找聊天页面。
4. 默认桌面通信不启动本地 Web 监听端口；内部地址是 `dsh-app://app/index.html`，不是可以复制到 Chrome 打开的服务地址。开发调试端口是另一回事。
5. 开发环境需要 Node.js 和 pnpm；打包后的最终用户程序自带运行时。首次打开不需要从 npm 安装核心 Harness。
6. 桌面外壳不会自动提供企业登录、组织、租户隔离和 RAG 数据授权。这些仍需由你的平台和业务插件实现。

## 操作约定

本教程以 Windows x64、PowerShell 和当前仓库路径为主。命令块只复制命令内容，不复制开头和结尾的三个反引号。一次执行一个步骤，看到成功条件后再继续。代码中的 `com.example.qsdesktop`、域名和密钥占位符是示例，需要替换成你自己的值。

报告中的“源码确认”表示已找到当前实现；“本机验证”表示本次确实执行过；“改造建议”表示需要你或开发人员新增实现。完整操作步骤不等于本次已经安装了编译器、申请了证书或发布了产品。

报告按你的要求保存在 `D:\code\CYG\Github\deepseek-harness\applications\qs-docs\原生桌面端技术分析`。中文分篇 Markdown 是报告原稿；同目录的 `桌面端技术分析.html` 是便于双击阅读、搜索和打印的离线阅读版。
